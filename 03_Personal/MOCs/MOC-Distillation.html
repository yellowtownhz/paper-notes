蒸馏研究地图

2026 年蒸馏研究的核心张力：信息差从何而来。自蒸馏方法证明同一模型只需条件化不同特权信息（ground-truth 答案、环境反馈、对比样本）即可自我教学，无需外部教师；标准蒸馏则面临 off-policy 分布漂移与 on-policy 可教性衰减的权衡。本 MOC 沿"特权信息来源"这条主线组织论文。 新增研究把这条主线延伸为三个问题：信息从何而来、经过什么监督接口、用什么证据确认迁移。教材问答、无关输入上的硬标签、动作条件注意力与共享特征测量，不能统一简化为逐 token KL 匹配。

自蒸馏

四篇论文共享同一结构：同一模型通过条件化不同的特权信息（OPSD 用 ground-truth 答案、SDPO 用环境反馈、SDFT 用专家示范、VC-STaR 用对比样本对）同时扮演教师和学生。它们都使用前向或逆向 KL 将教师分布蒸馏到学生策略，但解决的痛点各异——从稀疏奖励到灾难性遗忘到视觉幻觉。

文本推理自蒸馏

OPSD/SDPO/SDFT 三篇论文来自紧密交叉的作者圈（MIT/ETH），都将 RLVR 的稀疏标量奖励替换为 token 级密集信号——但特权信息的来源不同：OPSD 依赖标注答案（先验），SDPO 利用环境反馈（后验），SDFT 使用专家示范并通过 EMA 教师稳定训练。幻觉论文则从防御角度出发，证明固定快照自蒸馏可遏制 SFT 导致的事实遗忘。

  • Self-Distilled_Reasoner-On-Policy_Self-Distillation - OPSD，教师以标准答案作为特权信息，实现 8 倍 token 效率提升（UCLA, 2026）
  • Reinforcement_Learning_via_Self-Distillation-SDPO - SDPO，教师以环境反馈（运行时错误等）为条件，突破 RLVR 信息瓶颈（ETH+MIT+Stanford, 2026）
  • Self-Distillation_Enables_Continual_Learning - SDFT，教师看到示范数据，使用 EMA 稳定训练以防止灾难性遗忘（MIT+ETH, 2026）
  • Why-Fine-Tuning-Encourages-Hallucinations-SFT幻觉与自蒸馏 - 固定快照自蒸馏防止 SFT 导致的事实遗忘（~15pp -> ~3pp）；核心洞见：干扰集中在竞争实体 token 的高概率区域（Hebrew U + UIUC, 2026）

视觉推理自我改进

利用对比能力作为 VLM 的内在验证机制。

  • Through_the_Lens_of_Contrast-Self-Improving_Visual_Reasoning_in_VLMs - VC-STaR，挖掘视觉对比样本对；"对比即监督"解决视觉幻觉验证难题（ICLR 2026 Oral）

自我改进预训练

标准蒸馏

与自蒸馏不同，这些工作依赖外部强教师（如 DeepSeek-R1）。核心挑战不再是"特权信息从何而来"，而是如何施加密集监督：off-policy 蒸馏面临 compounding error，on-policy 蒸馏又遇到教师优势随前缀推进而衰减的"可教性崩塌"问题。数据选择策略（Provenance Tracing、步长去混淆）则从源头提升蒸馏数据的信息量。

推理能力蒸馏

将大模型推理轨迹迁移到更小的模型。

  • Tracing-Provenance-in-LLM-Reasoning-Distillation - Provenance Tracing，追踪蒸馏模型输出的来源（Teacher/Student/Boosted），发现 Teacher Sentence 与准确率高度相关；提出教师引导的数据选择策略（ZJU + Alibaba Cloud, 2025）
  • Step-Length-Confounding-LLM-Reasoning-Data-Selection - 同一团队的另一数据选择工作，关注步长混淆问题
  • Trust-Region-Adaptive-Policy-Optimization-TRAPO - 提出 TrSFT 作为从 DeepSeek-R1 expert trajectory 向学生模型蒸馏推理知识的改良方式，通过梯度裁剪将 forward KL 转为 mode-seeking

在线策略蒸馏（强到弱）

学生模型展开，教师在学生访问的前缀上打分；修改密集监督施加的位置和方式。

  • Prefix-Teach-Suffix-Fade-Local-Teachability-Collapse - 识别出强到弱 OPD 中的"局部可教性崩塌"：教师平均优势保持非零但 token 级离散度衰减；提出基于轨迹特异性 BIC 变点检测的教师 top1-top2 边界方法，按轨迹释放密集监督（ZJU + Meituan LongCat, 2026）
  • On-Policy-Distillation-在线策略蒸馏 - 提出 on-policy distillation——学生自身采样轨迹、老师逐 token 打分（reverse KL），9-30x 计算效率提升并解决 off-policy 蒸馏的 compounding error（Thinking Machines Lab, 2025）

监督接口与迁移机制

关键问题

蒸馏的信息既可能显式写在教材问答与教师预测中，也可能隐含在无关输入上的决策差异里。关键是分清学生接收了什么、哪些约束帮助它学习，以及最终收益来自知识、行为组织还是部署时的反馈速度。

关键方法

MechGPT 先生成领域问答再做监督微调；Shallow-π 只额外对齐动作读取条件的注意力与速度预测；ATD 采集共享祖先近边界上的教师硬标签；swap readout 则在共同字典中测量并干预蒸馏前后的特征使用变化。

关键结论

不同接口支持的证据不同：教材问答案例尚未隔离微调净收益；动作蒸馏的选择性约束有消融支持，但真机优势混有更低延迟；ATD 的同源迁移不等于任意新知识复制；swap 的双向干预支持部分 warm-up 收益可被移植，而零新增检出只适用于当前层、字典、数据和阈值。

Insight

更稳健的比较单位是“信息来源—监督接口—验收目标”三者的对应关系。先匹配基座、数据、训练与推理预算，再分别检查可执行任务、内部测量和闭环表现，才能判断蒸馏保留或改变了什么；把各种接口都叫作知识压缩，会掩盖最值得设计和检验的差别。

领域数据与动作条件：选择迁移什么

  • MechGPT-Mechanics-and-Materials-教材蒸馏与跨域知识图谱 - 把教材转成问答后以 LoRA 训练学生，是生成数据驱动的蒸馏，而非教师概率分布的 KL 匹配；清洗时删除公式与数值、缺少同基座受控评测，限制了对定量知识迁移的判断，外部构图与检索收益需另计。
  • Shallow-π-Knowledge-Distillation-for-Flow-Based-VLAs-联合减深与选择性蒸馏 - 联合压浅 VLM 与动作头，以速度场 MSE 和 action→VL 注意力 KL 补充任务监督；选择性对齐优于约束全部 token，真机学生优势同时包含延迟降低的闭环收益，长任务能力并未完全保留。

行为与表征：怎样确认发生了迁移

  • Post-Training-Leaves-Behavioral-Shadows-on-Unrelated-Decisions-ATD行为阴影蒸馏 - 在共享祖先的近边界普通词选择上读取教师硬标签，以精确匹配对照验证逐提示配对信息可带来部分任务收益；同源行为迁移、输出函数指纹恢复与任意新知识复制是不同主张。
  • Understanding-On-Policy-Distillation-Swap-Readout与共享特征重加权 - 用 swap readout 减少相近 checkpoint 的 crosscoder 分槽歧义，观察共享特征使用变化，并以双向在线移植检验 warm-up 的部分收益；单层、有限字典与阈值下的零新增检出不能推出 OPD 无法学习新特征。

理论框架

蒸馏是否构成独立于 SFT 和 RL 的"第三范式"？下面的统一框架论文给出否定回答：蒸馏的核心作用是巩固（将昂贵的运行时行为摊入参数），而非压缩——这一视角重新定位了上面所有具体方法的理论角色。

  • LLM-Post-Training-Unified-Off-Policy-On-Policy - 提出轨迹溯源框架，论证蒸馏并非第三范式而是"教师引导的监督接口"；其核心作用是巩固（将昂贵的运行时行为分摊到参数中），而非仅仅压缩（京东科技, 2026）

综合分析

  • Self-Distillation 三部曲 - 从持续学习到推理优化的范式演进 - SDFT/OPSD/SDPO/VC-STaR 统一框架的系统综述与技术比较

监督形式不等于迁移内容

MechGPT 让教材知识通过生成问答进入训练，ATD 则让与目标任务词义无关的选择携带后训练差异。二者共同提醒：监督的信息量不能只按是否出现目标任务文本判断。但 MechGPT 的案例不足以隔离微调净收益，ATD 的同源迁移也没有证明任意新知识可被复制；必须用固定基座、匹配数据与训练预算的对照确认增益来自哪里。

行为收益、计算变化与系统收益需要分层验收

Shallow-π 的真机成功率受到闭环延迟影响；swap readout 的特征频率变化属于特定测量坐标，其双向干预只支持所移植变化承载了部分 warm-up 收益。跨论文可以保留的判断是：输出匹配、内部机制和部署表现需要各自的证据，不能由“学生更好”倒推出更强的新表征，也不能由“未测到新特征”推出能力上限不变。

开放问题

跨论文的未解问题与研究线索。

  • "合谋"而非"博弈"：当前所有自蒸馏方法中教师和学生目标完全一致（单向 KL 模仿）。如果引入对抗目标——例如教师试图生成学生无法区分的 hard negative——是否能突破自蒸馏的性能天花板？OPSD 论文笔记中有详细分析。
  • 长程归因：token 级蒸馏在短推理链（数学、代码）上效果显著，但对需要 100+ step 搜索的任务（定理证明、长程规划），逐 token KL 是否反而限制探索？Prefix-Teach 的可教性衰减现象暗示答案可能是肯定的。
  • 开放域的特权信息来源：OPSD 需要标注答案，SDPO 需要可执行环境，VC-STaR 需要对比样本——在开放域文本生成（创意写作、对话）中，三种特权信息都不存在。LLM-as-Judge 是否足以充当代理特权信息？
  • ICL 能力门槛：SDPO 实验显示自蒸馏收益随模型规模增大而增大，暗示存在最低 ICL 能力门槛。具体阈值是多少？1B 以下模型能否通过 curriculum 设计补偿？
  • 跨 tokenizer 蒸馏：标准蒸馏中教师和学生 tokenizer 不兼容时，token 级 KL 无法直接计算。TRAPO 的梯度裁剪方案是否可推广为通用跨 tokenizer 蒸馏策略？
  • 数据清洗是否删掉了应迁移的知识结构？ 对 MechGPT 式教材蒸馏，固定基座、材料与预算，比较无公式问答和保留经核验公式、单位、条件的问答，分别测概念、条件改写与计算题，并拆开外部检索贡献。
  • 学生超越教师的收益来自哪里？ 对 Shallow-π 匹配推理延迟和重规划频率，再联合离线动作误差、逐任务成功率与长序列退化，区分策略逼近质量和反馈速度；选择性注意力监督还需匹配约束数量与权重。
  • 怎样区分已有能力调动与新知识迁移？ 对 ATD 固定查询及训练预算、匹配祖先关系；对 swap readout 扫描层、字典容量和阈值，并加入已知引入新概念的阳性对照。行为迁移成功与新特征零检出都不足以单独回答这一问题。
