MOC: 测试时训练

当序列中出现 "apple red ... apple ?" 时，attention 靠 KV cache 存住 apple→red 的关联。但上下文超出窗口怎么办？测试时训练 (TTT) 的思路是：在推理时用快速权重一边读 token 一边更新，把 apple→red 这种关联压进参数——模型不再只是"查表"，而是"边读边学"。核心思想是引入快速权重（区别于预训练的慢速权重），用自监督目标在线更新，把上下文信息压缩进参数。

核心笔记

  • In-Place-Test-Time-Training - 本文是该 MOC 的核心笔记：提出原位 TTT，复用预训练 MLP 的 W_down 作为快速权重，配合 NTP 对齐目标和分块并行更新，实现即插即用式 TTT 增强已有 LLM，无需从头重训。

关键概念

TTT 的概念框架围绕三个核心对立展开：(1) 参数的快/慢之分——哪些权重在推理时可以被改写？(2) 学习目标的对齐——快速权重应该记住输入还是预测未来？(3) 架构的侵入程度——TTT 是替换 attention 还是复用已有模块？以下概念贯穿这三条轴线。

  • 快速权重 vs 慢速权重: 慢速权重 = 预训练参数 (frozen); 快速权重 = 推理时动态更新的参数, 在一个 forward pass 内有效
  • 重建目标 vs 语言模型对齐目标: 对语言建模，重建目标让快速权重只记住当前 token（定理 1 证明其对正确 logit 贡献约等于噪声），NTP 对齐目标才能存储预测性关联。但在视觉场景（ViT3），点积（即重建目标）在全 batch + 非因果设定下表现良好——目标的选择是领域依赖的。
  • 即插即用增强: 不改架构, 在已有预训练模型上通过短暂持续训练激活 TTT 能力
  • 分块更新: 把输入分块, 每块更新一次快速权重 (vs 逐 token 更新), 天然支持并行

相关方向

TTT 的快速权重当前在文档边界重置（原位 TTT 第 3.5 节）。若要跨会话持久化——让模型真正在部署中持续适应——灾难性遗忘是核心障碍。SDFT 提供了一种思路：用在线策略自蒸馏（反向 KL）在信任区域内更新参数，避免遗忘。但 SDFT 更新的是全部模型参数而非局部快速权重，两者如何结合尚待探索。

  • 长上下文 LLM: TTT 是扩展上下文窗口的一种思路, 与 RoPE 外推 (YaRN), 稀疏 attention 等方法正交互补
  • 上下文学习: TTT 可视为参数化的上下文学习——把上下文信息压缩进权重而非仅靠 attention 访问
  • 持续学习: 快速权重跨会话持久化涉及灾难性遗忘问题, 见 Self-Distillation_Enables_Continual_Learning
  • 键值记忆: MLP 作为键值记忆 (Geva et al., 2021), 为 W_down 当快速权重提供理论支撑

相关方法

TTT 方法按与 attention 的关系可分为两条路线：(A) 用 TTT 层替换 attention（TTT-Linear, Titans, ViT3），需要从头训练但设计自由度大；(B) 在已有 MLP 上叠加 TTT（原位 TTT, LaCT），可即插即用增强已有 LLM，但受限于现有架构。

(A) 替换 attention 路线

  • TTT-Linear (Sun et al., 2024) -- 原始 TTT, 用线性层替代 attention
  • Titans (Behrouz et al., 2024) -- 基于注意力门的记忆架构
  • ViT3-Unlocking-Test-Time-Training-in-Vision - 系统性地探索 TTT 在视觉序列建模中的设计空间，提出 6 条设计准则并构建 ViT^3 作为纯 TTT 架构的视觉基线，将 TTT 的应用范围从 NLP 扩展到计算机视觉四大任务（分类、检测、分割、生成）

(B) 叠加 MLP 路线

  • In-Place-Test-Time-Training（核心笔记） - 复用预训练 MLP 的 W_down 作为快速权重，NTP 对齐目标 + 分块并行更新，即插即用增强
  • LaCT (Zhang et al., 2025) -- 大块 TTT, SWA 骨干 + TTT 补充

对比洞见

维度 原位 TTT ViT3
TTT 与 attention 的关系 补充（attention 管局部） 替代（TTT 即 token 混合器）
学习目标 NTP 对齐（预测未来 token） 点积（重建当前输入）
分块策略 大块（512-1024），attention 兜底局部 全 batch，视觉非因果
即插即用兼容 是（持续训练） 否（从头训练）

这两组选择不是偶然：NLP 的因果序列要求 NTP 对齐目标和分块因果更新；视觉的非因果空间结构允许全 batch 重建、且没有现成 attention 可以兜底局部交互，必须让 TTT 独立承担 token mixing。领域的因果性决定了目标和分块策略，是否保留 attention 决定了 TTT 的职责边界。

开放问题

  1. 快速权重跨会话持久化：当前快速权重在文档边界重置。若要实现真正的持续适应，如何避免灾难性遗忘？SDFT 的在线策略自蒸馏是候选，但与局部快速权重更新的结合方式未探索。
  2. 深层内模型的优化瓶颈：ViT3 证明加深内模型反而变差（2层78.9 vs 1层79.1），是优化问题而非容量问题。MAML 稳定性技术或专门的内循环优化器可能打破瓶颈。
  3. 内循环优化器的表达力-效率权衡：原位 TTT 的前缀和并行依赖单步 SGD 的加法结合律。更强的优化器（Adam 等）会破坏该性质，但这可能正是深层内模型优化需要的。
  4. 跨领域统一：NLP（NTP 对齐 + 大块 + 补充 attention）和视觉（重建目标 + 全 batch + 替代 attention）的最佳实践完全不同，是否存在统一框架？
