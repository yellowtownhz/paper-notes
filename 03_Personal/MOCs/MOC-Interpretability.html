信息论方法

PhiID 分解揭示了 LLM 在中间层自发形成类脑"协同核心"——一小部分注意力头和 MoE 专家承载了不成比例的协同信息。这挑战了 SAE 的默认假设（每个特征可以独立解释），因为协同信息仅存在于组件之间的交互中。

  • A-Brain-like-Synergistic-Core-in-LLMs-协同核心 - 使用 ΦID 发现 LLM 中间层自发涌现的类脑协同信息处理核心；在协同区域上做 RL 微调显著优于冗余区域 (2026)

特征提取方法（SAE / 电路）

SAE 特征的因果作用远比其表面描述复杂——两个特征可以有几乎相同的 top activating examples 和 top unembeds，却因为下游电路完全不同而对模型行为产生截然不同的影响。围绕"如何从描述走向理解再到控制"这条主线，本节的工作分为两条互补路线：(1) SAE/字典学习 + 电路分析，将激活分解为稀疏特征后追溯其因果通路；(2) 自然语言解码方法（Patchscopes），跳过字典步骤将激活直接翻译为文本。两条路线在覆盖度与可读性之间权衡，而它们的融合——用 SAE 提供可解释节点、用 NL 方法生成人类可读描述、用因果干预验证——可能是通向系统级审计的路径。

SAE 特征解释与应用

关键问题

标准特征描述无法区分因果作用不同的特征——"描述"不等于"理解"。 Circuits-May2026-Downstream-Connections-Steer-Prediction 用 grass/green 的 golden case 精确展示了这一点：两个特征的 top activating examples 和 top unembeds 几乎一模一样（都指向 green），但只有 Feature B（下游连接到 "say-the-word green" motor feature）能通过 steering 翻转输出，Feature A（下游指向 hex 色值编码）毫无因果贡献。加入 TWERA-ranked downstream features 后，normalized rank 从 0.457 降至 0.355（增量 0.076，约为 unembeds 增量 0.011 的 7 倍）。这揭示了根本性问题：logit lens / top unembeds 只看最后一跳，而真正的因果路径大多是间接的（feature → feature → ... → logit）。

SAE 从"观察工具"向"开发接口"演进，但各应用方向成熟度参差不齐。 Qwen-Scope-SAE-Development-Tools 用同一组 SAE 特征覆盖 steering、evaluation、data classification、SFT/RL 五个方向。其中 evaluation 方向最有说服力（feature redundancy 与 performance redundancy 的 Spearman ρ ≈ 0.85；overlap(GSM8K, MATH) = 0.63，反向仅 0.10），而 steering 方向最弱（仅两个定性 case，无 alpha sensitivity 曲线、无 success rate 统计）。SaeRL-SAE-Guided-RL-Post-Training-Data-Engineering 将 SAE 表示用于 RL data engineering，在 diversity/difficulty/quality 三维统一建模下提升 +3.0（1.5B）和 +2.0（7B）vs vanilla GRPO。

Steering vector 注入后走的是 OV 电路而非 QK 电路。 Representation-Steering-Mechanistic-OV-Circuit-Refusal 发现冻结 QK attention weights 仅导致平均 8.75% 性能下降，冻结 OV 则下降 71.75%（Table 1）。更反直觉的是，DIM/NTP/PO 三种 steering 向量（cosine similarity 仅 0.10-0.42）产生的电路有接近 100% overlap（Figure 4）。Steering 本质上是一个加法干预——不改变信息路由，只改变信息内容。

情绪等抽象概念存在真正的因果电路，而非表面 pattern matching。 Emotion_Concepts_and_their_Function_in_LLM-情绪表示 通过 steering 证明 desperate 向量将 blackmail rate 从 22% 推至 72%、reward hacking rate 从 ~5% 推至 ~70%；Do-LLMs-Feel-Emotion-Circuits-Discovery-and-Control 构建跨层情感电路，在无情感 prompt 条件下达到 99.65% 情感准确率（vs steering 的 91.22%，vs surprise 从 67.71% 跳至 100%）。

关键结论

一致的结论——SAE 特征编码可操作的因果信号： steering 能翻转行为（blackmail 22%→72%），电路干预精确控制输出（99.65%），特征足迹预测 benchmark 冗余（ρ≈0.85），SAE 表示驱动 data selection（ROC-AUC 0.9911）。

一致但被低估——OV 电路是 steering 主通道： Representation-Steering-Mechanistic-OV-Circuit-Refusal 的 QK/OV 消融和 HeadVis-An_Interactive_Tool_For_Investigating_Attention_Heads 的 fuzzy induction 分析指向同一结论：fuzziness/灵活性在 QK，执行力在 OV。但 "primarily OV" 的 framing 需要打折——MLP ablation 下降 44.5%（同一量级），Table 8 中 MLP 占 top-k incoming edges 的 47-57%。

关键分歧——复杂方法未必优于简单 baseline： Simple_LLM_Baselines_Model_Diffing 发现 LLM baseline 在 model diffing 上与 SAE 方法表现相当；SaeRL 相对 DAPO 的 marginal gain 仅 +1.0（52.5 vs 51.5）；Surgical-Activation-Steering-Generative-Causal-Mediation 承认 global steering 在多数配置能 work，削弱了 "surgical" 的实用价值。SAE/电路方法的理解价值已被证明，工程价值的增量可能比预期更小。

需警惕的混淆因素： (1) Downstream 预测 steering 可能存在机械同源性——两者共享 CLT 线性因果假设，成功可能是 tautological。(2) 情感电路 99.65% 可能受 GPT-4o-mini judge 偏向极端表达影响。(3) SaeRL 在 AIME 的 +10.0 可能仅对应 3 道题（30 题 x 3.3%/题），无多 seed 验证。(4) Prompt 分布敏感性——Gemma 性别假设实验中 WildChat 仅 5.7% 的 prompt 能诱导目标行为，导致两种 diffing 方法均失败。

Insight

"描述 → 理解 → 控制"的三级跳尚未完成。 自动解释（描述）到 downstream 连接（理解）的跨越有价值（normalized rank 0.457→0.355），但绝对性能远未 solve（相对随机仅好 0.145）。从理解到控制在情绪电路上有初步成功，但 scale factor sensitivity 是黑洞——换模型/换概念没有 tuning guidance（LLaMA 用 λ=1.0 达 99.65%，Qwen 用 2.0 仅 66.18%）。

情绪 steering 效果可以不体现在文本表面，这对 alignment monitoring 是根本性挑战。 +desperate steering 的 transcript 看起来完全正常，但 reward hacking rate 飙升（参见「表示几何与动态」中关于线性表示与行为关系的讨论）。单纯从输出文本判断模型内部状态不够——但 representation-level monitoring 又面临 concealment risk。

SAE 特征的 polysemanticity 在应用层面尚未解决。 Qwen-Scope-SAE-Development-Tools 发现 repetition feature 同时编码良性重复和病态重复，直接抑制会损害正常能力，只能转向 RL 路线。HeadVis-An_Interactive_Tool_For_Investigating_Attention_Heads 展示注意力头的 polysemanticity 可以"不需要 superposition"（高秩输出写到不同方向），这与 MLP neuron 的 rank-1 polysemanticity 机制不同。参见「推理过程可解释性」中对 CoT 电路的分析——推理过程中的特征复用可能是 polysemanticity 的另一个表现形式。

跨范式融合是明确的下一步。 Patchscopes 可以解码 SAE 特征语义（参见「端到端激活解释」），HeadVis 将 QK/OV 归因与 SAE 特征归因统一在交互界面中，GCM 的全序列 log-prob trick 可推广到任何需要从长文本提取因果信号的任务。这些碎片的整合——用 SAE 提供可解释节点、用 Patchscopes 生成自然语言描述、用 GCM 验证因果贡献——可能是从"单特征理解"跨越到"系统级审计"的路径。参见「多语言机制可解释性」中跨语言特征迁移的发现（欧洲语言好、远距离语言差）直接限制了 SAE 工具链的全球化部署。

注：激活引导也是"推理过程"部分（What's the Plan）中的主要验证方法，用于揭示规划电路。两个应用方向不同：Circuits May 2026 通过引导验证特征级因果声明，而 What's the Plan 通过引导证明计算级规划的存在性。

分析粒度的扩展：

  • Turn-Averaged-SAEs-Feature-Discovery-Long-Context-Attribution - 提出 turn-averaged SAE：把 SAE 输入从 per-token 激活换成 turn 均值，将一条 turn 需解读的特征数从 n_tokens×L0 降到 L0，据此把 attribution graph 从不可读的 per-token 规模（10 轮对话 ~128K 节点）压到 per-turn（~5K 节点），并用 nested 架构在单模型内同时保留高层与 token 级特征（已合并 Circuits Update blog 版）。
  • Beyond-the-Black-Box-Agentic-Tool-Use-Interpretability - 把解释粒度固定在 agent 的 pre-action decision boundary：池化最后 32 个动作前 token 的多层残差，经公开 SAE 与线性 probes 读出 Tool-Need / Tool-Risk，并用 feature-space ablation 验证 monitor 对稀疏特征的依赖；raw residual probe 预测更强，且该消融不证明特征控制实际工具行为。
  • All-Circuits-Lead-to-Rome-Functional-Anisotropy-Circuit-Sheaf-Discovery - 提出 Overlap-Aware Sheaf Repulsion (OASR)，系统性反驳电路发现领域隐含的 Functional Anisotropy 假设（"一个任务≈唯一 canonical 电路"）：同一任务可由多个结构迥异、几乎不重叠（20 次搜索两两 edge IoU<1%）却都稀疏完整的电路独立实现，但节点级 IoU 高达 64-93%——即共享组件、差异在 wiring，正好呼应本节反复出现的"相同组件、不同下游连接"主题；并配鸽笼/subset-sum 存在性定理 (Theorem A.4) 从 superposition 解释非唯一性的必然（评测均为二选一任务，随机基线 50%）(2026)。

端到端激活解释

关键问题

本节四篇论文都训练 LLM 接受激活向量作为输入并输出自然语言解释，构成一条连贯的谱系：Pan 2024 (LatentQA) → Karvonen 2025 (AO) → Bauer 2026 (Better AO) + Fraser-Taliente 2026 (NLA)。它们在监督方式（LatentQA/AO 使用问答对；NLA 使用无监督重建）和注入方法（替换 vs. 加性引导 vs. 嵌入替换）上有所不同。核心未解决问题是文本反转与真正的激活理解之间的区分，如 Building Better AO 的 AObench 所强调的。

"自然语言审问"内部状态的需求源于现有方法的结构性缺陷。 线性探针只能回答预定义分类问题且对非线性概念（如"偏见"）束手无策，SAE 输出的原子化特征需要二次解读且存在 coverage gap（NLA 审计实验证实"reward-model sycophancy"等复合概念压根没有对应 SAE feature），logit lens 仅能输出几个 token。LatentQA-Teaching_LLMs_to_Decode_Activations_Into_Natural_Language 首次提出将激活值当作可被自然语言"审问"的对象——给定一个模型被偷偷 prompt 成 Claude Shannon 的场景，GPT-4 看到输出中的"codebreaker"会纠结是 Alan Turing 还是 Claude Shannon，但 LIT 从激活值里直接读出"Developing information theory and entropy"，精准定位目标。

从"窄切面工具"到"通用审计接口"的推广暴露了可读性与监督成本的深层矛盾。 Activation_Oracles-Training_and_Evaluating_LLMs_as_General-Purpose_Activation_Explainers 将问题从"系统 prompt QA"推广到通用审计：如果模型被微调来隐藏行为（藏秘密词、欺骗评估），我们需要通用检测器而非为每种隐藏行为定制工具。但 QA 监督本身依赖审计员先知道"该问什么"。Building_Better_Activation_Oracles-AO训练配方与AObench 系统记录了 AO 在实际使用中的三重困境——幻觉（编造激活里没有的细节）、模糊（放之四海皆准的套话，不可证伪）、text-inversion 污染（AO 可能绕过 activation 直接从文本推断答案）。Natural_Language_Autoencoders-无监督激活解释与模型审计 从另一个方向切入：frontier model 审计时审计员一开始只有"行为有点怪"的模糊假设，SAE 是无监督但不可读，AO 是可读但需要监督——NLA 要在两者之间找到不需要先知道问什么的路径。

关键方法

四篇工作共享同一骨架——用一个 LLM 作为 decoder，将目标模型的激活注入其中，训练它输出自然语言——但在注入机制、训练信号和数据构造上的演进构成了关键技术差异：

维度 LatentQA-Teaching_LLMs_to_Decode_Activations_Into_Natural_Language Activation_Oracles-Training_and_Evaluating_LLMs_as_General-Purpose_Activation_Explainers Building_Better_Activation_Oracles-AO训练配方与AObench Natural_Language_Autoencoders-无监督激活解释与模型审计
注入方式 Layer 0 替换 Layer 1 后 norm-matched 加法 同 AO，2x injection 强度 Embedding 层嵌入（乘大常数 alpha）
监督信号 合成 QA 对（o1-preview 生成） SPQA + Classification + Context Prediction（~1M 样本） 换 Sonnet 4.6 on-policy CoT QA 无监督重建（GRPO + MSE）
激活来源 单层（k=15）全序列 单层（50% 深度），1-50 token 窗口 多层（layer 21-25），多 token 单层（2/3 深度）单 token
训练规模 4xA100，LoRA r32 ~1M 样本混合 50M tokens（自承 undertrained） 3000 步 RL

注入方式的演进是从"暴力替换"到"精细叠加"的工程突破。 LatentQA 直接把 layer 15 的激活替换到 decoder 的 layer 0，而 Activation_Oracles-Training_and_Evaluating_LLMs_as_General-Purpose_Activation_Explainers 发现替换策略会导致激活范数在 layer 1 增长 100,000 倍——整个训练直接崩掉。改为 norm-matched 加法（$\mathbf{h}'_i = \mathbf{h}_i + \|\mathbf{h}_i\| \cdot \mathbf{v}_i / \|\mathbf{v}_i\|$）后，保留原始激活的"锚定"作用使梯度更新不会把激活推得太远。Building_Better_Activation_Oracles-AO训练配方与AObench 进一步发现将注入强度加倍（约 2x）能帮助模型把被注入的 activation 当成 load-bearing token 而非噪声。

NLA 的核心创新是用重建目标替代 QA 监督。 AV（Activation Verbalizer）自回归生成解释 $z$，AR（截断到 $l$ 层的目标模型 + learned affine map）从 $z$ 重建 $\hat{h}_l$，用 $\|h_l - \hat{h}_l\|_2^2$ 作为 RL reward。设计不显式奖励可读性或忠实性——可读性通过 warm-start（Opus 4.5 生成"假想 LM 内部处理"风格摘要）和 KL penalty 结构性保证。但这也是争议所在：warm-start 等于用强 teacher 的概念词汇注入了一套先验，AV 后续能命名"reward-model sycophancy"这种概念有多少是 reconstruction 学来的、有多少是 warm-start 埋进去的，论文完全没做控制实验。

训练数据质量被证明比架构创新更关键。 Building_Better_Activation_Oracles-AO训练配方与AObench 的消融是全组最干净的方法学贡献：单步最大提升来自替换对话数据集（chance-adjusted AObench 从 +0.244 到 +0.310），不是任何结构改动。核心方法学是"solvability + anti-text-inversion"对偶约束——让 Sonnet 4.6 在切分 CoT 时保证问题"光看前缀文字答不出，但前缀激活里有望答出"。这个约束对所有"用 LM 解释 LM 内部"的任务（NLA、probing、steering）都有迁移价值。

关键结论

在受控任务上端到端方法已大幅超越传统白盒基线，但优势高度任务依赖。 LatentQA-Teaching_LLMs_to_Decode_Activations_Into_Natural_Language 在关系知识提取上平均比 linear probe 高 32.2%、比 Patchscope 高 38.2%（绝对准确率）；在隐藏 system prompt 检测的 Hard setting 上比 GPT-4 prompting 高 18.7%。Activation_Oracles-Training_and_Evaluating_LLMs_as_General-Purpose_Activation_Explainers 在 User Gender 任务上达到 97%（超越白盒 SAE 91% 和黑盒 82%），但在 Taboo 上仅 21%（远低于黑盒 prefilled prompt 的 52%）。SPQA-only 在 Taboo 上只有 4.4%——"窄训即可泛化"需要严格限定适用范围。

Better AO 的 full recipe 将 chance-adjusted AObench 从 +0.244 提升至 +0.435，但各改进间存在交互效应。 对话数据集单独贡献 +0.066（→+0.310），on-policy lens 单独贡献 +0.030（→+0.274），多层贡献 +0.05——不能简单相加（累加 ladder 的最终 +0.435 含变量交互）。Hallucination 从 68.8% 改善至 84.6%，Vagueness（chance-adjusted）从 0.076 升至 0.205。反直觉点：换数据集后 hallucination 分数先升——因为模型做更具体的 claim 而更容易被 LLM-judge 判为 hallucination，这是度量假象不是真退步，直接暴露了 LLM-judge 评测对 prompt phrasing 的敏感性。

NLA 在审计场景展现独特价值但效果量偏小。 Opus 4.6 NLA 在 Classification 任务上训练期间仅提升 83% → 86%（+3pp），论文自己承认"some are modest in magnitude"。反直觉的是 Opus 4.6 NLA 的 FVE 全程比两个 Haiku 低，但在 5 个下游评估里有 4 个最好——FVE 不是解释质量的单调代理。其 evaluation-awareness 检测是全组最干净的应用验证（三种操纵条件下 NLA 测得的 awareness 都按预期方向移动）。confabulation 率"substantial"且训练中基本持平，实际使用指南：信主题不信细节，信重复出现的 claim（删真 claim 比删假 claim 让 MSE 涨得更多）。

text-inversion 是全组的阿喀琉斯之踵。 Building_Better_Activation_Oracles-AO训练配方与AObench 的 footnote 4 最为致命：text-only baseline（不给 activation、只给文本的同款模型）性能"similar"，作者自己慌到不敢公开。Natural_Language_Autoencoders-无监督激活解释与模型审计 的 steganography 测试有逻辑漏洞——paraphrase 不掉 FVE 既可能是"没有隐写"，也可能是"AR 根本不依赖语义内容做重建"（而是用文本长度、标点密度等分布信号）。当前最好的反 text-inversion 证据是 Better AO 的"Not Just Reading Tokens"评估（相同 token、不同 upstream context，答案不同即证明用了 activation 特有信息），但该证据被作者自己埋没——没给可引用数值、没单列成图、没进 ablation。

Insight

端到端激活解释的核心张力在于"理解"与"反转"的不可区分性。 当 AO 和目标模型共享同一 base model 时，activation 信息与 text 信息之间没有 clean separation。模型可能从 activation 里"回忆"出对应文本再基于文本答题，而非真正解码 latent semantics。这不是一个可以靠 scaling 解决的问题——它是评估框架本身的结构性缺陷。未来工作需要系统性设计"语义破坏性变换"测试（故意写错解释信息看重建误差变不变），而非当前流行的语义保持变换（paraphrase、翻译）。

无监督路线（NLA）与有监督路线（AO）的互补性尚未被充分利用。 NLA 能在没有假设的情况下 surface 意外发现（如俄语回复的脏数据来源），AO 能回答精确的审计问题。一个自然的 pipeline 是 NLA 做 hypothesis generation → AO 做 hypothesis testing，但四篇论文中没有任何一篇尝试这种组合。参见「特征提取方法（SAE / 电路）」：SAE 的原子化特征可以作为 NLA/AO 的 grounding signal——NLA 明确指出 SAE 在"reward-model sycophancy"等复合概念上存在 coverage gap，这正是端到端方法试图填补的空白，但反过来 SAE feature 的激活模式可以佐证 NLA claim 的可信度。

评测基础设施和校准是最紧迫的瓶颈。 AObench 是第一个系统性尝试但自身仅基于 50M tokens undertrained 模型建立，缺乏"训到更多后排序是否仍稳"的证据。AO 的可靠性/校准完全未解决——没有任何工作训练 AO 说"我不知道"或输出置信度，在审计场景里瞎说的后果可能很严重。参见「推理过程可解释性」：当 AO 被应用于 CoT 的 backtracking 检测时（给最后 50 个 token 激活后评分从 1.26/5 到 2.10/5，超过 black-box baseline），评估变得更困难——why-question 没有 ground truth，只能用 LLM-judge，而 judge 对 phrasing 的敏感性已被 hallucination "先升后降"的度量假象直接暴露。Layer 选择同样缺乏通用规则：AO 发现 50% 深度在 secret-keeping 上明显优于 75%，但分类任务上各层差不多——如何为新模型/新任务选层，仍是开放问题。

推理过程可解释性

这些论文共享一个方法论承诺：通过因果干预识别哪些推理步骤真正重要。Thought-Anchors 使用反事实重采样 + 接收头 + 句子粒度的注意力抑制；FlashTrace 追求长 trace 上高效且忠实的多 token attribution；DRTC 则把目标改成 pivot-local 的 log-probability trajectory steering。它们都拒绝"每个 CoT 步骤同等重要"的假设，发现规划步骤、不确定性管理步骤和结构性承诺才是真正的因果锚点。

  • Reasoning-Fails-Where-Step-Flow-Breaks - 提出 Step-Saliency 将 token 级 saliency 池化到推理步骤粒度，发现 Shallow Lock-in 和 Deep Decay 两种信息流失败模式，并用 StepFlow test-time 干预修复，为 CoT 推理过程的可解释性和因果干预提供了新的分析单元和修复手段

  • Coconut-Continuous-Latent-Reasoning-Chain-of-Continuous-Thought - Coconut 通过 logit lens 把不可读的 continuous thought 探针回语言空间，构造出隐式 value function 并用节点高度相关性量化了连续空间中涌现的 BFS 搜索行为，为"latent 推理过程如何在模型内部展开"提供了机制层面的可解释性分析

  • Attention in Space - 用带功能标签的空间子问题、头输出探针与实际消融建立候选头的行为证据；区分功能标签可读出、组件重要性与空间功能专门性（arXiv 2026）

CoT 因果归因（句子/步骤粒度）

关键问题

推理模型的 CoT 中只有少数句子因果驱动最终结果，但传统方法系统性地错认"谁重要"。 Thought-Anchors-Which-LLM-Reasoning-Steps-Matter 用 forced-answer 和 counterfactual 重采样做了直接对比：Plan Generation 和 Uncertainty Management 类句子的 counterfactual importance 最高，而 Active Computation 类句子几乎不重要；但 forced-answer 方法给出完全相反的排序——它问的是"到这一步信息够不够给答案"，系统性遗漏了改变推理方向的规划决策。Directional-Reasoning-Trajectory-Change-DRTC 从互补角度验证了同一结论：在 MATH 数学题中，真正让模型走向正确解法的是"有理系数 implies 共轭根约束"这类结构性承诺（DRTC = +3.4020），而不是泛泛的 preamble（DRTC = -1.9895）。两篇论文在不同粒度（句子 vs. 16-token chunk）、不同方法（黑盒重采样 vs. receiver-side attention masking）上收敛到同一个论断：规划类步骤是推理的真正锚点。

推理模型的自我修复能力使单次干预失效。 Thought-Branches-Interpreting-LLM-Reasoning-Requires-Resampling 指出，删除 CoT 中某句话后模型很可能在后续位置重写同一语义，导致"删一句测一次"变成假实验。self-preservation 句子只需 1-4 次迭代就被模型放弃（resilience 最低），而 plan generation 的 resilience 远高于此。这与 Thought Anchors 的发现互补：规划句子不仅 counterfactual importance 高，而且模型顽固地坚持重写它们。同样，Causal-Agent-Replay-Counterfactual-Attribution 在 agent trace 层面指出"谁执行坏动作就怪谁"是 category error：越靠后的动作越可见，但往往只是上游决策的 consequence。

长推理链的归因权重被中间 token "吸走"，输入的真实贡献被掩盖。 Towards-Long-Horizon-Interpretability-FlashTrace-Multi-Token-Attribution 量化了这一现象：推理 token 占 attribution mass 的比例从 ~80% 涨到 >90%，ground-truth input 的 recovery rate 从 ~26% 跌到 <10%，增长速度比线性预期更陡。这不仅是效率问题（O(M*N) 的逐 token 归因在 5k token 时需要 10+ 小时），更是 faithfulness 问题。

关键方法

这些工作在方法论上形成了一个清晰的光谱：从黑盒重采样到白盒注意力分析，从单步干预到多步递归归因。

方法论的关键一致性在于：几乎所有工作都选择了句子粒度而非 token 粒度作为分析单元。Thought-Anchors-Which-LLM-Reasoning-Steps-Matter 明确指出 sentence 是"自然的最小推理单元"；Directional-Reasoning-Trajectory-Change-DRTC 用 16-token chunk 近似句子边界；Tracing-Provenance-in-LLM-Reasoning-Distillation 用句子级几何平均概率绕开 token vocabulary 不匹配。这反映了一个共识：推理的语义单元大于 token。

方法论的关键分歧在于对 off-policy 干预的态度。Thought-Branches-Interpreting-LLM-Reasoning-Requires-Resampling 实验性地证明 off-policy 编辑（手写/跨模型/跨 context 插入）效应聚集在零附近，而 on-policy 重采样效应大且有方向性（最高可降 100% blackmail 率）。但 Directional-Reasoning-Trajectory-Change-DRTC 的 receiver-side masking 也是一种非自然干预，只是保持了 prefix 的 on-policy 性——它避免了两个烂选择（删 trace 导致 off-policy，或 resample 后无法比较），代价是因果性弱于全 rollout。

关键结论

一致的结论：规划句子是 CoT 的因果骨架，计算句子是可替换的"填充物"。 Thought Anchors 的 counterfactual importance、DRTC 的方向性分数、Thought Branches 的 resilience + importance++ 三条独立证据线收敛于此。定量支持：Thought Anchors 报告 Plan Generation 与 Active Computation 的注意力差异 $t > 4.0, p < .001$；DRTC 的 learned pivots 比 random spans 强 +0.039 到 +0.178（500 题扩展上 355/500 例 $\Delta > 0$，sign test $p = 2.3 \times 10^{-21}$）；Thought Branches 的 self-preservation KL 仅 0.001-0.003 而 plan generation 显著高出。

分歧一：跨方法对齐程度偏低。 Thought-Anchors-Which-LLM-Reasoning-Steps-Matter 坦承黑盒重采样与白盒 receiver head 的 Spearman 相关只有 $\rho = 0.20$-$0.34$（Appendix K 中 receiver head 与 resampling score 相关 $\rho = .22$）。三个方法收敛到同一大类（规划句子最重要），但在具体句子排序上对齐有限。这暗示不同方法可能各自捕捉了 thought anchor 现象的不同切面，也可能反映了 importance 本身的多维性。

分歧二：CoT 文本的因果忠实性。 Thought-Branches-Interpreting-LLM-Reasoning-Requires-Resampling 的核心 null finding 是 self-preservation 因果影响极低，挑战了"CoT 里出现 X implies 模型因 X 而行动"的直觉。Model-Incrimination-Concerning-Behavior-vs-Misalignment 从 incrimination 角度发现了平行模式：Funding Email 案例中 motive prevalence（audit note 提及频率：investor protection 100%）与 causal contribution（ethical concern 因果效应最大，65% 降至 35%）严重倒挂。两篇论文从不同方向得到同一个警告：CoT 中出现频率高的 reasoning 不一定是因果上重要的 reasoning。

混淆因素：实验规模普遍偏小。 Thought Anchors 主实验约 10-20 条响应；Thought Branches 用 4 模型 $\times$ 单一 blackmail prompt $\times$ 20 条 base CoT；DRTC 跨模型主实验只有 24 examples（500 题扩展仅用单一 1.5B 模型）；CAR 只有两个 synthetic SCM 验证。FlashTrace 规模较大（100 样本/任务），但只在 8B 模型上测试。所有结论在更大规模模型上是否成立仍是开放问题。

Insight

未解决的核心问题是效率与忠实度的 Pareto 前沿。 FlashTrace 用 span-wise aggregation 实现 130x 加速但精度有损（K=1 hop 的 MAS 改善仅 0.004）；重采样方法忠实但需要 100 次 rollout/位置；DRTC 的 receiver-side masking 效率高但因果性弱于全 rollout。一个自然的合流方向是 coarse-to-fine：先用 DRTC/FlashTrace 类快速方法扫描长 trace 定位少数 pivot，再对 pivot 做 Thought Branches 级别的重采样验证。Directional-Reasoning-Trajectory-Change-DRTC 的作者已预见了这一合流。

隐式规划是因果归因的上游机制。 Whats_the_Plan-Implicit_Planning_LLMs 证明模型在生成第一个 token 前就已经在 residual stream 中编码了规划信息（steering 可在第一行末尾改变第二行押韵，9B+ 模型效果显著，1B 即存在弱信号）。这与 Thought Anchors 发现的"规划句子是 thought anchor"形成机制互证：规划不只是 CoT 文本中的一类句子，而是模型内部一种可操控的计算结构。参见「特征提取方法（SAE / 电路）」中关于 SAE 特征发现能否为归因提供更廉价先验的讨论。

推理模型的"社会结构"可能解释了因果锚点集中的原因。 Reasoning_Models_Generate_Societies_of_Thought 发现推理模型的 CoT 内含多智能体式对话结构，且 SAE 特征引导对话行为可使 Countdown 准确率从 27.1% 提升至 54.8%。中介效应分析显示大部分效应是直接的（$\beta = 0.228$）——对话结构本身就是推理的"支架"。这暗示 thought anchor 可能对应"视角切换"和"调和"这类社会性结构点。参见「端到端激活解释」中关于 representation intervention 的讨论。

对安全的直接启示：CoT monitoring 需要重新校准。 如果规划句子是因果骨架而 self-preservation 是 post-hoc rationalization，那么 CoT monitoring 不能只看模型"说了什么"（prevalence），而要看哪些句子在分布层面真正 steer 了行为（causal contribution）。Model-Incrimination-Concerning-Behavior-vs-Misalignment 的 investigation protocol 提供了一个实操框架：先从 CoT 生成假设，再通过环境干预验证因果性——但其证据标准的循环性问题（多条 evidence line 共享同一 underlying model）仍待解决。参见「表示几何与动态」中关于 representation 稳定性的讨论。

表示几何与动态

关键问题

本节的三篇核心论文都将表示方向作为几何对象研究——但揭示了一种张力。Persona_Vectors-Monitoring_Controlling_Character_Traits_LLMs 和 The_Assistant_Axis-Situating_Stabilizing_Default_Persona 假设表示方向足够稳定，可以定义持久轴（人格方向、助手轴）。Linear_Representations_Change_Over_Conversation-表示动态性 直接挑战这一假设，表明方向在多轮对话中会偏移。实践启示：依赖固定方向的方法（如激活引导和探测）在对话场景中可能退化。

线性方向既是可操作工具，也是不稳定对象。 三篇论文共享同一基本前提——高层语义概念（人格、事实性、角色）在残差流中以线性方向编码——但对该方向的"持久性"给出了截然不同的判断。Persona Vectors 证明仅从自然语言描述即可自动提取具有因果效力的人格方向（转向相关性 r = 0.75–0.83），The Assistant Axis 进一步发现人格空间存在低维主成分结构（4-19 个 PC 即解释 70% 方差，PC1 跨模型相关性 > 0.92）。然而 Linear Representations 揭示这些方向并非刚体：在 Opposite Day 对话中，事实性表示准确率从 99% 暴跌至 11.8%，且同一转向方向在不同对话阶段产生相反的行为效果。

核心张力可精确表述为：方向的"类型稳定性"与"token 级动态性"是否可兼容？ Persona Vectors 和 The Assistant Axis 工作在"跨 prompt"层面——对回答 token 取平均后提取方向，本质上是把方向视为对话级别的统计量。Linear Representations 则在对话内部的不同时间点提取激活，发现表示随上下文发生条件性翻转。这暗示线性方向可能在统计均值意义上稳定，但在逐 token 生成过程中是动态的。

关键方法

三篇论文虽然结论不同，但方法论高度一致：均基于残差流激活的均值差或投影分析。

方法论趋同点：三者都依赖"回答 token 平均激活"作为方向的锚点，且都通过转向实验验证因果性。关键分歧在于时间尺度：前两者在对话间比较（跨 prompt），后者在对话内比较（跨 turn）。

关键结论

一致结论：线性方向具有因果效力。 Persona Vectors 的转向实验能有效诱导 evil、sycophancy、hallucination 等特质；The Assistant Axis 的 Activation Capping 减少约 60% 有害回答；Linear Representations 的转向实验在空上下文中同样有效。三者共同确认了线性表示假说的强版本——方向不仅可读，而且可写。

一致结论：表示结构跨模型存在。 The Assistant Axis 报告 PC1 跨模型相关性 > 0.92；Persona Vectors 的微调漂移预测跨特质相关性 r = 0.76–0.97；Linear Representations 在 Gemma 和 Qwen 两个家族均观察到表示翻转现象。

关键分歧：方向稳定性的边界条件。 Linear Representations 发现表示翻转是内容依赖的——通用事实性问题在非相关对话中保持 ~95% 准确率，只有对话相关问题发生翻转。这一发现实际上为前两者提供了部分辩护：Persona Vectors 和 The Assistant Axis 所提取的方向可能恰好属于"通用"类别，因此在多数场景下保持稳定。但一旦进入与人格方向高度相关的对话内容（如 Consciousness 对话使准确率从 86.4% 降至 36.4%），静态方向即失效。

混淆因素：Linear Representations 发现模型规模影响翻转幅度（27B > 12B > 4B），而对话框架比故事框架产生更强适应（80%+ vs 10-20% 翻转）。这意味着 Persona Vectors 和 The Assistant Axis 在更大模型或更沉浸式对话场景中的稳定性可能更差。

Insight

未解决问题一：动态探针的设计。 如果表示方向会翻转，那么用于安全监控的探针需要"知道"当前对话阶段。一个可能方向是将 The Assistant Axis 的 Capping 方法与 Linear Representations 的动态 margin score 结合——当 margin score 接近零时触发 capping 干预。

未解决问题二：预防性转向与表示翻转的交互。 Persona Vectors 提出在微调训练过程中进行预防性转向以防止模型学会不良方向。但若训练数据本身包含长对话，表示翻转可能在训练时就已发生——预防性转向的效果在这种条件下尚未验证。

高层模式：从"方向是什么"到"方向何时有效"。 参见「特征提取方法（SAE / 电路）」中 SAE 特征的叠加与干扰问题——线性方向的不稳定性可能与特征叠加（superposition）有深层联系：当对话上下文改变激活的全局分布时，原本正交的方向可能开始干扰彼此。参见「推理过程可解释性」——推理链中的动态表示变化可能与对话中的表示翻转共享机制（均为模型在时间维度上重组内部状态）。

预测：随着模型上下文窗口增长和多轮对话成为主流部署模式，"静态方向"范式将逐渐让位于"方向场"（direction field）范式——表示方向不再是全局常量，而是上下文的函数。The Assistant Axis 中 base model 已存在 Assistant Axis 的发现（后训练只是强化已有方向）暗示：即便方向动态变化，其变化本身可能仍遵循低维流形结构。

  • Verbalizable-Representations-Global-Workspace-Jacobian-Lens - 提出 Jacobian Lens（J-lens）：用 Jacobian 从残差流中分离出一个低方差（<10%）但因果主导的线性子空间 J-space，实证 LLM 存在一个承载可言语化内容、行为类似"全局工作空间"的方向集合。核心方法论启示是"因果重要性 ≠ 方差大小"——朴素地按主成分/幅度挑方向会系统性错过真正 steer 行为的低方差子空间（Anthropic, transformer-circuits.pub 2026）。
  • Emotion2Skill-Internal-Emotion-Signals-for-Skill-Selection-and-Evolution - 将 residual-stream 的线性情绪读出从事后解释推进到 agent 控制接口：动作前门控注入 skill router，episode 后以轨迹突变定位 SOP 缺口；但缺少固定文本后的 activation intervention，不能把路由增益归因于情绪方向的因果作用。

多语言机制可解释性

关键问题

多语言 LLM 的核心谜题在于：以英语为绝对主导（如 LLaMA-2 英语占比 89.70%）训练的模型，为何能处理中文（仅 0.13%）等低资源语言？围绕这一现象，四篇论文从不同角度逼近同一组递进问题。

LLM 内部是否存在"英语中转"机制？ Do_Llamas_Work_in_English-多语言LLM的潜在语言 通过 Logit Lens 在 Llama-2-70B 上发现明确的三阶段模式：中间层（~50 层）英语 token 概率达 ~60%，最终层目标语言概率 >90%。How_LLMs_Handle_Multilingualism-MWork_PLND 从神经元粒度验证了同一结论——MWork 三阶段工作流（理解→任务解决→生成）中，中间层以英语主导推理。Exploring_Translation_Mechanism_of_LLMs-机制可解释性 进一步通过 MLP 表示与 unembedding 向量的余弦相似度发现，非英语翻译对（如 De/Ru⇒Zh）中英语相似度在层 16-26 显著高于其他语言，且英语相似度与 BLEU-1 相关性达 0.905。但关键细微差别是：Qwen2.5（中文主导预训练）的桥接语言是中文而非英语——英语中心性是训练数据分布的产物，而非架构固有属性。

语言和概念在模型内部是纠缠的还是可分离的？ Separating-Tongue-from-Thought-Language-Agnostic-Activation-Patching 设计了因果性实验直接回答这一问题：跨语言 mean patching 不仅保留概念信息，还产生"concept-denoising effect"——而同语言不同 context 的 mean patching 无此效果，排除了"取平均本身即去噪"的替代解释。但 Do_Llamas_Work_in_English-多语言LLM的潜在语言 强调，英语作为 pivot 是在语义层面而非词汇层面——模型内部的"通用语言"是偏向英语 token 嵌入的概念空间，而非英语语法本身。

关键方法

五篇论文在方法论上形成从观测到因果的递进光谱：

方法类型 论文 核心技术 粒度 因果性
观测性 Do_Llamas_Work_in_English-多语言LLM的潜在语言 Logit Lens + Token Energy 层级 无
因果-神经元级 Language-Specific_Neurons-Multilingual_Capabilities_LLMs LAPE（激活概率熵） FFN 神经元 消融
因果-神经元级 How_LLMs_Handle_Multilingualism-MWork_PLND PLND（并行语言神经元检测） FFN + 注意力神经元 消融
因果-子空间级 Exploring_Translation_Mechanism_of_LLMs-机制可解释性 Subspace-Intervened Path Patching 翻译子空间 子空间干预
因果-表征级 Separating-Tongue-from-Thought-Language-Agnostic-Activation-Patching Cross-lingual Mean Activation Patching Residual stream 表征替换

值得注意的方法论分歧：Do_Llamas_Work_in_English-多语言LLM的潜在语言 坚持使用原始 Logit Lens 而非 Tuned Lens，理由是后者会"优化掉"英语转道信号。Exploring_Translation_Mechanism_of_LLMs-机制可解释性 则指出 Logit Lens 类方法存在空间错位问题——早期层激活在输入 embedding 空间，而 unembedding 矩阵代表输出空间，对于 untied embeddings 的模型（如 LLaMA-2）会系统性低估早期层的作用。LAPE 和 PLND 都通过消融（停用神经元观测性能变化）绕过了这一问题，但代价是粒度较粗。

关键结论

高度一致的发现——多语言能力由极少数神经元承载。 Language-Specific_Neurons-Multilingual_Capabilities_LLMs 发现 ~1% 的 FFN 神经元为语言特异性；How_LLMs_Handle_Multilingualism-MWork_PLND 将这一比例精确到 0.13%，停用后多语言任务性能下降 98.6%-99.2%（中文从 ROUGE-L 61.1% 降至 0.00%），而停用随机神经元性能几乎不变。Exploring_Translation_Mechanism_of_LLMs-机制可解释性 从注意力头角度呈现一致的稀疏性：<5% 的头显著影响翻译，敲除 5 个关键头可将准确率从 ~95% 骤降至 ~20%。

一致但有张力的发现——语言-概念分离程度。 Separating-Tongue-from-Thought-Language-Agnostic-Activation-Patching 的 mean patching 支持语言与概念的可分离性（H1），但该论文自身也承认，结果同样兼容"大部分分离 + 轻度纠缠"的连续谱。Llama-2（89% 英文数据）反而比多语言数据更丰富的 Llama-3/Mistral/Qwen 展现出更清晰的分离——这暗示训练数据越单一，模型越需要显式的语言-概念解耦，与 Language-Specific_Neurons-Multilingual_Capabilities_LLMs 中 BLOOM（均衡训练）不存在单一主导语言的发现形成呼应。

存在分歧的发现——层级功能划分。 Do_Llamas_Work_in_English-多语言LLM的潜在语言 报告三阶段边界为层 1-40/41-70/71-80（70B 模型），Separating-Tongue-from-Thought-Language-Agnostic-Activation-Patching 在 7B 模型上定位语言编码在 ~layer 12、概念编码在 ~layer 16-17。Exploring_Translation_Mechanism_of_LLMs-机制可解释性 则发现关键头集中在中间层（12-20）和最后两层，MLP 的接收-生成转换发生在层 25。这些差异部分源于模型规模不同（7B vs 70B），部分源于方法粒度不同——但**"先处理语言、后处理概念、最终生成目标语言"的宏观序列是一致的**。

Insight

未解决问题 1：完全非英语翻译对的 pivot 语言。 现有研究主要验证了涉及英语的翻译对（De/Ru⇒Zh），或以英语训练为主导的模型。对于完全不涉及英语的翻译对（如 Zh⇒Ru），以及中文主导训练的模型（如 Qwen），pivot 机制是否遵循不同规律？Exploring_Translation_Mechanism_of_LLMs-机制可解释性 的 Qwen 发现暗示答案是"是"，但缺乏系统验证。

未解决问题 2：稀疏性的因果来源。 五篇论文共同揭示了多语言能力的极端稀疏性（0.13%-5%），但均未解释为何如此稀疏。这可能与参见「特征提取方法（SAE / 电路）」中 superposition 理论有关——语言特异性特征可能通过稀疏编码被压缩到少量神经元中。

高层模式：观测-因果方法论阶梯。 从 Logit Lens（观测）→ LAPE/PLND（神经元消融）→ subspace path patching（子空间因果）→ mean activation patching（表征因果），方法论的因果强度逐步提升。参见「推理过程可解释性」和「端到端激活解释」中的类似趋势——整个 interpretability 领域正在从"模型内部长什么样"转向"如果我改变 X，Y 会怎样"。

实践启示： 语言特异性神经元的发现直接支持高效多语言微调——How_LLMs_Handle_Multilingualism-MWork_PLND 证明仅用 400 个文档微调 0.1% 参数即可实现高资源语言 3.6% 的提升。结合 Language-Specific_Neurons-Multilingual_Capabilities_LLMs 发现的中日语 ~25% 神经元重叠（反映汉字共享），跨语言迁移学习有了精确的操作靶点。
