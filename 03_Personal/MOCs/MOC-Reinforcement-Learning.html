强化学习研究地图

本 MOC 涵盖"在 LLM 后训练中应用强化学习"这一研究线上的所有论文。 核心范式：通过奖励信号或专家引导来优化模型行为。

策略优化

这组论文共享一个核心张力：标准 GRPO/PPO 的 episode-level sparse reward 信息量不足，但直接引入外部密集信号（SFT loss、teacher logprob、环境反馈）又会破坏 on-policy 训练的稳定性。每篇论文提出不同的"注入密集信号而不崩溃"的机制——TRAPO 用梯度裁剪驯服 SFT、SDPO 用 self-teacher 回避外部依赖、On-Policy Distillation 用 reverse KL 替代 forward KL。

  • Trust-Region-Adaptive-Policy-Optimization-TRAPO - 提出 TRAPO 框架，通过 TrSFT 梯度裁剪和自适应 prefix 引导，在 instance 级别融合 SFT 和 RL
  • Policy_Gradient_with_Adaptive_Entropy_Annealing-aEPG - 自适应熵退火策略，平衡探索与利用（2025）
  • Reinforcement_Learning_via_Self-Distillation-SDPO - SDPO，以环境反馈为条件的教师模型，突破 RLVR 信息瓶颈（ETH+MIT+Stanford，2026）
  • On-Policy-Distillation-在线策略蒸馏 - 将 RL 训练管线的 reward model 替换为 teacher model 的 logprob，实现 per-token dense reward，用 RL importance sampling 框架完成 distillation（Thinking Machines Lab, 2025）
  • Language-as-a-Latent-Variable-for-Reasoning-Optimization-polyGRPO - 提出 polyGRPO，将语言多样性作为 GRPO rollout 的隐式探索信号，在英文推理 AVG 上比标准 GRPO 提升 6.72%

偏好对齐

DPO 及其变体将 RLHF 的 reward modeling + PPO 两阶段压缩为单阶段 implicit reward 优化，但原始 DPO 在 token 粒度和偏好建模精细度上仍有提升空间。

  • Token-Importance_Guided_Direct_Preference_Optimization-TI-DPO - 梯度归因衡量 token 重要性 + 三元组损失引入中间状态；TruthfulQA 较 DPO 提升 5.3，将偏好学习重构为度量学习问题（中科院 + 微软 + 字节跳动，ICLR 2026 Oral）

RLVR（可验证奖励的强化学习）

RLVR 用确定性验证器（代码执行、数学答案匹配）替代 learned reward model，减少对 learned reward model 的依赖，但验证器漏洞与目标级 hacking 仍需分别检查。另一项挑战是：binary pass/fail reward 的信号极度稀疏，且数据工程（难度、多样性、课程设计）直接决定训练效率。

  • Evaluating-PEFT-Methods-for-RLVR - 评估 PEFT 方法（LoRA/DoRA）在 RLVR 场景中的表现，发现 rank 选择对性能影响显著（2025）
  • Probing_RLVR_Training_Instability-Objective-Level_Hacking - 对 RLVR 训练不稳定性的机理分析，揭示目标级 hacking 等问题（2025）
  • SaeRL-SAE-Guided-RL-Post-Training-Data-Engineering - 提出 SaeRL 框架，用 SAE 激活统一建模数据 diversity/difficulty/quality 三属性来驱动 RL 后训练的 batching + curriculum + filtering，在 GRPO 上平均提升 3%

奖励模型与排序

RL 后训练的效果上界由 reward signal 的质量决定。这组论文关注两个层面：reward model 本身的可靠性（仅看结果准确性不够，还需理由一致性），以及当 ground-truth reward 不可得时如何通过相对排序构造代理信号。

  • Outcome_Accuracy_is_Not_Enough-Rationale_Consistency_for_Reward_Models - 强调理由一致性的重要性；仅看结果准确性是不够的（2025）
  • ArenaRL-Tournament-Based_Relative_Ranking_for_Open-Ended_Agents - 基于锦标赛的相对排序方法，用于开放域智能体评估（2025）
  • LLM-Critics-Help-Catch-Bugs-in-Mathematics-Math-Minos - Math-Minos 先用知道标签的教师生成错误解释进行评价预训练，再训练 ORM/PRM 标量读出，用于候选排序与 PPO。强教师、标签感知和反馈可靠性共同决定收益；弱教师反馈可能有害，不能把自然语言监督本身视为质量保证。

应用场景

策略优化方法落地到具体任务时，往往需要任务特定的 reward 设计和训练策略适配。数学推理是 RLVR 的主战场（可验证 reward 天然可得），而机器翻译等非可验证任务则需要 surrogate reward（如后编辑信号）。

数学推理

  • Self-Distilled_Reasoner-On-Policy_Self-Distillation - OPSD，在线策略自蒸馏实现 8 倍 token 效率提升（UCLA，2026）
  • Reinforcing_CoT_Reasoning-Self_Evolving_Rubrics - 自演化评分标准引导 CoT 推理强化（2025）
  • TAPO-Translation_Augmented_Policy_Optimization_for_Multilingual_Mathematical_Reasoning - 步骤级优势解耦翻译与推理奖励，解决多语言数学推理中的理解瓶颈（南京大学 + 上海 AI Lab，2026）
  • Efficient-Multilingual-Reasoning-Transfer-via-Progressive-Code-Switching-PCS - GRPO 应用于多语言数学推理：把难直接优化的语言一致性离散化成阈值课程 + 0.1 小 bonus，正确性钉高权重，并用 reference reset + KL 稳定后期偏移（南京大学 + 阿里通义，2026）

机器翻译

  • PEGRL-Post-Editing_Guided_RL_for_MT - 后编辑引导的机器翻译强化学习（2025）

理论框架

蒸馏和 RL 通常被视为两条独立路径，但从轨迹来源（on-policy vs off-policy）和优化目标（KL 方向）的角度看，二者可以统一到同一个框架下。

  • LLM-Post-Training-Unified-Off-Policy-On-Policy - 提出轨迹来源框架，主张蒸馏与 RL 的统一视角；核心洞见：专家前缀引导桥接了蒸馏与 RL（京东科技，2026）

开放问题

  • 高带宽反馈应保留什么？ 在等教师成本和等 token 预算下，比较自由文本解释、结构化错误标签和反事实修正；单独审计“标签—解释”冲突，检验改进是否来自错误定位而非更长的监督文本。

跨论文的共性未解决问题。

  • 密集信号的最优注入方式：TRAPO（梯度裁剪 SFT）、SDPO（self-teacher KL）、On-Policy Distillation（teacher logprob）都在向 GRPO 注入密集信号，但三者的信号来源和注入机制完全不同——是否存在统一的最优注入框架？
  • Forward KL vs Reverse KL 的任务依赖性：TRAPO 通过 TrSFT 隐式转向 reverse KL，On-Policy Distillation 显式使用 reverse KL，而标准 SFT 用 forward KL。KL 方向的选择是否取决于 teacher-student 分布距离？
  • Reward 信号稀疏性的根本解法：RLVR 的 binary reward 是信息瓶颈，当前解法要么引入外部教师（蒸馏），要么利用环境反馈（SDPO 的 RLRF）——对于既无教师又无丰富环境反馈的任务，密集 reward 从何而来？
  • 向更大模型扩展：当前验证主要在 7B-8B 模型上（TRAPO 用 Qwen2.5-Math-7B，SDPO 用 Qwen3-8B）——密集信号注入的收益是否随模型规模变化？
  • 数学推理 RL 的通用推理泛化：数学推理训练如何保持通用推理能力（ARC-c, MMLU-Pro）？TRAPO 显示通用推理同步提升，但这是否依赖于特定的训练数据混合？
