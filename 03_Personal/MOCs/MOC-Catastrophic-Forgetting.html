Catastrophic Forgetting 概念图谱

这是一份概念型 MOC（与 MOC-Exposure-Bias 同类），围绕"灾难性遗忘"这一技术概念组织本库论文。该概念横跨持续学习、蒸馏、多语言、RL 后训练等多个领域 MOC，是 LLM 后训练中最普遍的失败模式之一。

1. 定义

Catastrophic forgetting（灾难性遗忘）是神经网络在学习新任务/知识时覆写已学知识的现象：

  • 训练阶段 A：模型在任务 A 上获得能力 $f_A$。
  • 训练阶段 B：模型在任务 B 上优化参数 $\theta$，使得 $\theta$ 移出 $f_A$ 的低损失区域——$f_A$ 性能骤降。

形式化：设 $\theta_A = \arg\min_\theta \mathcal{L}_A(\theta)$，训练阶段 B 将参数推至 $\theta_B = \arg\min_\theta \mathcal{L}_B(\theta)$。当 $\mathcal{L}_A(\theta_B) \gg \mathcal{L}_A(\theta_A)$ 时，catastrophic forgetting 发生。

这不是容量问题——Why-Fine-Tuning-Encourages-Hallucinations-SFT幻觉与自蒸馏 证明 1M UUID 实体可以零遗忘地学习。真正的原因是表示干扰（representational interference）：新知识与旧知识在中间层共享 token 表示时，新知识的梯度更新使旧知识的表示漂移。

该概念与持续学习（continual learning）文献中的 stability-plasticity dilemma 同构：稳定性（保留旧知识）与可塑性（学习新知识）之间的张力。

3. 解决方法族 × 本库对应论文

3.1 自蒸馏（Self-Distillation）

用模型自身的早期 checkpoint 或条件化版本作为 teacher，约束输出分布不偏移——在函数空间（而非参数空间）上保护旧知识。三篇论文独立发现这一路线有效，核心机制相同但应用场景不同。

  • Self-Distillation_Enables_Continual_Learning —— SDFT，核心论文。利用 ICL 条件化同一模型的 teacher 版本（带 demonstration）与 student 版本（无 demonstration），用 reverse KL 蒸馏。EMA teacher 更新是关键稳定机制。在 3 任务序列学习中保持 ~100% 归一化性能，SFT 降至 ~0。
  • Why-Fine-Tuning-Encourages-Hallucinations-SFT幻觉与自蒸馏 —— 冻结仅在已知事实上训练的 teacher checkpoint，在 SFT 新知识时加 KL 蒸馏损失。证明遗忘不是容量问题（1M UUID 零遗忘），而是表示干扰：新旧知识共享 token 导致中间层表示漂移。top-76 token 消融实验揭示机制：保护 teacher 在竞争实体 token 上的意见（0.5% 词表覆盖 91-92% 概率质量）即足够。
  • On-Policy-Distillation-在线策略蒸馏 —— 个性化场景的"事后修复"：中训在内部文档上训练后 IF-eval 从 85% 降至 45-79%，用"中训前版本的自己"作 teacher 的 on-policy 蒸馏恢复至 83%。关键发现：混入 100% 背景聊天数据也无法完全防止遗忘，LoRA 同样失败。

3.2 模型融合（Model Merging）

训练时不防止遗忘，推理时通过参数缩放修复。范式从"预防"转向"治疗"。

  • Train-with-Perturbation-Infer-after-Merging-PnM-CL —— P&M，在 task vector 方向加扰动训练，推理时用凸组合融合新旧参数。单独融合（LoRA-M）在 INR-10 上比 vanilla LoRA +12.63%，说明"用当前任务参数直接推理"是严重次优的。Fisher 信息矩阵确定最优融合系数。

3.3 架构级隔离（Architecture-based Isolation）

通过冻层或模块化架构将新旧知识物理隔离。

  • LLaMAX2-Translation_Enhanced_Model_Performs_Well_in_Reasoning —— 层选择性微调。冻结中间层（"概念空间"）、只训练底层（编码）和顶层（解码），用 0.8B token 实现 SOTA 翻译同时完全保留推理能力。传统 pipeline（Base → CPT → SFT → RL）用数十亿 token 反而灾难性遗忘推理能力。
  • Group_then_Scale-Dynamic_MoE_Multilingual_LLM —— Dynamic MoE：为新语言复制最相似的专家，冻结其余参数，只训练新专家 + 路由器。遗忘减少 65%（PPL 增加从 +2.0 降至 +0.7）。MoE 架构天然支持知识隔离。
  • DeltaMoE-Multilingual-Expansion-via-Post-training-Delta-Integration-into-Upcycled-MoE —— DeltaMoE：dense FFN sparse-upcycle 成 4-expert MoE，CPT 阶段冻结 expert-0 作为原能力锚点，router 学会把英语 token 几乎全部路由到 expert-0（Figure 3）；Merging 阶段把 dense post-training delta 广播到所有 experts 的 FFN 上，完成 alignment 嫁接。在 Qwen2.5-7B 上 Expanded +1.76（vs MoLA），Original 仅 −1.16（vs Instruct）。证明"参数空间嫁接 + 架构子空间隔离"可同时拿下"扩"和"保"，是 LLaMAX2 层选择性微调的架构级推广。

3.4 On-Policy RL（替代 Off-Policy SFT）

SFT 是 off-policy 的——强制模型匹配外部分布，导致已学分布被覆写。On-policy RL 从模型自身采样，梯度更温和，不破坏已有能力。

  • Trust-Region-Adaptive-Policy-Optimization-TRAPO —— TrSFT 裁剪 forward KL 的 1/p 梯度权重（$\alpha$=0.1），隐式将优化从 mode-covering 转为 mode-seeking，防止灾难性分布偏移。直接混合 SFT+RL 损失会使性能从 50.4 崩至 32.3。
  • TAPO-Translation_Augmented_Policy_Optimization_for_Multilingual_Mathematical_Reasoning —— 最戏剧性的数据点：SFT-TransTest 使 Qwen 平均准确率从 44.8% 崩至 5.0%。所有 on-policy 方法（RAFT、GRPO、TAPO）成功避免遗忘。引用 Shenfeld 2025 的"RL's razor"解释机制。

3.5 课程学习 / 数据顺序（Curriculum / Data Ordering）

训练数据的排列顺序直接决定遗忘程度。

  • Just_Go_Parallel-Improving_Multilingual_Capabilities_LLMs —— 教科书级演示：PARALLEL FIRST（并行数据在前）导致翻译能力"在并行数据用尽后完全消失"——后续单语训练覆写了翻译知识。PARALLEL LAST（并行数据在后）因无后续覆写而成功。
  • Seed-X（Seed-X-Multilingual_Translation_LLM_7B）—— 务实承认遗忘风险，通过学习率调度管理纯并行数据训练中的遗忘。

3.6 重放 / 混合（Replay / Rehearsal）

在新任务训练中混入旧任务数据，维持旧任务性能。经典但计算代价随任务数线性增长。

  • MetricX-24（MetricX-24-The-Google-Submission-to-the-WMT-2024-Metrics-Shared-Task-MetricX-24-Hybrid-Evaluation）—— 两阶段微调（DA → MQM）导致"语言遗忘"（DA 评估降 -2.27）。以 1:10 比例混入 DA 数据恢复性能。

3.7 刻意遗忘（Deliberate Forgetting for Safety）

将遗忘从"bug"变为"feature"：在预训练阶段将危险知识隔离到专属参数，使删除变为参数清零。

  • Beyond_Data_Filtering-Knowledge_Localization_SGTM —— SGTM 在预训练时用选择性梯度遮蔽隔离目标知识。删除后重新学习需要 7x 更多微调步数（vs post-hoc unlearning 的 RMU）。自增强定位属性使即使标错的样本也能路由到正确的参数分区。

4. 跨论文洞见

4.1 Off-policy 是根因

多篇论文独立收敛到同一诊断：SFT 的 off-policy 本质（强制模型匹配外部分布）是遗忘的根本驱动力。SDFT、TRAPO、TAPO、On-Policy-Distillation 都从不同角度得出"on-policy 方法更好地保留能力"。TAPO 的数据最极端：SFT 使 Qwen 从 44.8% 降至 5.0%。

这与 MOC-Exposure-Bias 的核心洞见形成镜像：exposure bias 说的是 train/inference 分布错配导致推理时误差放大；catastrophic forgetting 说的是 task A/task B 分布冲突导致旧能力被覆写。两者的共同根源都是 off-policy 训练的分布错配。

4.2 遗忘不是容量问题，是表示干扰

Why-Fine-Tuning-Encourages-Hallucinations-SFT幻觉与自蒸馏 提供了最干净的证据：1M UUID 实体可以零遗忘地学习，因为 UUID 不与已有实体共享 token。遗忘发生在新旧知识共享 token 表示时——新知识的梯度更新使共享 token 的中间层表示漂移。这把问题从"如何腾出空间"重新定义为"如何防止串扰"。

4.3 自蒸馏作为统一机制

三篇论文（SDFT、Why-FT-Hallucinations、On-Policy-Distillation）独立发现，用模型自身的早期 checkpoint 作 teacher 来正则化输出分布是高效的防遗忘手段。机制相同：约束函数空间（输出分布不漂移）而非参数空间（权重不变），让参数自由移动，只要旧任务行为保持。

4.4 层级架构洞见

LLaMAX2（冻结中间层）和 DMoE（MoE 隔离）都发现同一架构原理：中间层编码共享的"概念空间"，应被保护；顶层/底层编码任务/语言特定知识，可安全修改。这与 Language-Specific_Neurons-Multilingual_Capabilities_LLMs 的 U 型分布发现一致。

4.5 "预防 vs 治疗"是伪二元对立

P&M-CL 证明可以完全跳过训练时的防遗忘措施，在推理时通过参数融合修复遗忘。这与自蒸馏（训练时预防）互补而非竞争——理论上可以堆叠两者获得更强的防遗忘效果。

4.6 Catastrophic forgetting 与邻近概念的边界

概念 与 catastrophic forgetting 的关系
Exposure bias 不同问题——前者关心 task A → task B 的知识覆写，后者关心 train/inference 的分布错配；但共享"off-policy 是根因"这一诊断，见 MOC-Exposure-Bias
Representational interference 遗忘的机制而非遗忘本身——新旧知识共享 token 时中间层表示漂移
Stability-plasticity dilemma 遗忘是该 dilemma 在"过度可塑"一端的表现
Knowledge localization 反面应用——SGTM 利用参数隔离实现"可控遗忘"
Distribution shift 遗忘是其在序贯训练场景的特例——任务 B 的梯度将参数推出任务 A 的低损失区域

5. 开放问题

  • 自蒸馏 + 模型融合能否叠加？ SDFT 在训练时、P&M 在推理时分别操作，理论上互补。但无实证验证两者组合的效果。
  • On-policy 训练防遗忘的理论解释：多篇论文经验性地证明 RL 比 SFT 温和，但理论解释（除了"梯度更小"）仍然单薄。到底是 KL 约束、on-policy 采样、还是 reward 结构最重要？
  • 表示干扰是否随模型规模缩放？ Why-FT-Hallucinations 论文在 1.5B-8B 规模展示干扰。70B+ 模型是否因表示容量充裕而天然避免干扰？
  • 能否在训练前预测哪些新知识会导致遗忘？ Why-FT-Hallucinations 论文展示了 token 级重叠预测干扰。能否将此转化为训练前诊断工具来标记危险数据？
  • 层选择性方法 + 自蒸馏的混合：LLaMAX2 的冻层简单但粗糙，自蒸馏灵活但增加计算。只对未冻结层做蒸馏的混合方案是否能兼得两者优势？
