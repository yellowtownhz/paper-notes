南京大学 NLP 研究组（黄书剑）

南京大学 NLP 研究组由黄书剑教授领导，是多语言翻译与翻译优化强化学习领域的核心团队。 本 MOC 追踪该组的研究脉络。

核心成员：黄书剑（通讯）、Xu Huang、Zhejian Lai、Zixian Huang、Jiajun Chen、Sen Yang、Shanbo Cheng、Lu Xu 等。

翻译强化学习

三篇工作共享同一核心张力：GRPO 依赖组内相对排序，但翻译任务的奖励信号天然噪声大、信用分配困难。各论文从不同粒度切入——PEGRL 用后编辑的低方差信号稳定句子级训练，GRRM 用组联合评估（GQM）替代独立打分解决组级排序失真，TAPO 用步级优势将翻译与推理的 advantage 彻底解耦。这条路径呈现清晰的奖励信号精细化趋势：句子级 → 组级 → token 级。

  • PEGRL-Post-Editing_Guided_RL_for_MT - 利用后编辑信号引导翻译 RL，借助低方差特性稳定训练（Nanjing University + China Mobile, 2026）
  • GRRM_Group_Relative_Reward_Modeling_for_Machine_Translation - GQM 范式，以组联合评估替代独立打分；提出 SQM-GenRM 解决信用分配问题（Nanjing University, 2026）
  • TAPO-Translation_Augmented_Policy_Optimization_for_Multilingual_Mathematical_Reasoning - 步级优势解耦翻译与推理奖励，解决多语言数学推理中的理解瓶颈（Nanjing University + Shanghai AI Lab, 2026）

多语言能力与推理保持

翻译增强模型长期面临"翻译-推理跷跷板"问题：强化翻译能力往往以推理退化为代价。该组两篇工作从互补方向应对这一张力——LLaMAX2 通过层选择性微调在参数层面隔离翻译与推理（冻结中间层保持推理，仅训练底层/顶层增强翻译），TRIT 则在训练目标层面将翻译与推理整合为闭环反馈（用推理准确率作为翻译质量的代理信号）。两者共同表明：关键不在翻译数据量，而在训练策略的精细设计。

  • LLaMAX2-Translation_Enhanced_Model_Performs_Well_in_Reasoning - 层选择性微调，翻译增强同时保持推理能力（Nanjing University + HKU + CMU + Shanghai AI Lab, 2025）
  • Self-Improving_Multilingual_Long_Reasoning-TRIT - 跨语言自改进长推理，在 RLVR 框架下增强多语言推理（Nanjing University + University of Tübingen + China Mobile Research Institute, 2026）
  • Efficient-Multilingual-Reasoning-Transfer-via-Progressive-Code-Switching-PCS - 黄书剑（通讯）组联合阿里通义的又一篇工作，将该组从翻译 RL / 推理保持延伸到多语言推理迁移——用课程式 code-switching RL 把英文推理能力平滑搬到目标语言（Nanjing University + Tongyi Lab, 2026）

多语言扩展与架构隔离

从 LLaMAX2 的"层选择性微调"（参数空间隔离）继续向架构层延伸：DeltaMoE 把 dense FFN 升级为 4-expert MoE，冻结 expert-0 作为知识锚点，把 dense post-training delta 广播到所有 experts 完成 alignment 嫁接。该组研究脉络从翻译 RL / 推理保持延伸到 data-free 多语言扩展的架构层方案。

  • DeltaMoE-Multilingual-Expansion-via-Post-training-Delta-Integration-into-Upcycled-MoE - 南大 NLP 联合阿里通义，将研究边界扩到 data-free 多语言能力扩展的架构层方案，与 LLaMAX2 思路同源（参数空间隔离 → 架构子空间隔离）（Nanjing University + Tongyi + ZJU, 2026）

翻译质量评估

该组研究边界从翻译 RL / 多语言推理 / 架构隔离进一步扩展到 span 级翻译质量评估（QE）方向。不同于固定 MQM rubric 的静态评测，Rubric-as-Experts 用轻量 router 为每条译文动态分配 MQM rubric 粒度，并揭示 rubric 是塑造评审员探索轨迹的搜索空间而非静态标签清单。

  • Rubric-as-Experts-Case-Specific-MQM-Rubrics - 黄书剑（通讯）组的又一篇工作，将研究边界从翻译 RL / 多语言推理扩展到 span 级翻译质量评估，用轻量 router 为每条译文动态分配 MQM rubric 粒度（南京大学, 2026）

研究脉络

翻译 RL 的演进逻辑

  1. 首先，利用后编辑信号稳定翻译 RL（PEGRL）
  2. 其次，利用组相对评估解决信用分配（GRRM）
  3. 最后，利用步级优势解耦翻译与推理（TAPO）

这条演进路径揭示了一个清晰的奖励信号精细化趋势：从句子级 → 组级 → token 级。

向多语言推理的延伸

从纯翻译优化（PEGRL/GRRM）延伸到多语言数学推理（TAPO/TRIT），该组正将翻译 RL 经验迁移到更广泛的多语言推理场景。TAPO 是桥梁角色——它同时属于翻译 RL（步级奖励分离）和多语言推理（解决理解瓶颈），而 LLaMAX2 则从模型架构层面提供了"翻译增强不损害推理"的基础保障。

开放问题

  • GQM 范式能否推广到翻译之外的开放式生成任务？ GRRM 论文自身分析认为文本摘要和创意写作（无绝对正确答案 + 细粒度质量差异）最适合，但尚无实验验证
  • TAPO 的步级优势能否与 GRRM 的组级评估相结合？ 具体方案：用 GRRM 替代 ChrF++ 作为翻译 reward，同时保持 TAPO 的步级 advantage 解耦
  • 低资源语言的 RL 训练瓶颈何在？ PEGRL 在 EN→FI/TR 上效果显著但语言覆盖有限；TAPO 在 Swahili/Telugu 上提升最大但 xCOMET 出现 reward hacking；LLaMAX2 用 0.8B tokens 覆盖 17 种语言但未测试极低资源语种——三条路径的低资源极限尚未探明
