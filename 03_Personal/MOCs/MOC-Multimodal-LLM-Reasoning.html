多模态 LLM 推理研究地图

本 MOC 覆盖"多模态 LLM（视觉/视频 + 语言）推理"研究线上的所有论文。 核心范式：将强化学习、自我改进与注意力机制扩展到多模态场景。

视觉推理的自我改进与选择性优化

多模态推理的核心张力在于：视觉任务缺乏像数学题那样的标准答案验证器，因此 LLM 自改进范式无法直接迁移。本节的工作各自提出不同的"选择性"策略来绕开这一瓶颈——VC-STaR 用对比样本对作为隐式验证器（选择性地过滤训练数据），RAL 直接将注意力分布作为可优化的策略（选择性地优化内部计算过程而非输出 token）。两者在方法层面互补：VC-STaR 解决"用什么数据训练"，RAL 解决"优化模型的哪个部分"。

  • Through_the_Lens_of_Contrast-Self-Improving_Visual_Reasoning_in_VLMs - VC-STaR，挖掘视觉对比样本对以实现自我改进推理，"以对比作为监督"解决视觉幻觉验证难题（ICLR 2026 Oral）

  • Reinforced-Attention-Learning-RAL - 强化注意力学习，通过 RL 显式优化 VLM 的注意力分配，提升视觉定位质量（UC Davis + Google DeepMind，2026）

  • Attention in Space - 在空间子任务中定位功能候选头，并分别研究 SHA 对象框／mask 输入增强和头输出 steering；两条路线的收益与证据边界分开解释（arXiv 2026）

视频推理

视频推理在图像推理基础上引入时序维度，但序列级奖励信号无法区分"视觉感知错误"与"时序推理错误"。Video-KTR 通过反事实扰动（视觉遮蔽、帧打乱）将 token 按模态归因分类，仅对关键 token 执行 RL 更新，延续了本 MOC 的核心主题——选择性优化。与上节 RAL 的注意力层级选择性不同，Video-KTR 工作在 token 层级，两者可能互补。

  • Video-KTR-Key-Token_Attribution_for_Video_Reasoning - 面向视频推理的关键 token 归因方法，token 级优化提升视频理解质量（ByteDance + NTU，ICLR 2026）

视觉编码器

传统 VLM 将图像 patch 按固定栅格顺序展平为 1D 序列，这种硬编码的空间-序列映射在复杂布局（如多栏文档、螺旋排列）下引入归纳偏置。DeepSeek-OCR 2 用可学习的因果流查询替代固定展平，让编码器自主学习语义驱动的视觉 token 重排，仅用 1120 个视觉 token 即超越使用 6000+ token 的模型。这一工作关注的是"信息如何进入 LLM"，与上两节关注"LLM 内部如何处理信息"形成上下游互补。

  • DeepSeek-OCR_2-Visual_Causal_Flow - 面向 OCR 的视觉因果流架构，改进视觉编码器中的因果注意力设计（DeepSeek，2025）

视觉表征的组合性地基

上面三节都默认"视觉表征本身可用"。ARO 用 5 万+ 词袋相同的最小对立样本证明了这个前提有多脆弱：CLIP/BLIP/FLAVA 在关系、属性、词序上仅达偶然水平，且修复方案（composition-aware hard negatives）只在词汇可解的关系上生效，反而打坏了遮挡/垂直空间关系。它给本 MOC 的所有"在表征之上继续优化"的工作标定了天花板。

  • When-and-why-VLMs-behave-like-bags-of-words-ARO组合性评测 - ARO benchmark + NegCLIP，揭示 VLM 的袋装词行为并给出组合性评测口径（Stanford，ICLR 2023）

开放问题

跨论文的未解问题与研究线索。

  • 选择性优化的统一框架：VC-STaR 在样本层面选择（对比过滤）、RAL 在注意力层面选择（注意力策略）、Video-KTR 在 token 层面选择（模态归因掩码）——三者能否统一为一个多层级的选择性 RL 框架？例如先用 VC-STaR 筛选高质量训练数据，再用 Video-KTR 识别关键 token，最后用 RAL 优化这些 token 对应的注意力分布
  • VLM 中 RL 的奖励设计：当前所有工作均使用规则化的精确匹配奖励（accuracy + format），但视觉推理的正确性常依赖主观判断（如"这张图的风格是什么"）。对比验证（VC-STaR）是否可以作为一种通用的、无需标注的奖励信号？
  • 注意力优化 vs CoT 推理的效率权衡：RAL-zero 证明对感知任务无需显式 CoT 即可通过注意力优化获得提升，但对推理密集任务（如 MathVista）CoT 仍不可或缺。如何自适应决定"用注意力优化还是用 CoT"？
  • 视觉编码与推理的端到端联合优化：DeepSeek-OCR 2 的因果流查询优化了"信息如何进入 LLM"，RAL/Video-KTR 优化了"LLM 内部如何处理信息"——两者能否端到端联合训练而非分阶段串联？
