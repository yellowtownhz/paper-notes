Credit Assignment 概念图谱

这是一份概念型 MOC（与 MOC-Exposure-Bias、MOC-Catastrophic-Forgetting、MOC-Reward-Hacking 同类），围绕"信用分配"这一基础问题组织本库论文。在 LLM 后训练中，该问题表现为：如何从序列级奖励信号向下分配到 token 级、步骤级、或注意力级的优化信号。

1. 定义

Credit assignment（信用分配）是将宏观结果（奖励、损失、改进）归因到微观动作（token、步骤、注意力模式）的问题：

  • 给定：一条生成轨迹 $y = (y_1, y_2, \ldots, y_T)$ 和一个序列级奖励 $R(y)$。
  • 目标：确定每个 $y_t$（或轨迹中某个子段 / 某个内部计算节点）对 $R(y)$ 的贡献 $c_t$，使得 $\sum_t c_t \approx R(y)$。

形式化：REINFORCE 的朴素信用分配是 $\nabla_\theta J = \mathbb{E}[R(y) \sum_t \nabla_\theta \log \pi_\theta(y_t | y_{<t})]$——整个 $R(y)$ 均匀加权每个 token 的梯度。这导致高方差和虚假归因。所有改进方法本质上都在设计更精确的 $c_t$：从 baseline subtraction（GRPO 的 group-relative advantage）到 dense per-token signal（self-distillation KL）到 explicit attribution（gradient-based importance）。

在 RL 文献中，credit assignment 是与 temporal difference learning、reward shaping、hindsight reasoning 共同构成强化学习核心难题的基础概念。但 LLM 后训练将其推向了极端：单条推理链可达 16k-32k token，而结果奖励只有 1 bit（对/错）。

2. 起源与关键形式化

论文 贡献
Minsky 1961 Steps toward Artificial Intelligence (Proceedings of the IRE) 最早提出 credit assignment problem：在由多步骤组成的行为中，如何确定哪些步骤对最终成功/失败负责
Sutton 1984 Temporal Credit Assignment in Reinforcement Learning (PhD thesis) 将 credit assignment 分为 structural（哪些组件负责）和 temporal（哪些时间步负责），奠定 TD learning 基础
Williams 1992 Simple statistical gradient-following algorithms for connectionist reinforcement learning (REINFORCE) 给出 policy gradient 的朴素信用分配——所有 token 均匀加权；后续改进的起点
Arjona-Medina et al. 2019 RUDDER: Return Decomposition for Delayed Rewards (NeurIPS) 将序列级 reward 分解为 per-step contribution——直接启发了 LLM 后训练中的 token-level reward decomposition 思路

3. 信用分配粒度 × 本库对应论文

3.1 序列级 → 步骤级分解（Segment-Level Decomposition）

将轨迹拆分为功能不同的子段，每段获得独立的奖励信号。最适合轨迹本身具有异质结构的任务（如翻译 + 推理）。

  • TAPO-Translation_Augmented_Policy_Optimization_for_Multilingual_Mathematical_Reasoning —— 核心论文。轨迹拆分为翻译段和推理段，各段独立归一化 advantage，防止奖励冲突。翻译 advantage 进一步与推理 advantage 混合（$\alpha$=0.25），使翻译朝"对推理有用"而非"字面准确"方向优化。关键数据：轨迹级奖励产生 ~30% 假阳性/阴性 advantage。
  • PEGRL-Post-Editing_Guided_RL_for_MT —— 两阶段局部探索：先生成初稿，再做小范围后编辑。后编辑在固定初稿上操作，模型可清晰归因"哪个词/短语的改动导致了分数提升"。翻译 reward 取后编辑奖励的均值，提供更干净的信用分配链。开放式生成中的信用分配比数学/代码更难——每个 token 都影响质量，且奖励是连续而非二值的。
  • Self-Improving_Multilingual_Long_Reasoning-TRIT —— 隐式信用分配：推理准确率作为翻译质量的代理信号。但论文自身指出硬伤：好翻译 + 坏推理会错误惩罚翻译，坏翻译 + 强推理会错误奖励翻译。信号混淆是段级分解不够精细的典型失败。

3.2 密集 Token 级信号 via 自蒸馏（Dense Token-Level Signal via Self-Distillation）

利用信息不对称创造 token 级监督——teacher 看到 student 看不到的特权信息（答案 / 环境反馈），teacher-student 在每个 token 位置的 KL 散度提供密集信用分配。

  • Reinforcement_Learning_via_Self-Distillation-SDPO —— 核心论文。同一模型充当 student（无反馈）和 teacher（条件化环境反馈如运行时错误），每个 token 的 KL 散度提供密集信号。打破 GRPO 的信息瓶颈：标准 RLVR 将丰富的环境反馈压缩为标量奖励，丢失了大部分信用分配信息。SDPO 保留此信息，效率比 GRPO 提升 4x。
  • Self-Distilled_Reasoner-On-Policy_Self-Distillation —— OPSD，ground-truth 答案作为特权信息。Teacher（看到正确答案的同一模型）在每个 token 位置提供 KL 散度信号给 student（未看到答案的同一模型）。将 GRPO 的稀疏 1-bit reward 转化为密集 token 级监督。Token 效率比 GRPO 提升 8x。但限于有可验证答案的任务（数学、代码）。

3.3 基于归因的 Token 选择（Attribution-Based Token Selection）

计算 token 重要性分数，将优化信号聚焦于关键 token。

  • Token-Importance_Guided_Direct_Preference_Optimization-TI-DPO —— 核心论文。计算每个 token embedding 对策略 log-probability 的梯度的 L1 范数作为重要性分数。高重要性 token 在 DPO 损失中获得放大权重。比基于概率的重要性估计（TIS-DPO）更有原则性。不同任务展示不同权重分布：TruthfulQA 中安全关键 token 权重高，GSM8K 中仅关键数学符号高权重。
  • Video-KTR-Key-Token_Attribution_for_Video_Reasoning —— 多模态反事实归因：视觉感知（视频遮蔽）、时间感知（帧洗牌）、熵感知（预测不确定性）三路信号识别关键 token。仅 top-20% token 接受 RL 梯度更新（二值遮罩）。硬选择优于软加权——信用分配受益于稀疏性。
  • Towards-Long-Horizon-Interpretability-FlashTrace-Multi-Token-Attribution —— 解决"推理 token 吸收"问题：自回归模型中相邻推理 token 吸收 ~90% 归因权重，使输入 token 信用缺失。递归归因沿推理链回溯信用至输入。130x 加速来自代数重排（从注意力贡献中提取 value 向量）。

3.4 过程级优化（Process-Level Optimization）

不优化输出 token（结果），而直接优化内部计算过程（注意力分布）。

  • Reinforced-Attention-Learning-RAL —— 核心论文。将注意力分布作为策略直接优化，而非优化输出 token（间接影响注意力）。用 advantage-weighted attention divergence（JSD）作为损失。每 token 粒度防止长序列梯度消失。对多模态感知任务，瓶颈是"看哪里"而非"说什么"——信用分配目标应是内部计算路径而非输出 token。
  • Outcome_Accuracy_is_Not_Enough-Rationale_Consistency_for_Reward_Models —— Reward model 的过程级信用分配：hybrid reward = $R_{rationale} \times R_{outcome}$（乘法门控），强制模型将判断归因到正确证据而非表面线索。纯 outcome reward 使 evidence-grounded 推理从 93.6% 降至 45.4%——"答案对但归因错"是信用分配失败的表现。

3.5 奖励信号质量（Reward Signal Quality as Prerequisite）

信用分配的前提是奖励信号本身足够可靠。当 group 方差接近噪声方差时，无论方法多精细，信用分配都不可能。

  • ArenaRL-Tournament-Based_Relative_Ranking_for_Open-Ended_Agents —— 当评分饱和导致"判别力崩溃"（SNR ~1.5）时，GRPO 的 advantage 信号被噪声主导——信用分配在源头失败。锦标赛式相对排名提供更干净的序数信号。相对排名只需序数比较，不需基数评分，因此本质上更鲁棒。
  • GRRM_Group_Relative_Reward_Modeling_for_Machine_Translation —— 独立评分（SQM）在所有候选都获得饱和分数时，advantage（信用分配的基础）信号消失。联合评估（GQM）提供比较上下文，恢复有意义的信用分配。

3.6 推理链中的因果归因（Causal Attribution in Reasoning Chains）

识别推理链中哪些步骤对最终结果有因果作用——不是所有 token 都值得分配信用。

  • Thought-Anchors-Which-LLM-Reasoning-Steps-Matter —— 通过重采样实验发现：计划生成（Plan Generation）和不确定性管理（Uncertainty Management）句子的反事实重要性最高，而主动计算（Active Computation）步骤可替换。Forced-answer 重要性系统性地误识别——它突出计算步骤（包含充分信息），但遗漏计划步骤（决定轨迹方向）。RL 信用分配应偏向计划 token 而非计算 token。
  • Prefix-Teach-Suffix-Fade-Local-Teachability-Collapse —— 发现 teacher margin（teacher 在 student top-K 候选上的 top1-top2 logprob 差距）沿轨迹衰减——在轨迹后段 teacher 已无法区分好坏候选。此时监督信号退化为噪声。"哪些位置应接受学习信号"本身就是一个信用分配问题。

3.7 参数空间中的信用分配（Credit Assignment in Parameter Space）

奖励信号在参数空间中的分配方式——不同训练范式要求不同的参数更新几何。

  • Evaluating-PEFT-Methods-for-RLVR —— RLVR 的 1-bit 稀疏奖励创造特殊的信用分配挑战：梯度稀疏，更新必须分布在完整权重谱上（而非集中在主成分上如 SFT）。DoRA 的 magnitude-direction 分解天然匹配：magnitude 调整"置信度"，direction 处理"推理方向"。SFT 和 RLVR 有根本不同的参数更新几何。
  • A-Brain-like-Synergistic-Core-in-LLMs-协同核心 —— RL 微调（GRPO）特别受益于更新中间层的高协同性注意力头，SFT 无此偏好。协同性头可能是网络的内部信用分配机制——整合跨源信息以确定哪些组件应接受梯度更新。

3.8 决策点与工具组合的信用分配

工具反馈的价值取决于它对应哪次决策、与哪些信息一起出现；更多反馈未必产生更好的计划。

  • Towards-Feedback-to-Plan-Decisions-for-Self-Evolving-LLM-Agents-in-CUDA-Kernel-Generation-CUDAnalyst — CUDAnalyst 将规划、反馈、摘要及调试/结构分析/profiling 作为可开关组件，用 Shapley、Banzhaf 和交互项度量条件贡献；反馈打乱对照支持证据匹配的重要性。局部决策点结果与代际统计不等于整条自演化轨迹的无偏因果效应，工具贡献也没有跨模型固定排名。

4. 跨论文洞见

4.1 信用分配粒度存在层级结构

在做精细的 token 级信用分配之前，需要可靠的序列级信号（ArenaRL、GRRM）。有了干净的序数信号后，可以在段级分解（TAPO、PEGRL）。Token 级方法（TI-DPO、SDPO）需要密集监督源或强归因方法。层级自底而上：信号质量 → 段级分解 → token 级归因。

4.2 开放式生成的信用分配比数学/代码更难

数学/代码有二值结果奖励，推理路径多样性有界。但翻译、摘要、创意写作中每个 token 都影响质量，奖励连续，输出空间巨大。PEGRL（通过后编辑缩小探索空间）、GRRM（通过更好的 reward model）、ArenaRL（通过相对排名）都在应对这一根本困难。

4.3 推理链中"什么重要"是反直觉的

Thought-Anchors 展示计划和不确定性管理步骤的因果重要性最高，而非计算步骤。这直接挑战朴素的 token 级信用分配方法。Forced-answer 重要性（标准方法）系统性地误导——它突出计算（包含充分信息）而遗漏计划（决定轨迹方向）。

4.4 信用分配方法形成互补对

信号质量（ArenaRL/GRRM）与信号粒度（TAPO/TI-DPO）正交。过程监督（RAL/Rationale Consistency）与输出监督（GRPO/DPO）正交。最有效的系统应组合多种方法。

4.5 Credit assignment 与邻近概念的边界

概念 与 credit assignment 的关系
Reward hacking 互为因果——信用分配失败可导致 objective-level hacking（Probing RLVR），见 MOC-Reward-Hacking
Reward sparsity credit assignment 困难的原因之一——1-bit outcome reward 包含的信用分配信息极少
Exposure bias 不同问题——exposure bias 关心 train/inference 分布错配，credit assignment 关心 reward 到 action 的归因；但 on-policy 方法同时缓解两者，见 MOC-Exposure-Bias
Causal mediation analysis credit assignment 在可解释性领域的对应——如何将模型行为归因到特定内部组件（head、layer、feature）
Local teachability collapse 信用分配信号质量沿轨迹衰减的特例，见 Prefix-Teach-Suffix-Fade-Local-Teachability-Collapse

5. 开放问题

  • 局部信用能否指导后续工具选择？ 将工具组合归因转换为下一步反馈策略后，需在固定总调用预算下做前瞻闭环对照，并报告正确性、速度和额外成本；局部边际值不能直接当成长期策略价值。

  • 段级 + token 级信用分配的层次化统一：TAPO 做段级，TI-DPO 做 token 级。是否存在有原则的方法先按段分解、再在段内做 token 级归因？

  • 真正开放式任务的信用分配信号：SDPO/OPSD 需要可验证答案，PEGRL/TAPO 需要结构化输出。对创意写作、复杂规划、多轮对话，什么可以充当信用分配信号？

  • 注意力是否是正确的优化层级？ RAL 直接优化注意力并在感知任务上成功。但 Thought-Anchors 显示 receiver head 已能自动追踪重要推理步骤。应该直接优化注意力，还是相信模型在更好的 reward 信号下自然学会合适的注意力模式？

  • 跨训练范式的信用分配迁移：PEFT 论文揭示 SFT 和 RLVR 有根本不同的参数更新几何。这是否意味着为一种范式设计的信用分配方法无法迁移到另一种？

  • 信用分配与训练效率的数量关系：SDPO 4x、OPSD 8x 相对 GRPO 的效率提升来自更精确的信用分配。这一效率增益是否可预测？给定信用分配精度的提升，能否预测训练效率的改善？
