2. 关键问题：传统 CL 用当前任务最优参数做推理，为什么不用合并后的模型？

传统持续学习的方法有个"默认设置"：任务 t 训练完后，直接用 $\theta_t^*$ 做所有任务的推理。但这个参数只在当前任务上优化过，对之前的任务早就"跑偏"了。

更有意思的是，持续学习和模型合并这两个领域目标相同（多任务统一模型），但流程完全不兼容：

  • 传统 CL：$\theta_t^* = \theta_{t-1} + \Delta\theta_t^*$，顺序训练，但推理用当前参数
  • 模型合并：$\theta_t^* = \theta_0 + \Delta\theta_t^*$，独立训练后合并，但没法做 CL——CL 的前提是顺序训练，数据不能回头

那问题来了：能不能把 CL 的训练动态和模型合并的推理原则结合起来？

3. 数据集：5 个标准 CL benchmark

训练数据和评估数据都遵循 prior work [35, 23] 的协议：

Benchmark 任务数 类别数 特点
ImageNet-R 5/10/20 200 分布外泛化测试
ImageNet-A 10 200 对抗样本
DomainNet 5 345/200* 域迁移（DN* 是 200 类子集）
CIFAR100 10 100 经典分类
CUB200 10 200 细粒度分类

评估指标：

  • Acc：所有任务训练完后，在全部任务上的平均准确率
  • AAA (Average Anytime Accuracy)：每学完一个任务后在所有已见任务上的平均准确率，再取平均——capture 学习动态

Backbone：ViT-B/16，ImageNet-21K 预训练 + ImageNet-1K 微调

4. 关键方法：训练时扰动，推理时合并

P&M 做的事情就两件：

  1. 推理时做合并：训练完任务 t 后，把旧推理参数 $\hat{\theta}_{t-1}$ 和当前任务参数 $\theta_t^*$ 做凸组合
  2. 训练时加扰动：在训练过程中沿着任务向量方向随机扰动参数
方法 训练 推理
传统 CL $\theta_t^* = \theta_{t-1} + \Delta\theta_t^*$ $\hat{\theta}_t = \theta_t^*$
模型合并 $\theta_t^* = \theta_0 + \Delta\theta_t^*$ $\hat{\theta}_t = \sum_{i=1}^t \alpha_i\theta_i^*$
P&M $\theta_t^* = \hat{\theta}_{t-1} + \Delta\theta_t^*$ $\hat{\theta}_t = \hat{\theta}_{t-1} + \alpha_t\Delta\theta_t^*$

注意到了吗？P&M 继承了 CL 的顺序训练动态，但在推理时引入了模型合并的思路。

4.1 Infer after Merging

核心公式（Eq. 3-4）： $$\hat{\theta}_t = (1 - \alpha_t)\hat{\theta}_{t-1} + \alpha_t \theta_t^* = \hat{\theta}_{t-1} + \alpha_t \Delta\theta_t^*$$

其中 $\Delta\theta_t^* = \theta_t^* - \hat{\theta}_{t-1}$ 是任务向量。凸组合等价于对任务向量做缩放——缩放不会破坏 $\hat{\theta}_{t-1}$（旧任务的参数），只是减弱 $\Delta\theta_t^*$ 对旧参数的干扰。

关键问题：α 取多少最合适？

4.2 最优 α 的闭式解

定义"性能下降" $\delta_i$ 为合并后的模型在任务 i 上的 loss 相对于任务最优 $\theta_i^*$ 的增量（Eq. 5）： $$\delta_i = \mathcal{L}_i(\hat{\theta}_t) - \mathcal{L}_i(\theta_i^*)$$

在 $\theta_i^*$ 处做 Taylor 展开（Eq. 6），一阶项在最优点趋于 0： $$\delta_i \approx \frac{1}{2}(\hat{\theta}_t - \theta_i^*)^\top \mathbf{H}_i(\theta_i^*)(\hat{\theta}_t - \theta_i^*)$$

最小化 $\sum_{i=1}^t \delta_i$，对 α 求导 = 0，得到闭式解（Eq. 8）： $$\alpha_t^* = -\frac{\sum_{i=1}^t (\hat{\theta}_{t-1} - \theta_i^*)^\top \mathbf{H}_i \Delta\theta_t^*}{\sum_{i=1}^t \Delta\theta_t^{*\top} \mathbf{H}_i \Delta\theta_t^*}$$

实际实现用对角经验 Fisher 信息矩阵近似 Hessian（Eq. 9-10）： $$\hat{\mathbf{F}}(\theta) = \frac{1}{N}\sum_{i=1}^N \nabla_\theta \log p_\theta(y_i|x_i) \nabla_\theta \log p_\theta(y_i|x_i)^\top$$

只存对角线元素，每个任务训练完后算一次 Fisher，供后续 α 计算使用。

4.3 Train with Perturbation

合并后模型还是会比各任务最优模型差一点——因为存在"参数冲突"。但有个关键观察（Eq. 11-12）：合并后总损失增量的上界中，只有最后一项 $\delta_t(\alpha_t^*) = \Delta\theta_t^{*\top} \mathbf{H}_t \Delta\theta_t^*$ 能在当前任务 t 的训练中优化。

朴素想法：把这项当正则化加到 loss 里。但 Hessian 计算太贵，而且训练时参数远没到最优，Fisher 近似不靠谱。

关键 trick：用对称有限差分近似这个二次型（Eq. 13）： $$\Delta\theta_t^\top \mathbf{H}_t \Delta\theta_t \approx \frac{1}{\epsilon^2}\left[\mathcal{L}_t(\theta_t + \epsilon\Delta\theta_t) + \mathcal{L}_t(\theta_t - \epsilon\Delta\theta_t) - 2\mathcal{L}_t(\theta_t)\right]$$

问题是这样需要 3 次 forward pass。但作者发现：这个近似可以变成随机扰动！

每个 batch 以概率 $p_0$ 用原始参数，以概率 $p_+$ 用 $\theta + \epsilon\Delta\theta_t$，以概率 $p_-$ 用 $\theta - \epsilon\Delta\theta_t$。期望值无偏，但每个 batch 只需要一次 forward（Eq. 15-16）。

实验中设 $p_0 = p_+ = p_- = \frac{1}{3}$，$\epsilon = 0.5$。

直觉理解：训练时偶尔沿着 task vector 方向"晃一晃"参数，让模型学会在这个方向上保持稳定。这样合并时，task vector 的干扰就小了。

4.4 LoRA-P&M

存所有 $\theta_i^*$ 的 Fisher 信息内存开销大。解决方案是结合 LoRA：每个任务只训练低秩矩阵 $A_t, B_t$： $$\theta_t = \hat{\theta}_{t-1} + \mathbf{A}_t\mathbf{B}_t$$

只需要存 LoRA 参数的 Fisher（rank=10 的两个小矩阵），大幅减少存储。

LoRA 配置：

  • 插入位置：key 和 value projection
  • Rank = 10

4.5 训练流程（Algorithm 1）

for t = 1 to T:
    # Train with Perturbation
    冻结 θ̂_{t-1}，初始化新的 LoRA_t
    for each batch:
        随机选扰动 ε̃ ∈ {-0.5, 0, +0.5}，各 1/3 概率
        计算 loss = L_ce(θ̂_{t-1} + (1+ε̃)LoRA_t)
        更新 LoRA_t

    # Infer after Merging
    θ_t* = θ̂_{t-1} + LoRA_t
    计算 diagonal Fisher F_t(θ_t*)
    α_t* = 闭式解
    θ̂_t = θ̂_{t-1} + α_t* LoRA_t

5.3 Loss Landscape 分析（Figure 2）

四个关键观察：

  1. Scaling 减少遗忘，对塑性影响小：P&M 保持和 LoRA 相近的新任务性能，但旧任务遗忘显著减少
  2. 凸组合在低损失区域：$\hat{\theta}_{t-1}$ 和 $\theta_t^*$ 之间的直线路径一直在低损失区域
  3. 最优 α 找到低损失点：理论推导的 α* 确实落在 loss landscape 的低谷
  4. 扰动扩大平坦区域：加入扰动后，合并点周围的低损失盆地变宽变平

6. Golden Case：ImageNet-R 任务 4 合并的完整流程

假设我们在做 ImageNet-R 10 任务设置，当前到了第 4 个任务。

输入状态：

  • 任务 1-3 已学完，推理模型为 $\hat{\theta}_3$
  • 任务 4 数据：$D_4 = \{(x_i^4, y_i^4)\}$
  • $\hat{\theta}_3$ 在任务 1-3 上表现好，但对任务 4 没知识

处理流程：

Step 1: 初始化 LoRA_4

  • 从 $\hat{\theta}_3$ 开始，插入新的 LoRA 模块 $(A_4, B_4)$
  • 此时 $\theta_4 = \hat{\theta}_3 + A_4 B_4 \approx \hat{\theta}_3$（LoRA 初始为 0）

Step 2: Train with Perturbation

  • 每个 batch:
    • 采样扰动 $\tilde{\epsilon} \in \{-0.5, 0, +0.5\}$，各 1/3 概率
    • 计算 loss = CrossEntropy($\hat{\theta}_3 + (1+\tilde{\epsilon}) \cdot A_4 \cdot B_4$; $x_i^4, y_i^4$)
    • 反向传播更新 $A_4, B_4$
  • 直觉：训练时偶尔把 LoRA 参数放大/缩小 0.5 倍，让模型学会在 task vector 方向上不敏感

Step 3: 训练结束，得到任务最优

  • $\theta_4^* = \hat{\theta}_3 + A_4 \cdot B_4$
  • 此时 $\theta_4^*$ 在任务 4 上最优，但对任务 1-3 可能遗忘

Step 4: 计算 Fisher 矩阵

  • 在 $D_4$ 上计算 diagonal empirical Fisher: $F_4(\theta_4^*) = \frac{1}{N} \sum \nabla_\theta \log p(y|x) \odot \nabla_\theta \log p(y|x)$
  • 只存 LoRA 参数的 Fisher

Step 5: 计算最优 α

  • 用闭式解计算 $\alpha_4^*$
  • 假设算出 $\alpha_4^* = 0.7$

Step 6: 合并得到推理模型

  • $\hat{\theta}_4 = \hat{\theta}_3 + 0.7 \times \text{LoRA}_4$
  • 相当于把任务 4 的知识融入 70%，保留旧知识

最终效果：

  • $\hat{\theta}_4$ 用于任务 1-4 的推理
  • 相比直接用 $\theta_4^*$，旧任务遗忘减少
  • 相比不用扰动，合并更平滑

7. 我的疑问

疑问 1: Diagonal Fisher 近似有多准？

  • 我的理解：论文用对角 Fisher 近似 Hessian，省计算。但 Fisher 等于 Hessian 的期望是在 $N \to \infty$ 且模型最优时才成立，而且 Hessian 的非对角元素包含参数间交互信息，丢弃可能影响 α* 的准确性。
  • 想搞清楚：有没有实验对比 diagonal vs full Fisher？或者和其他 curvature 近似方法（如 K-FAC）对比？
  • Reviewer 回应：[?] 论文没有给出对比实验。但对于"找最优 α"这个目的，对角近似已经够用了（实验证明）。

疑问 2: 扰动方向为什么一定是 task vector？

  • 我的理解：论文说扰动方向必须是 task vector 方向才有效，随机高斯噪声效果差。
  • 想搞清楚：有没有理论分析说明 task vector 方向的扰动为什么能近似 Hessian-related 正则项？
  • Reviewer 回应：任务向量方向是训练优化方向，也是 loss 变化最敏感的方向。在这个方向扰动，相当于让模型在"学到的方向"上保持稳定。随机噪声在很多不敏感方向扰动，效果自然差。[?] 但论文没有理论证明这一点，只是消融实验验证。

疑问 3: α 的闭式解是否真的最优？

  • 我的理解：推导基于 Taylor 展开，假设 $\theta_i^*$ 是局部最优（梯度≈0），三阶项可忽略。但实际训练可能没收敛到真正的最优点；当 α 较小时，$\hat{\theta}_t$ 和旧任务最优可能差得较远，三阶项还能忽略吗？
  • 想搞清楚：有没有实验验证闭式解 α* vs 网格搜索找到的真正最优 α？实验中观察到的 α 值分布是怎样的？
  • Reviewer 回应：[?] 论文应该做一个实验：用网格搜索找真正的最优 α，和闭式解对比。建议论文报告实验中观察到的 α 分布。

疑问 4: 扰动的方差增加会不会影响收敛？

  • 我的理解：论文只说期望无偏，方差"略有增加"但没给具体数据。理论上方差太大会导致训练不稳定。
  • 想搞清楚：实验中是否观察到方差相关的训练问题？有没有考虑方差缩减的技巧？
  • Reviewer 回应：[?] 论文没给数据，这是个实际工程问题。

疑问 5: LoRA rank=10 够用吗？

  • 我的理解：论文用 rank=10 的 LoRA，只用在 key/value projection，总参数量不大。如果任务比较复杂，秩 10 可能不够表达。
  • 想搞清楚：有没有不同 rank 的消融实验？
  • Reviewer 回应：[?] 论文没有 rank 消融实验。但论文效果已经很好，说明至少在这些任务上够用。

疑问 6: 为什么论文没有和 EMA 对比？

  • 我的理解：P&M 的合并系数 α 是任务级别的优化，用闭式解算，考虑了所有历史任务的 Fisher 信息。EMA 是参数级别的动量，没有考虑任务的 curvature 信息。理论上 P&M 更优，但 EMA 不需要存历史 Fisher，更轻量。
  • 想搞清楚：论文应该做这个对比实验。

8. Insights

8.1 对论文本身的 Comments

反直觉的点：

  1. 训练时扰动不增加计算量：这个 trick 很妙。朴素做法需要 3× forward（原始 + 两个扰动点），但随机采样让每个 batch 只需要 1× forward。无偏估计 + 方差可控，这个设计很聪明。从方法论角度理解，这是"参数空间的 data augmentation"——在参数空间而非数据空间做增强。

  2. CL + Model Merging 的结合不是简单拼接：之前的直觉可能是"先 CL 训练，再用 Merging 后处理"。但论文发现 Merging 的效果受训练过程影响——如果训练时没考虑后续要合并，合并时冲突就大。Train with Perturbation 本质是"为更好的合并而训练"。

  3. 这个思路转变很关键：传统 CL 方法（EWC、replay、架构方法）都在训练阶段"防守"，试图让参数不走偏。P&M 说：不管你怎么防守，训练完参数总是偏的。那不如训练照常，推理时用数学方法把偏掉的参数"修正"回来。从"预防"变成"治疗"。

让我想不到的点：

  • Loss landscape 可视化（Figure 2）很漂亮地验证了理论推导。凸组合路径确实在低损失区域，α* 确实落在最低点附近。这种 theory + visualization 的闭环很少见。
  • Task vector 方向扰动 vs 随机噪声的对比（Table 4）是关键实验，说明"方向"比"扰动"本身重要。任务向量方向是 loss 变化最敏感的方向——因为训练就是沿着这个方向优化的。在这个方向上加扰动，相当于问模型"你学到的这个方向稳固吗？"

做得不好的地方：

  • 没有对比 EMA、moving average 这些更简单的方案。论文说"不同于 EMA"，但没有实验证明 EMA 就一定差。
  • 没有 Fisher 近似质量的消融实验，只说用 diagonal Fisher，但没有实验验证这个近似的误差。
  • LoRA rank 选择没有消融。rank=10 是拍脑袋还是实验得出？
  • 扰动的方差分析缺失，只说"variance may increase slightly"。
  • 所有实验都是 ViT + 分类任务，没有 NLP 或其他模态的验证。

8.3 研究品味

"为更好的合并而训练"——一个通用范式：

Train with Perturbation 的本质是：既然推理时要合并，那训练时就为合并做准备。这让我想到 Agent 领域的 "Train with Environment"——既然部署时要与环境交互，那训练时就模拟环境。

背后的逻辑是：推理/融合阶段遇到的问题，可以提前到训练阶段解决。

场景 推理阶段问题 训练阶段准备
P&M 参数合并时有冲突 沿任务向量扰动，让参数在合并方向上稳定
Agent 与环境交互时泛化差 训练时模拟环境，学习环境适应能力

这个思路可推广：任何需要在推理时"组装"或"适应"的场景，都可以问一句——训练时能不能为这个组装/适应做准备？

"把两个领域的痛点互相解决"的思路：

  • CL 的痛点：推理用当前任务参数，对旧任务不友好
  • Model Merging 的痛点：要求独立训练，无法用于顺序学习场景
  • 论文发现：CL 的顺序训练让参数在更好的轨迹上（相比独立训练），而 Merging 的 post-hoc 组合机制可以借过来用

这个思路可复用：当看到两个领域目标相同但流程不同时，思考——能否把 A 的流程优势嵌入 B？关键是找到两个流程的"接口"，这里就是"训练结束后的模型参数"。

复杂公式的高效近似：

  • Hessian 难算 → 用 Fisher
  • 二次型难算 → 用有限差分
  • 3× 前向传播太慢 → 用随机采样
  • 每一步近似都保持了无偏性，同时大幅降低计算开销

9. 总结

  • 核心创新：把 Model Merging 的 post-training 组合机制引入 CL 流程，同时设计 task-vector-aligned 扰动让模型"为更好的合并而训练"。最有价值的一点是"推理时补救"的思路——承认训练会遗忘，但在推理时通过参数缩放来缓解。

  • 局限性：

    • 理论假设强（Fisher 近似 Hessian、忽略三阶项、对角 Fisher）
    • 需要存储历史 Fisher 矩阵，任务数很多时仍有内存压力（假设 ViT-B/16 约 86M 参数，20 个任务的对角 Fisher 约 6.88 GB）
    • 只在 ViT 分类任务上验证，泛化性待考察
    • 扰动的方差分析缺失

  • 改进方向：

    • 探索更精确但高效的 curvature 近似（如 K-FAC）
    • 做闭式解 α* vs 网格搜索真正最优 α 的对比实验
    • 与 EMA 的对比实验
    • 扩展到 LLM 的 CL 场景
