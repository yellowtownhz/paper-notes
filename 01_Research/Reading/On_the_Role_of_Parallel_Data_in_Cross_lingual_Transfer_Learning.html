2. 关键问题：平行数据对跨语言迁移的贡献来源是什么？

核心动机

多语言模型通常在拼接的单语语料上预训练，然后在英语下游数据上微调，实现零样本跨语言迁移。已有研究表明引入平行数据能提升跨语言迁移效果，但根本原因尚不清楚：

"Is the data itself that matters, given the additional information that it contains? Or is it the explicit modeling of parallel interactions that is important?"

两种假设：

  1. 数据假设：平行数据本身包含额外信息（如对齐知识），直接提升模型能力
  2. 建模假设：对平行交互的显式建模才是关键，即使数据是合成的也有效

研究问题

  • 平行数据的改进效果来自数据本身，还是对平行交互的建模？
  • 合成平行数据（无监督MT生成）能否替代真实平行数据？

核心模块：四种平行数据来源

1. Gold (真实平行数据)

  • 来源：IWSLT, WMT 及其他平行语料库的组合

2. Supervised MT (有监督机器翻译)

  • 模型：420M参数的 M2M-100 模型
  • 数据生成：翻译 CC-100 的随机子集

3. Unsupervised MT (无监督机器翻译) — 关键创新

这是论文验证"建模假设"的核心实验设计：

  • 初始化：使用 XLM-R base 初始化无监督MT模型
  • 训练方法：迭代式去噪自编码 + 回翻译
  • 数据来源：仅使用与XLM-R预训练相同的单语数据，无任何额外数据
  • 训练规模：750k iterations，batch size 128k tokens

4. Dictionary (词典替换)

  • 词典来源：MUSE词典 + 词对齐器提取的词典
  • 替换策略：以0.4概率用词典中对应词替换原词

方法细节：两种融入方式

Pretraining Incorporation

  1. 以 XLM-R base 为起点
  2. 继续预训练70k steps，batch size 64k tokens
  3. 目标函数：70% MLM + 30% TLM

Finetuning Incorporation

  1. 将英语训练数据通过MT翻译到目标语言
  2. 在所有语言的组合数据上微调 XLM-R

数学形式化

Translation Language Modeling (TLM) 目标函数：

$$\mathcal{L}_{TLM} = -\sum_{i \in M} \log P(x_i^{(1)}, x_i^{(2)} | \tilde{x}^{(1)}, \tilde{x}^{(2)}; \theta)$$

其中：

  • $x^{(1)}, x^{(2)}$：平行句对的两种语言表示
  • $M$：被掩码的token位置集合
  • $\tilde{x}^{(1)}, \tilde{x}^{(2)}$：掩码后的序列

TLM 实现细节

来源：Conneau & Lample (2019). Cross-lingual Language Model Pretraining. NeurIPS 2019. Cross_lingual_Language_Model_Pretraining-TLM

平行句对拼接格式

输入序列格式为：

[/s] [source_tokens] [/s] [/s] [target_tokens] [/s]

示例（英法平行句对）：

[/s] the  blue [/s] [/s] rideaux étaient  [/s]
  • [/s] 作为句子的起始/结束标记
  • 两个连续的 [/s] 分隔源语言和目标语言

Attention 设置

两种语言的 token 可以互相 attend（full attention）

原文说明：

"To predict a word masked in an English sentence, the model can either attend to surrounding English words or to the French translation"

这是 TLM 的核心设计——预测 masked token 时可以参考整个平行句对，鼓励模型学习跨语言对齐。

Language Embedding 编码

组件 说明
方式 与 Token Embedding、Position Embedding 相加
实现 每种语言有唯一的 language embedding
示例 英语 tokens 用 en embedding，法语 tokens 用 fr embedding

重要细节：目标语言句子的 Position Embedding 从 0 重新开始（而非接续源语言位置），便于学习平行对齐。

Mask 策略

沿用 MLM 的 mask 策略（15% tokens，80%/10%/10% 替换规则），区别在于预测时可以 attend 到整个平行句对。

5. 关键实验：合成平行数据有效，但真实数据更优

主实验结果：Pretraining Incorporation (Table 1)

方法 XNLI avg XQuAD avg WikiANN avg
XLM-R (baseline) 73.3 77.5 63.5
+ Unsup MT 75.2 (+1.9) 79.0 (+1.5) 64.9 (+1.4)
+ Sup MT 76.0 (+2.7) 80.7 (+3.2) 66.1 (+2.6)
+ Gold 76.4 (+3.1) 80.6 (+3.1) 66.2 (+2.7)

关键发现：

  1. 无监督MT显著优于baseline：证明仅通过对单语数据的建模就能获得改进
  2. 有监督MT≈真实平行数据：XNLI上76.0 vs 76.4，差距仅0.4
  3. 英语性能无变化：说明改进的是跨语言能力而非一般质量

任务差异分析

任务 建模 vs 数据
XNLI 建模更重要
WikiANN 建模更重要
XQuAD 数据更重要

可能原因：XQuAD作为QA任务对跨语言对齐要求更高，真实平行数据的对齐质量更关键。

消融实验：为什么改进来自平行数据而非额外训练？

两个证据：

  1. 训练量对比：XLM-R原始训练13k GPU days，继续预训练仅96 GPU days (0.7%)
  2. 语言特定改进：所有目标语言改进，但英语无改进

6. Golden Case：无监督MT生成的平行数据如何改进跨语言迁移

选择案例：XNLI任务，Swahili语言

Swahili XNLI准确率提升：62.2 → 67.8 (+5.6)

处理流程

Step 1: 无监督MT生成Swahili平行数据

  • 训练数据来源：CC-100 Swahili单语文本（200MB）
  • 方法：迭代去噪自编码 + 回翻译

Step 2: Pretraining阶段融入

  • TLM训练：70% MLM + 30% TLM
  • 关键决策：模型学习到跨语言对齐信号

Step 3: 下游任务微调

  • 英语微调后零样本迁移到Swahili

最终输出对比

阶段 Swahili XNLI准确率 vs Baseline
XLM-R baseline 62.2 –
+ Unsup MT 67.8 +5.6
+ Sup MT 70.1 +7.9
+ Gold 70.4 +8.2

案例分析：无监督MT仅用与预训练相同的单语数据，就将Swahili性能提升5.6个点。

8. 总结

核心创新

最重要的发现：即使是仅由单语数据生成的合成平行数据，也能显著改进跨语言迁移性能。这证明了对平行交互的显式建模比数据来源更关键。

局限性

  1. 范式限制：仅研究pretrain-finetune，未涉及prompt-based/few-shot
  2. 语言覆盖：仅9种语言
  3. 任务类型：未研究生成任务（如翻译、摘要）
  4. [?] 机制分析缺失：未深入分析TLM如何改变多语言表示空间

改进方向

  1. 探索无监督MT的最优训练策略
  2. 扩展到LLM的in-context learning设置
  3. 分析TLM如何改变表示空间
