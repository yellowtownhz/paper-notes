2. 关键问题：如何在无需外部教师模型的情况下实现 On-Policy 密集监督

  • 动机: 现有推理后训练方法存在明显局限：

    • RLVR (如 GRPO): 使用 on-policy 数据，但只有序列级稀疏奖励，无法指导每个 token 的生成
    • Off-Policy Distillation/SFT: 提供密集 token 级信号，但存在训练-推理分布不匹配问题
    • On-Policy Distillation: 结合两者优势，但需要额外的大型教师模型

  • 核心洞见: 一个足够强的 LLM 可以通过条件化不同信息来同时扮演教师和学生——教师看到 ground-truth 答案作为特权信息，学生只看到问题

3. 数据集：数学推理任务的标准 benchmark

训练数据:

  • 使用包含验证答案的数学推理数据集 $\mathcal{S} = \{(x_i, y_i^\star)\}_{i=1}^N$
  • $x$: 问题，$y^\star$: 验证过的推理轨迹

评估数据 (4个竞赛级数学推理任务):

  • AIME (American Invitational Mathematics Examination)
  • AMC (American Mathematics Competition)
  • MATH benchmark
  • Minerva benchmark

4. 关键方法：On-Policy Self-Distillation (OPSD)

核心思想: 单一模型同时扮演教师和学生角色。学生策略仅基于问题生成 rollout，教师策略额外条件化于 ground-truth 答案。在学生自己生成的轨迹上最小化两者之间的 per-token divergence。

(1) 框架设计

给定推理数据集 $\mathcal{S} = \{(x_i, y_i^\star)\}_{i=1}^N$，从同一个 LLM 实例化两个策略：

  • Student Policy: $p_S(\cdot \mid x)$ — 只看到问题
  • Teacher Policy: $p_T(\cdot \mid x, y^\star)$ — 额外看到 ground-truth 答案

(2) 训练流程

  1. 学生采样: 学生生成 on-policy 响应 $\hat{y} \sim p_S(\cdot \mid x)$
  2. 双策略评估: 两个策略都在学生轨迹上计算 next-token 分布
    • Student: $p_S(\cdot \mid x, \hat{y}_{<n})$
    • Teacher: $p_T(\cdot \mid x, y^\star, \hat{y}_{<n})$
  3. 梯度更新: 只通过学生的 logits 反向传播

(3) 损失函数

$$\mathcal{L}_{\text{OPSD}}(\theta) = \mathbb{E}_{(x,y^\star)\sim\mathcal{S}} \; \mathbb{E}_{\hat{y}\sim p_S(\cdot\mid x)} \sum_{n=1}^{|\hat{y}|} D\!\left(p_T(\cdot\mid x,y^\star,\hat{y}_{<n}) \;\|\; p_S(\cdot\mid x,\hat{y}_{<n})\right)$$

其中 $D$ 是 token 级 divergence（如 KL divergence）。

(4) 与 On-Policy Distillation 的对比

传统 On-Policy Distillation: $$\mathcal{L}_{\text{On-Policy Distillation}}(\theta) = \mathbb{E}_{x\sim\mathcal{S}} \left[ \mathbb{E}_{\hat{y}\sim p_S(\cdot|x)} \left[ D(p_T \| p_S)(\hat{y}|x) \right] \right]$$

关键区别: OPSD 不需要外部教师模型，而是通过 ground-truth 条件化创造"特权信息"来区分教师和学生。

(5) 与 GRPO 的对比

GRPO 的核心问题：

  1. 稀疏奖励: 只有序列级 binary reward，所有 token 共享相同的 advantage
  2. 零梯度问题: 当所有采样响应 reward 相同时（全对或全错），advantage 归零

GRPO Advantage 计算: $$A_i = \frac{r_i - \text{mean}(\{r_j\}_{j=1}^G)}{\text{std}(\{r_j\}_{j=1}^G)}$$

(6) 背景：Off-Policy vs On-Policy Distillation

Off-Policy Distillation (传统 SFT): $$\mathcal{L}_{\text{Supervised Distillation}}(\theta) = \mathbb{E}_{(x,y)\sim\mathcal{S}} \left[ D(p_T \| p_S)(y|x) \right]$$

问题：训练时学生看到的是固定数据集的 $y_{<n}$，推理时看到的是自己生成的 partial sequences，导致 distribution mismatch 和累积误差。

On-Policy Distillation 通过在学生自己的 rollouts 上训练来解决这个问题，连接到 imitation learning (DAgger)。

6. Golden Case：OPSD 的工作机制

场景：数学问题求解

问题 x: "求解方程 2x + 5 = 13"
Ground-truth y*: "首先将 5 移到右边得 2x = 8，然后两边除以 2 得 x = 4"

学生 rollout (不看答案):
"让我解这个方程...2x + 5 = 13...减去 5...2x = 8...除以 2..."

Teacher 分布 (看到 y*):  
- 在每个 token 位置，知道正确答案应该是什么
- 倾向于生成更接近正确推理链的 tokens

Student 分布 (只看问题):
- 只能根据问题和已生成内容来预测
- 可能偏离正确路径

训练目标：让 Student 分布逼近 Teacher 分布

为什么有效？

  1. 特权信息差异: Teacher 有"答案"作为额外上下文，即使在学生的错误 rollout 上，也能提供"正确方向"的指导
  2. On-Policy 训练: 在学生自己的分布上训练，避免 exposure bias
  3. Dense Feedback: 每个 token 都有监督信号，不仅仅是最终答案对错

7. Insights：Self-Distillation 是 On-Policy Distillation 的无外部教师版本

  1. 特权信息的巧妙利用: Ground-truth 答案作为"特权信息"创造教师-学生差异，无需额外模型
  2. 密集信号 + On-Policy 的完美结合: 同时解决 GRPO 的稀疏奖励问题和 SFT 的 distribution mismatch 问题
  3. Token Efficiency: 8× 的效率提升意味着相同计算预算下可以做更多探索
  4. 模型容量要求: Self-distillation 需要模型有足够能力"理解"特权信息并生成有意义的指导

8. 个人总结

核心局限：Ground-Truth 依赖导致无法解决 Open Problem

这篇论文的整体价值有限。OPSD 的核心假设是存在验证过的推理轨迹 $y^\star$，这意味着：

  • 只适用于封闭问题: 数学、代码等有"标准答案"的任务
  • 对开放性问题失效: 创意写作、复杂推理、多解问题完全无法使用
  • 本质是路径优化: 在"已知答案"的前提下优化"到达答案的路径"，而非真正的推理能力提升

有趣的 Idea：信息差制造的"共谋"结构

通过制造学生和老师之间的信息差的设计比较有意思，有点纳什不均衡的意思。但仔细分析，这里没有博弈的意味：

结构类型 目标函数 策略关系 交互模式
纳什均衡（博弈） 各自独立 相互影响 对抗/竞争
OPSD（共谋） 完全一致 单向模仿 Teacher 是看得更多的 Student

这更像是 Privileged Information Learning 或 Learning with Hints，Teacher 没有自己的"利益"，只是作为一个 oracle 指引方向。本质上是 Student 和 Teacher 在"共谋"达成同一个目标。

与 Self-Improving Pretraining 的对比

与 Self-Improving_Pretraining-Post-trained_Models_Bootstrap 相比：

  • Self-Improving Pretraining 使用外部的后训练模型作为 Judge/Rewriter
  • OPSD 让同一个模型自己教自己，无需外部模型
  • 两者都在解决"如何用更强的信号指导训练"的问题，但层次不同：一个在预训练，一个在后训练

可能的改进方向

如果要让这个框架处理 open problem，可能需要：

  1. 引入对抗机制: 让 Teacher 和 Student 有不同的目标，形成真正的博弈
  2. 替代 Ground-Truth: 用 Judge 模型或 self-consistency 来估计答案质量
  3. 多解空间探索: 允许多个"正确"轨迹，而非单一 $y^\star$

    目标 提升推理能力 防止灾难性遗忘
    解决的问题 GRPO的稀疏奖励 SFT的分布剧变→遗忘
    教师更新 不单独更新（共享参数） EMA更新 (关键稳定机制)
