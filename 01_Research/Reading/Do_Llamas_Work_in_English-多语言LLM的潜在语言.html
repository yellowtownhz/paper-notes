2. 关键问题：多语言LLM是否在内部使用英语作为枢纽语言？

这篇文章的核心动机是探究一个被广泛讨论但未被实证验证的假设：以英语为主导训练数据的多语言模型，在处理非英语任务时，是否会在内部"转道"经过英语表示？

关注的具体问题：

  • 当模型接收非英语输入时，其中间层的潜在表示更接近哪种语言？
  • 如果存在英语偏向，这种偏向的机制是什么？
  • 这种偏向对模型的语言学偏见有什么影响？

这是一个关键问题，因为：

  1. 如果 LLM 隐式使用英语作为枢纽，可能导致 Anglocentric（英语中心主义）偏见
  2. 影响模型在词汇、语法、隐喻等方面的倾向性
  3. 可能塑造更深层次的行为，如情感立场和时间推理

词汇枢纽 vs 语义枢纽： 论文明确区分了这两种 pivot。原文指出：

"English could still be seen as a pivot language, but in a semantic, rather than a purely lexical, sense."

英语作为枢纽语言，是在语义层面而非词汇层面起作用。模型的内部通用语言不是英语本身，而是偏向英语的概念。

3. 数据集：精心设计的单token任务，确保语言可归因

任务设计原则

为确保 next token 可以被无歧义地归因到特定语言，作者设计了三类任务，每类任务都保证正确答案是一个单 token：

  • 翻译任务 (Translation Task): 将非英语单词翻译到目标语言
  • 重复任务 (Repetition Task): 简单复制最后一个单词
  • 完形填空任务 (Cloze Task): 填充句子中被遮蔽的单词

数据规模

语言 翻译任务总数 单token数 重复任务 完形填空
中文(ZH) 353 353 (100%) 139 139
德语(DE) 287 126 (44%) 104 104
法语(FR) 162 88 (54%) 56 56
俄语(RU) 324 45 (14%) 115 115

数据预处理：

  • 中文字符特意选择单token词汇，确保语言归因的清晰性
  • 使用 DeepL 进行跨语言翻译，并过滤掉在英语和目标语言间共享 token 前缀的词汇
  • 完形填空任务使用 GPT-4 生成英文例句后翻译

数据来源：完全自建数据集，非标准 benchmark。原文说明：

"We scan Llama-2's vocabulary for single-token Chinese words... We work with 139 Chinese, 104 German, 56 French, and 115 Russian words."

4. 关键方法：Logit Lens 与高维几何分析

整体架构

研究框架包含两个互补的分析视角：

  1. 概率视角（Logit Lens）：将中间层潜在向量提前解码为 token 分布
  2. 几何视角（高维空间分析）：直接分析潜在向量在欧几里得空间中的轨迹

核心技术：Logit Lens

"Prematurely decoding tokens from latents this way, a method called the logit lens, can facilitate the inspection and interpretation of the internal state of transformers."

原理： 在 Transformer 中，每个输入 token 的嵌入向量逐层变换但保持形状不变。Logit Lens 的核心思想是在中间层（而非仅最后一层）应用 unembedding 操作，将潜在向量映射到 token 分布：

$$z_i = Uh_i^{(m)}$$

其中：

  • $U \in \mathbb{R}^{v \times d}$ 是 unembedding 矩阵
  • $h_i^{(j)}$ 是第 j 层位置 i 的潜在向量
  • $v = 32,000$ 是词汇表大小

语言概率定义： $$P(\text{lang}=\ell|h_n^{(j)}) := P(x_{n+1} = t_\ell|h_n^{(j)})$$

其中 $t_\ell$ 是正确答案在语言 $\ell$ 中的单 token 版本。

核心指标：Token Energy

为衡量潜在向量与"token 子空间"的对齐程度，作者提出 Token Energy 指标：

$$E(h)_2 = \frac{\frac{1}{v^2}\|\hat{U}h\|^2_F}{\frac{1}{v^2}\|\hat{U}\hat{U}^\top\|^2_F}$$

其中 $\hat{U}$ 是行归一化后的 unembedding 矩阵。

Token Energy 的物理意义：

  • 衡量潜在向量的"能量"有多少转化为 logit 分数
  • 高 Token Energy = 潜在向量与 token 嵌入对齐，适合直接预测
  • 低 Token Energy = 潜在向量包含与输出无关的信息

可视化方法：多维缩放 (MDS)

使用 MDS 将高维潜在向量和 token 嵌入投影到 2D 空间，可视化前向传播的轨迹：

$$d(h_n, t) = -\log P(x_{n+1} = t|h_n)$$

距离定义为负对数似然，保留概率关系。

与已有方法的区别

为何选择 Logit Lens 而非 Tuned Lens？

"The latter would defeat our purpose of understanding whether Llama-2, when prompted in non-English, takes a detour via English internal states before outputting non-English text."

Tuned Lens 通过训练仿射映射来优化中间层预测，这会"优化掉"我们想观察的信号——即英语转道现象。因此本研究坚持使用 Logit Lens。

Token Energy 的物理意义：

  • 衡量潜在向量的"能量"有多少转化为 logit 分数
  • 高 Token Energy = 潜在向量与 token 嵌入对齐，适合直接预测
  • 低 Token Energy = 潜在向量包含与输出无关的信息

分母含义：$\|\hat{U}\hat{U}^\top\|^2_F$ 是 token 嵌入矩阵的 Frobenius 范数平方，用于归一化。论文给出了完整的归一化公式： $$E(h)^2 = \frac{(1/v)\|\hat{U}h\|_2^2/\|h\|_2^2}{(1/v^2)\|\hat{U}\hat{U}^\top\|_F^2} = \frac{v}{d} \cdot \frac{\|\hat{U}h\|_2^2}{\|\hat{U}\hat{U}^\top\|_F^2}$$

5. 关键实验：三阶段处理模式与英语偏向

主实验结果

核心发现：所有模型规模（7B/13B/70B）和所有任务（翻译/重复/完形填空）均呈现一致的三阶段模式：

阶段 层范围 (70B) 熵 Token Energy 主导语言
Phase 1 1-40 ~14 bits（近均匀分布） ~20%（低） 无
Phase 2 41-70 1-2 bits（低） ~20%（低） 英语
Phase 3 71-80 低 20%→30%（高） 目标语言

具体数值（Llama-2-70B，翻译任务，中文输出）：

  • 中间层（约50层）：英语 token 概率达峰值 ~60%，中文几乎为 0
  • 最终层：中文 token 概率 >90%，英语回落
  • Token Energy 在最后 10 层从 ~20% 飙升至 ~30%

来源：Figure 2, Figure 4

消融实验

不同语言的表现（Appendix B）：

  • 德语、法语、俄语均呈现相同的"英语先出现，目标语言后出现"模式
  • 中文重复任务例外：中文和英语概率同时上升，可能因为中文 token 化更高效（100% 单 token）

低资源语言（爱沙尼亚语）：

  • 单 token 词仅 1/99
  • 重复任务表现类似中文
  • 翻译任务最终层成功率较低，但中间层仍可见英语偏向

其他模型（Mistral-7B）：

  • 表现与 Llama-2 一致，表明发现的普适性

对比实验：不同任务类型的差异

翻译任务 vs 重复任务 vs 完形填空：

任务类型 英语峰值 目标语言上升时机
翻译 明显（~60%） 最后 10 层
完形填空 明显（~50%） 最后 10 层
重复 较弱 较早（尤其中文）

解释：重复任务更偏句法层面，可能不需要深入"概念空间"，因此英语偏向较轻。

Phase 边界稳定性：边界相对稳定，但论文在讨论部分提到边界可能因 tokenization 而变化。1-40/41-70/71-80 的划分是基于 Llama-2-70B 的经验观察。

模型范围限制：论文明确说明未与其他多语言模型对比：

"we focus on the Llama-2 family of language models, which limits the claims we can make about other English-dominated models."

但 Mistral-7B 的验证表明发现具有普适性。---

6. Golden Case：法语翻译到中文的完整流程

输入样本

Français: "neige" - 中文: "雪"
Français: "montagne" - 中文: "山"
Français: "fleur" - 中文: "

目标：模型需要预测"花"（法语"fleur"的中文翻译）

处理流程

Phase 1（层 1-40）：输入空间

  • 潜在向量位于超球面"北极"，与输出 token 嵌入正交
  • Token Energy 低（~20%）
  • 熵高（~14 bits），预测近均匀分布
  • 正在处理 tokenization、整合词内 token、构建语义单元

Phase 2（层 41-70）：概念空间

  • 潜在向量旋转进入"概念空间"
  • 熵骤降（1-2 bits），语义已明确
  • 英语 "flower" 获得高概率（~60%）
  • 中文 "花" 概率仍接近 0
  • 关键洞察：概念嵌入更接近英语 token 嵌入

Phase 3（层 71-80）：输出空间

  • 潜在向量沿"赤道"旋转进入目标语言区域
  • Token Energy 飙升（20%→30%）
  • 中文 "花" 概率超越英语，最终达 >90%
  • 丢弃与输出无关的信息

关键决策点

  1. Layer ~40：从输入空间过渡到概念空间，熵骤降
  2. Layer ~50-60：英语概率达到峰值
  3. Layer ~70：开始从英语转向目标语言
  4. Layer ~75：目标语言概率超越英语

最终输出

"花"

成功预测，但经历了英语偏向的中间状态。

7. Insights：概念空间比词汇空间更根本

核心洞见

"The model's internal lingua franca is not English but concepts—concepts that are biased toward English."

关键论断：

  1. 概念空间存在：中间层存在一个抽象的"概念空间"，部分正交于语言特定的"token 空间"
  2. 英语偏向的语义本质：英语并非纯粹的词汇枢纽，而是概念空间中的语义偏向
  3. Tokenization 的影响：单 token 词比例高的语言（如中文）能更快绕过英语偏向

"语义 pivot"的精确含义：

论文区分了两种 pivot：

  • 词汇层面 pivot：中间层真的"说出"英语单词（如 "flower"）
  • 语义层面 pivot：中间层的概念表示向量恰好更接近英语 token 嵌入

这意味着：

  • 模型内部的"通用语言"不是英语的语法、价值观，而是英语 token 嵌入所锚定的概念空间
  • 英语训练数据占比高（89.70%），英语 token 嵌入被优化成最"标准"的概念锚点
  • 其他语言学习时，只需建立 概念锚点 → 目标语言词汇 的映射，这是一种信息压缩效率
  • 但这不意味着英语语法规则或价值观被内化——论文发现的是几何/表示层面的偏向

对未来工作的启发

  1. 减少英语偏向：研究不同训练数据语言分布对概念空间的影响
  2. 更公平的 tokenizer：改进 tokenizer 设计，减少对非英语语言的 token 开销
  3. 概念空间测绘：系统性研究高维概念空间的结构
  4. 偏见传播研究：英语偏向如何影响情感立场、时间推理等深层行为

8. 总结

核心创新

首次通过实证方法揭示了多语言 LLM 内部处理的三阶段模式，并提出"概念空间"理论解释英语偏向现象。Logit Lens 与 Token Energy 的结合提供了一种可复用的模型可解释性分析方法。

局限性

  1. 任务简单：仅研究单 token 预测，尚未验证于复杂任务
  2. 模型范围有限：主要研究 Llama-2 系列，闭源模型无法分析
  3. 概念空间结构不明确：对高维概念空间的理解仍有限
  4. Logit Lens 盲区：无法观测非输出相关的中间计算（如 K/Q/V 构建）

局限性与开放问题

  1. "概念空间"的定义：论文对"概念空间"的描述相对概念化，缺乏严格的数学刻画。原文定义为：

    "abstract 'concept space' where latent 'concept embeddings' are closer to those output token embeddings that can express the respective concept." 具体是什么子空间（PCA 主成分？语义子空间？）仍有待进一步研究。

  2. 因果性 vs 相关性：论文承认 Logit Lens 的局限性。在 Limitations 部分指出：

    "the logit lens grants us approximate access to the internal beliefs... everything else contained in the intermediate representations... remains hidden and only enters the logit lens-based part of our analysis as noise." Logit Lens 揭示的是中间层表示"看起来像英语"，但这是否意味着模型"真的在用英语思维"，需要更多因果干预实验验证。

  3. 统计显著性：论文在 Figure 2 等图表中展示了 "95% Gaussian confidence intervals over input texts"，表明进行了统计显著性分析。

改进方向

  1. 扩展到多 token 预测、复杂推理任务
  2. 研究不同语言比例训练数据对概念空间的影响
  3. 设计干预实验（如激活 steering）验证英语偏向的因果关系
  4. 探索是否有方法"干预"中间层，直接跳过英语偏向
