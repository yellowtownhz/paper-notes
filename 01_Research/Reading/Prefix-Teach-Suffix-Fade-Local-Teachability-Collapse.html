论文笔记: Prefix Teach, Suffix Fade — Local Teachability Collapse in Strong-to-Weak On-Policy Distillation

  • 发表时间: 2026/05/13 arXiv preprint（v1，未明确投稿目标）
  • 领域: 大模型蒸馏 / on-policy distillation (OPD)
  • 核心 setting: 强老师 → 弱学生（teacher Qwen3-30B-A3B-Instruct-2507，student Qwen3-1.7B / 4B / 8B-Non-Thinking），训练数据来自 DeepMath-103k

2. 关键问题：dense OPD 监督到底该不该铺满整条 trajectory？

Golden Case — 问题是什么？

假设 Qwen3-1.7B（student）在解一道数学题：求 $\lim_{n\to\infty} n^3 x^n(1-x)^4$（for $x \in [0,1]$）。Student roll 出了一条 ~4000 token 的推理链。Teacher（Qwen3-30B-A3B）对每个 token 打分，算出 advantage $A_t = \log p_T(y_t) - \log p_S(y_t)$。

看 trajectory 前半段：student 把问题正确切成 3 个 case（x=0, x=1, 0<x<1），对 case 3 用 ratio test 算到 $a_{n+1}/a_n = (1+1/n)^3 x \to x < 1$，得出 exponential decay。这段核心论证里，teacher 对 student 采样的不同 token 有明显的好坏偏好区分——有些 token teacher 给的 logprob 比 student 高很多，有些只高一点。Advantage 的方差大，teacher 的信号"有区分度"，student 能学到"哪些动作更好"。

但到后半段：student 开始反复重复同一个论点、出现 "Wait — no, wait."、"Actually..."、"But is it ∞? Yes... Wait — that's not helpful." 这种 self-doubt 循环。Teacher 对所有 student 可能选的 token 给的 logprob 差不多——"再说一遍"vs"换个说法再说一遍"对 teacher 来说差不多。

这里要区分两个概念：mean advantage 衡量的是"teacher 还在持有意见"（全局 disagreement），$\text{std}(A_t)$ 衡量的是"teacher 还能不能指出哪条路更好"（局部区分度）。两个东西可以独立变化。在这条 trajectory 的后半段：mean advantage 大约还在 -0.3（teacher 和 student 还在 disagree），但 $\text{std}(A_t)$ 已经从早期的 1.0+ 跌到了 0.2-0.4 区间（读图估计，Figure 1b）。论文里一个 case：log-prob correlation 从 -0.09（几乎无关）升到 0.93（高度对齐），advantage std 从 2.08 降到 0.61。

这就是 local teachability collapse：teacher 的全局指导信号（mean advantage）还在，但局部的区分能力（advantage dispersion / teacher margin）已经塌缩了。两码事。

下面两张图把"global signal 还在 vs local contrast 已塌"这件事讲得很直白：

为什么会这样？

根因在于 strong-to-weak 的能力差距。当 teacher 比 student 强太多时，到了推理链后半段，student 的 top-K 候选对 teacher 来说"都差不多"——因为 student 的能力决定了它的 reachable action space 本身就比较窄，teacher 在这个窄空间里区分不出明显的好坏。

为什么已有方法解决不了？

  • 标准 OPD：直接对整条轨迹做 dense supervision，默认所有 token 的 teacher signal 都有价值。但上面的例子说明后半段的学习信号接近噪声，优化这些噪声反而会干扰训练。
  • FastOPD（prefix OPD）：只保留前 k 个 token 的 supervision。这是一个全局硬截断，但不同 trajectory 的 teachability collapse 发生位置差异很大（论文数据：mean=0.25, median=0.13），一刀切必然有 suboptimal 的 case。
  • ExOPD：修改 OPD objective（reward extrapolation），但没考虑 signal quality 本身在衰减。

类比 RL 中的常识：outcome-driven RL 早就发现"50% 正确率的 prompt 最有用"——全对或全错的 prompt 梯度信号废了。OPD 里 dense supervision 也是同理：teacher 在某个 prefix 已经对 student 的所有候选都一视同仁了，那个位置的监督就是噪声。

一个自然的想法是：直接用 $\text{std}(A_t)$ 的衰减当截断信号。但后面会看到，这个 realized-path 统计量在训练早期不够稳定（Section 4.2.2），作者最终选了一个 state-local 的替代方案（teacher margin），效果更好（Table 2: 40.1% vs 38.8%）。

4. 关键方法：teacher 在 student top-K 上的 top1-top2 margin 当 teachability 信号，BIC 检测下降变点

Golden Case — 方法怎么跑？

还是用 $\lim_{n\to\infty} n^3 x^n(1-x)^4$ 那条 trajectory。

Step 1: 计算 teacher margin。在每个 prefix 位置，拿出 student 的 top-4 候选 token（$C_t$），让 teacher 对这 4 个 token 排名。取 teacher 排名第一和第二的 logprob 差值作为 margin $M_t$。前半段（case split + ratio test）这个 margin 可能是 0.5~1.0，teacher 对"student 该选哪个"有明确偏好。后半段（重复论证 + self-doubt）margin 跌到 0.05~0.1，teacher 基本分不出好坏。

Step 2: 句子级聚合。用 NLTK 做 sentence segmentation，把 token-level margin 按句子聚合（取平均再 log 平滑），得到 $S_i$。这条 trajectory 可能被切成 20 个句子，就得到 20 个 $S_i$ 值。

Step 3: BIC 变点检测。对 $\{S_1, ..., S_n\}$ 做一个"单点下降"检测——对比"全程一个均值"（$H_0$）和"某个点 $\tau$ 之后均值下降"（$H_1$）。如果 $\text{BIC}_1(\tau^*) < \text{BIC}_0$，就接受变点，保留 $\tau^*$ 之前的 supervision，之后的 mask 掉。在这条 trajectory 里，变点落在 student 写完 case split 和 exponential decay 论证之后——之后 student 开始反复重复论点，margin 曲线在这里显著下降。

Step 4: 重新加权。被 mask 掉的 token 不再参与训练，但为了保证每个 sample 的 loss 总量不变，对保留下来的 prefix 做一个 rescale：$A'_t = A_t \cdot q_t \cdot \frac{\sum l_t}{\sum l_t q_t}$。

结果：这条 trajectory 的 supervision 只集中在 teachability 高的前半段核心论证。另一条 trajectory 可能保留 40%，全看各自的 margin 曲线。

核心原则（原文）： "supervision should concentrate on trajectory regions where the teacher's feedback remains discriminative, rather than uniformly covering the entire response"

4.1 整体架构

方法不改 OPD objective 本身，只改 supervision 的 覆盖范围。是在标准 OPD 训练 loop 外面加一层 post-hoc 诊断 + loss mask。注意 release 是 post-hoc 的——必须先把整条 rollout 跑完，才能算 BIC、决定要 mask 哪段。所以本文不是 efficiency claim。

4.2 核心模块

4.2.1 标准 OPD advantage（背景）

$$A_t = \log p_T(y_t \mid x, y_{<t}) - \log p_S(y_t \mid x, y_{<t})$$
  • $A_t > 0$：teacher 比 student 更看好这个 token，student 应该提升概率
  • $A_t < 0$：反过来
  • Mean advantage 衡量全局 disagreement，std 衡量 token-level 区分度

注意这是在 sampled token $y_t$ 上算的，不是在所有候选上——这是后面 $\text{std}(A_t)$ baseline 输给 margin 的核心理由。

4.2.2 Teacher Margin（核心创新）

Motivation：$\text{std}(A_t)$ 有个根本问题——它量的是 student 实际采样到的那一条路径上的 variance。这太依赖单次采样的随机性了，尤其训练早期 student 还没对齐 teacher，一条 rollout 上的 dispersion 波动很大。

我们真正想知道的是另一个问题："在当前 prefix state 下，看 student 的所有可达候选，teacher 能不能做出清晰的排名？" 这是个 state-local 的 ranking question，不依赖采样路径。

具体做法：在每个 prefix $(x, y_{<t})$：

  1. 取 student 的 top-K 候选集（student 的"可达 action 空间"）：$\mathcal{C}_t = \text{TopK}_a \; p_S(a \mid x, y_{<t})$
  2. 用 teacher logprob 对 $\mathcal{C}_t$ 排名，取前两名：
    • $a_t^{(1)} = \arg\max_{a \in \mathcal{C}_t} \log p_T(a \mid x, y_{<t})$
    • $a_t^{(2)} = \arg\max_{a \in \mathcal{C}_t \setminus \{a_t^{(1)}\}} \log p_T(a \mid x, y_{<t})$
  3. Nearest-competitor margin：$M_t = \log p_T(a_t^{(1)} \mid x, y_{<t}) - \log p_T(a_t^{(2)} \mid x, y_{<t})$

$M_t$ 问的是一个 state-local 的问题："在 student 的 reachable action space 里，teacher 还能不能给出清晰的偏好排序？" 如果 $M_t$ 大，说明 teacher 对"student 该选哪个 token"有明确偏好；如果 $M_t$ 小，teacher 对 student 的候选基本无所谓——dense supervision 的 action-dependent signal 就弱了。

这里有个 subtle 但重要的区分：$\text{std}(A_t)$ 评的是 sampled trajectory 上的 dispersion——诊断什么有问题的 symptom；$M_t$ 评的是 state-local 的 ranking question——诊断如何修复的 control signal。对症 ≠ 对因。 论文 Table 2 验证了：$\text{std}(A_t)$ release 虽然也 beat full OPD（38.8%），但比 teacher margin 差 1.3 点（40.1%），印证了 state-local margin 比 realized-path dispersion 更 robust。

4.2.3 句子级聚合

$$S_i = \log\left(1 + \frac{1}{|\mathcal{B}_i|} \sum_{t \in \mathcal{B}_i} M_t\right)$$
  • $\mathcal{B}_i$：第 $i$ 个句子 segment 的 token 集合
  • log1p 是为了数值稳定
  • 用 NLTK sentence segmentation 而不是固定 bin，因为 trajectory 长度差异太大，而且对 reasoning trace 来说"换段落"和"开始新论证"通常重合

4.2.4 Profiled RSS-BIC 变点检测

Motivation：需要自动化判断"margin 在哪里开始显著下降"，而不是手动设阈值。

两模型比较：

  • $H_0$（无变化）：$S_i = \mu + \epsilon_i$，参数数 $k_0 = 1$
  • $H_1(\tau)$（单点下降）：$S_i = \mu_{\text{pre}} + \epsilon_i$（$i \le \tau$）或 $S_i = \mu_{\text{post}} + \epsilon_i$（$i > \tau$），参数数 $k_1 = 3$（两个均值 + 一个变点），要求 $\mu_{\text{pre}} > \mu_{\text{post}}$（只接受向下变点）

BIC 准则（profiled，noise variance 吸收进 RSS）：

$$\text{BIC}_0 = n \log\left(\frac{\text{RSS}_0 + \epsilon}{n}\right) + k_0 \log n$$
$$\text{BIC}_1(\tau) = n \log\left(\frac{\text{RSS}_1(\tau) + \epsilon}{n}\right) + k_1 \log n$$

选取满足 $\bar{S}_{>\tau} < \bar{S}_{\le\tau}$ 的 $\tau$ 中 BIC 最小的：

$$\tau^* = \arg\min_{\tau: \bar{S}_{>\tau} < \bar{S}_{\le\tau}} \text{BIC}_1(\tau)$$

如果 $\text{BIC}_1(\tau^*) < \text{BIC}_0$，接受变点；否则 fallback 到 full OPD——这是个保守安全网，避免 BIC 误判时损害训练。

4.2.5 Mass-Preserving Rescale

$$A'_t = A_t \cdot q_t \cdot \frac{\sum_t l_t}{\sum_t l_t q_t}$$
  • $q_t \in \{0, 1\}$：prefix mask（release 之前的 token = 1）
  • $l_t$：原始 loss mask
  • rescale factor 保证截断后每个 sample 的 loss 总量不变

关键设计思想：release 改的是 supervision 的位置（where），不是 supervision 的总量（how much）。如果不 rescale 直接 mask，被截断的样本贡献的总 loss 会缩小到 prefix 占比，相当于隐式给短样本更低权重，跟 baseline 不公平。

值得注意的是，rescale 后每个保留 token 的梯度幅度被乘了 $(\sum l_t)/(\sum l_t \cdot q_t) > 1$——等价于"把这条样本应得的总梯度预算压到 prefix 里"。论文没做 mask-only vs mask+rescale 的解耦实验（见 Section 6.1 Comments），所以涨分的 driver 到底是"砍掉垃圾后缀"还是"放大好前缀梯度"，没法区分。

4.3 SNR 视角的理论 motivation（Appendix A.2）

核心思想很简单：如果 suffix 贡献的噪声比信号多，砍掉它就提升整个 update 的信噪比。下面的形式化是这個直觉的推导。

用 Cauchy inequality 可以推导：

$$\|\tilde{g}_t\|^2 \le \text{Var}_{a \sim \pi_t}(A_t(a)) \cdot \mathbb{E}_{a \sim \pi_t}\|s_t(a)\|^2$$

其中 $\tilde{g}_t$ 是去掉 action-independent baseline 后的 informative gradient component。这说的是：如果 teacher 的 advantage 在 student reachable set 上的 variance 小，那 policy update 的 informative part 就小。

SNR 视角：把 update 拆成 prefix P 和 released suffix R：

$$\text{SNR}_{\text{full}} = \frac{(m_P + m_R)^2}{v_P + v_R}, \quad \text{SNR}_{\text{release}} = \frac{m_P^2}{v_P}$$

Release 对 SNR 有利，当且仅当 suffix 的 variance/signal ratio 足够差：$v_R/v_P \ge 2(m_R/m_P) + (m_R/m_P)^2$。

不过这个论证是 hand-wavy 的——Cauchy-Schwarz 是用 $\text{Var}_{\pi_t}(A_t(a))$ 做 upper bound 的，但实际方法用的是 top1-top2 margin，这中间的 theory-to-method gap 没说清楚。而且 SNR 的 sufficient condition 没说什么时候成立。

几个 take-away：

  • Full OPD 不是上限：所有 fixed-prefix（1024/2048/4096/8192）都比 full OPD 强，说明"砍掉后半段"本身就有帮助。但 fixed-prefix 的最优长度因 benchmark 而异（4096 在 AVG 上最好但 GPQA 比 2048 差），需要全局调参。
  • Trajectory-specific 比 fixed prefix 好：40.1 vs best fixed 39.4，且不需要调全局 prefix length。
  • Random release 是关键控制实验：保留了 batch 级 release point 分布，但打乱了"哪条 trajectory 拿哪个 release point"。结果掉到 38.0%，证明 gain 不来自"平均砍多少 token"，而来自 trajectory-specific 的耦合。有意思的是 Random release 比 full OPD 还高 1.2 点——说明单纯减少 supervision 量本身就有点用（可能是 SNR 改善或者正则化效应），但比 trajectory-specific 又差 2.1 点，耦合到 trajectory 才是大头。
  • GPQA（OOD）的 framing 要小心：
    • 跟 OPD baseline 比，Ours 42.4 vs 40.7 = +1.7 点，幅度并不戏剧性
    • 跟 ExOPD 比，Ours 42.4 vs 36.6 = +5.8 点——但这部分主要是 ExOPD 自己 OOD 掉了（"改 objective 易伤 OOD"是个独立 finding）
    • 所以"better preserves OOD"的准确理解是："vs OPD 持平略涨；vs ExOPD 这种改 objective 路线则避免了大幅退化"

5.7 Release 案例详解（Appendix A.4）

以 $\lim_{n\to\infty} n^3 x^n(1-x)^4$（$x \in [0,1]$）为例，看 release rule 在一条真实 trajectory 上做了什么。

Pre-release（蓝色，被监督）：模型把问题切成 3 个 case（x=0, x=1, 0<x<1），case 3 用 ratio test 算出 exponential decay。核心论证已经搭好，结论 0 已可下。

Release point：BIC 检测到 margin curve 在这里显著下降。

Post-release（红色，被 mask）：模型开始自言自语——重新写一遍指数衰减论证、反复 toggle "Wait — no, wait."、把 $x=1/2$, $x=1/10$ 的特殊情况再列一遍、同样的结论 0 说了至少 4 遍。Teacher 对这些"再说一遍"vs"换个说法再说一遍"的候选无法做出锐利偏好排序，margin 塌缩。

6. Insights

6.1 对论文本身的 Comments

反直觉的点：

  1. "teacher mean advantage 非零 ≠ teacher feedback 有用"——这是文章最 sharp 的洞见。我自己一开始也会默认"只要 teacher 还在反对 student，监督就有信号"。但 mean advantage 反映的是"全局还有多少 disagreement"，sample-level 的可学习性需要 dispersion 或 margin 这种局部 contrast。Figure 1 (a)(b) 就是把这个"global signal exists"vs"local teachability"分开看，简单粗暴但有说服力。

  2. $\text{std}(A_t)$ 是 symptom，$M_t$ 是 control signal——作者明确区分了 sampled-path dispersion（用来诊断什么有问题）vs state-local margin（用来决策如何修复），并且实验上 $\text{std}(A_t)$ release 比 margin release 差 1.3 点。这个区分很 subtle 但重要。如果让我来做，我大概率会直接用 $\text{std}(A_t)$ 当 release 信号——因为它最直接对应 motivation 里的 dispersion 衰减。但作者意识到 sampled-path dispersion 在训练早期不稳定，改用 state-local 的 top-K margin。对症 ≠ 对因。

  3. Random release control 的实验设计——保留了"砍多少"的批次分布，只打乱"哪条 trajectory 拿哪个 release point"。结果掉 2.1 点直接证明耦合到 trajectory 是必要的。当你想证明"X 的具体形式重要"而不只是"X 的存在重要"时，构造一个保留 X 的边际分布、但破坏 X 的实例对应关系的 control——这是一个可以复用的实验范式。

做得不太好 / 可质疑的点：

  1. 只训 100 步——最大的实证短板。Ours 40.1 vs Fixed-prefix-4096 39.4 仅差 0.7 点，AIME25 / HMMT 这种 32 sample/题的 setup，估计随机波动至少 ±1 分。"consistently outperforms"在 8B 上只差 +0.5 vs FastOPD（AVG），且 AIME25/HMMT-Feb 上还略输——很可能在 noise 范围。而且 100 步是否够也是个问号——长训练可能让 student distribution 跟 teacher 拉近，late-segment 也变得 teachable，跟 $\text{std}(A_t)$ baseline 在训练后期可能更稳是联动的问题。

  2. Loss mass rescale 是真正的 driver 吗？ 论文没做 mask-only vs mask+rescale 的解耦实验。更严重的是：median release position 是 0.13，意味着对 median trajectory 来说 rescale factor 约 8x——每个保留 token 上的梯度被放大了 8 倍。如果 rescale 才是真正的 driver，那贡献就不是"noise removal"而是"gradient concentration"。

  3. MoE teacher 是一个未控制的 confound：Teacher 是 Qwen3-30B-A3B，只有 3B active parameters。"Local teachability collapse"可能只在 teacher 有效参数量接近 student 时才出现（3B active vs 1.7B student，只差 ~2x），而不是"strong-to-weak OPD"的一般性质。论文没讨论。

  4. 每个 prompt 只做 1 次 rollout：release point 基于 N=1 的单次随机采样，没有 stochasticity averaging。

  5. 为什么是 top1-top2 margin 而不是 Var？ 作者提到可以直接算 $\text{Var}_{C_t}(A_t(a))$，cost 差不多。而且 Appendix A.2 的 Cauchy 不等式是用 $\text{Var}_{\pi_t}(A_t(a))$ 做 upper bound 的——但实际方法用的是 margin。Theory-to-method gap 没说清楚。

  6. BIC 的假设：高斯噪声 + 单点变点。如果 teachability 是渐进式衰减呢？"只检测 single drop"对"先 collapse 再 recover"的 trajectory 会误判。

  7. 缺少 fixed-50% truncation baseline：Fixed-prefix-4096 已经拿到 39.4%（只差 0.7 pts），如果简单的 fixed-50% 截断也能涨 ~2 pts，那 BIC + margin 的整套 machinery 可能是 overkill。

6.3 研究品味

  1. 诊断 → 操作化 → 验证的链条非常完整。Section 3 先用 Figure 1 把现象说清楚（"global signal vs local contrast"），再 operationalize 成 BIC release rule。Section 4 的实验顺序也好：先证 release 规则有用，再证 trajectory-specific 必要（random release control），再做 sensitivity check，最后 scaling。每一步都在回答一个明确的 what-if 问题，不是堆数据。

  2. 挑一个反直觉的小 finding 当主线。"地基"就一个观察：mean advantage 还在但 std 衰减了。围绕这个观察展开整套方法和实验。这种"小切口、深挖掘"的论文形态比"我提出了新 OPD framework with multiple components"更容易让人记住。有一个 take-home message 比有十个还重要。

  3. BIC 作为 heuristic 的选择比较 pragmatic——不需要调 threshold，直接比两个模型的好坏。虽然不是理论最优，但足够 simple 和 interpretable。这种"先分析问题，再设计 simple rule，最后 empirical validate"的路径，比一上来就 propose 一个 end-to-end learnable truncation module 要更 solid。
