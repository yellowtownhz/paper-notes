ULTRA：从动作跟踪到稀疏目标驱动的人形全身控制

最值得记住的判断：ULTRA 把接触稳定的动作先验，与部署时可变的目标和感知输入接起来了；这种统一有用，但并非免费。 它在偏离示范的目标上受益于 RL 微调，同时牺牲部分分布内轨迹跟踪精度。真实机器人验证了第一视角搬运的可行性，距离开放环境中的通用自主操作仍有明显边界。

1. 背景信息

  • 作者与团队：Xialin He、Sirui Xu 等，University of Illinois Urbana-Champaign。
  • 阅读版本：2026-03-03 发布的 arXiv v1，阅读覆盖正文与附录；不据此判断后续版本或会议录用状态。
  • 原始资料：论文全文 · 项目与演示。本笔记未核查代码实现，也未独立复现实验。

2. 关键问题：没有完整动作剧本，机器人还能把箱子搬到目标处吗？

Golden Case：双手提起并搬运箱子。 这是论文实际测试的任务类型。人的动作捕捉记录给出了身体和箱子的完整轨迹，但直接把人体姿态映射到 G1 上，会遇到两层困难。

第一层是动作看起来对，接触却不对：人和机器人的比例、关节限制不同，逐关节复刻可能让脚滑动、手离开箱子。第二层是跟踪成功不等于会完成目标：部署时操作者通过键盘指定箱子的未来目标位姿，并没有每一帧身体如何移动的参考。机器人还可能只能从头部深度点云估计箱子位置，必须自行决定迈步、弯腰和维持接触的过程。（§I、§V-E）

因此，这篇论文同时处理两个瓶颈：把人类示范变成物理可执行的数据，以及把依赖完整参考的技能变成可接受稀疏目标的闭环控制。这里的“多模态”主要指本体感觉、物体状态、点云和不同粒度的控制目标，不是语言—视觉大模型控制。

3. 关键方法：先学能执行的动作，再逐步撤掉特权信息与逐帧参考

沿着搬箱子案例，整个流程如下：

  1. 人类示范 → G1 仿真轨迹：RL 重定向器读取人体与物体轨迹，在仿真中寻找既接近动作意图、又保持手箱接触的机器人动作。
  2. G1 轨迹 → 特权教师：教师看到完整状态与密集参考，学习在实际控制接口、随机物理参数和外部扰动下稳定跟踪。
  3. 教师 → 多模态学生：训练时逐步遮掉部分目标和观测；学生通过可用信息预测技能潜变量，再输出关节目标。
  4. 学生 → 稀疏目标执行：对偏移后的目标与初始状态做 RL 微调。部署时只给本体感觉、箱子点云和目标，学生用自己的先验生成动作，经 PD 控制器驱动关节；不再需要教师或测试时参考动作。（§IV、Fig. 2）

来源：原文 Figure 2。重点看教师与学生的输入差别：完整状态和密集参考用于训练教师，部署时学生使用现实传感和稀疏目标；这解释了为何不能把重定向器直接当部署策略。

3.1 重定向：允许身体偏离示范，优先保住交互

传统运动学重定向主要求姿态对应；ULTRA 让仿真器负责动力学与接触约束，奖励负责“想保留什么”。它只把脚和手掌的位置作为稀疏锚点，用连杆方向保持整体姿态，再加入物体运动、手掌到物体表面的距离，以及接触事件匹配奖励。对箱子来说，手是否抓住箱子，比每个身体关节是否逐帧与人一致更重要。（§IV-A）

一个策略在全部示范上训练，训练完成后还能处理轨迹各轴缩放、物体尺寸缩放，不必逐条动作重新做 RL 优化。这是它相对逐轨迹物理优化的扩展性来源。

但“物理可行”有前提。 这一阶段采用理想化低层控制，控制频率等于仿真频率，而且没有域随机化；它生成的是仿真参考，并不直接证明真实电机能忠实执行。第二阶段单独训练教师，才引入部署控制接口、执行器限制、物理随机化和扰动恢复。这解释了为什么不能直接把重定向策略拿去部署。（§IV-A/B）

3.2 学生：用 mask 表示缺失，用潜变量处理目标的不确定性

学生把不同输入编码成统一 token，并用 availability mask 告诉融合网络哪些信息存在。给出下一帧局部身体目标时，它可以精细跟踪；遮掉局部参考、保留长期物体目标时，它需要自行补全中间动作；遮掉 MoCap 物体状态、保留点云时，它从视觉几何信息执行任务。（§IV-C）

附录 C 的关键规模是：64 维技能潜变量，模态 token 为 256 维，融合 Transformer 为 2 层、4 个 attention head。PointNet 把 64 个三维点编码成点云 token。学生还使用本体感觉历史；它不是只凭单帧箱子位置预测动作。

为什么要潜变量？“把箱子放到那里”通常对应多种身体动作，目标并没有唯一指定下一帧姿态。作者让训练期的特权编码器利用完整信息辅助推断技能，同时训练仅依赖学生可见输入的 prior。正文写成潜变量 prior 与特权 residual 相加，部署时仅使用 prior。

核心蒸馏目标可按 Eq. (1) 写为：

$$ \mathcal L=\|a^{\mathrm{student}}-a^{\mathrm{teacher}}\|_2^2 +\mathcal L_{\mathrm{aux}} +\lambda_{\mathrm{KL}}D_{\mathrm{KL}}\big(q_\phi(z\mid o_s,o_T)\,\|\,p_\theta(z\mid o_s)\big). $$

动作匹配保住教师的控制方式；辅助预测要求潜变量保留被遮蔽信息中的任务线索；KL 将特权后验约束到部署可用的先验附近。否则，训练效果可能主要来自部署时不存在的信息。附录 C 还加入 prior-only 动作匹配和潜变量时间平滑，不能把实际实现理解为只有上面三个简单项。

两个避免信息丢失的细节：一是 DAgger 式采样，逐步从教师 rollout 转向学生 rollout，再向教师查询学生实际访问状态的动作；二是把密集局部目标直接旁路连接到动作解码器。精确跟踪的信息不必全部挤过随机技能瓶颈。（§IV-C）

复现时需核对原文的符号约定：正文用 residual 与 prior 的和，附录 Table F 又直接用 privileged posterior 表述 KL；Table F 总损失列出 prior-only 项，却未单列其权重。概念数据流明确，完整实现仍需代码补齐。

3.3 为什么蒸馏以后还需要 RL？

学生跟随教师访问过的状态，不代表会处理“箱子目标突然偏移”后的接触与恢复。ULTRA 微调时随机偏移物体目标、身体根部目标与初始状态，直接奖励靠近目标、逐步取得进展和最终成功。（§IV-C、附录 C/Table H）

PPO 更新的是真正部署的 prior-only 策略；保留 1/4 的并行环境做蒸馏，避免目标优化完全冲掉已有动作技能。目标相关奖励还受 mask 控制：不可见的目标不计奖励，也不纳入成功检查。它学的是针对已提供目标的行为，不能据此认为机器人会自主推断未提供的任务。

4. 数据与评价范围：规模扩增主要来自同类交互的变化

作者使用 OMOMO 人—物动作捕捉中经 InterMimic 修正的子集，聚焦 4 种箱形物体；其他物体涉及灵巧手能力。重定向后通过轨迹和物体缩放得到约 6 倍语料。跟踪 OOD 指留出的动作与新的物体尺度；目标控制 OOD 则使用随机目标偏移。（§V-A/D）

训练在 IsaacGym 中进行，目标执行另外在 MuJoCo 验证，再部署到 Unitree G1。学生蒸馏使用 4096 个并行环境；实机点云由深度反投影、前方区域裁剪、去地面、取主要点簇并降采样得到。（附录 C、§V-E）

这个感知流程依赖场景中箱子的几何可分离性。它没有证明从杂乱物体中根据语言识别目标，也没有覆盖任意形状、材质或精细手内操作。

5. 关键结果：更自由的任务接口，伴随可量化的跟踪代价

5.1 重定向确实改善接触，但不是每个指标都最优

Table II 在相同 OMOMO 子集比较 PHC、GMR、OmniRetarget 与 ULTRA。以 Largebox 为例，OmniRetarget → ULTRA 的 foot-skating duration 为 0.205 → 0.061，contact-floating duration 为 0.231 → 0.015；后者直接对应“搬运时手没有可靠贴住物体”的问题。

这里保留表中 duration 原始数值，不把它擅自换算成秒。边界同样值得看：Largebox 穿透 duration 是 0.000 → 0.008，ULTRA 并未在所有指标上胜出。更准确的结论是接触稳定性与滑步显著改善，而非彻底消除几何违规。

成功要求没有跌倒，且逐帧全局身体位置误差与物体位置误差都低于 0.3 m。（§V-C）这是轨迹执行指标，不是精密装配指标。

证据支持两点：教师蒸馏比学生直接 RL 更容易学到接触丰富的全身控制；统一 ULTRA 超过这里适配的外部跟踪基线，但相对自己的专用蒸馏学生，ID 成功率下降 19.71 个百分点，OOD 基本持平。作者将后者解释为更不依赖特定轨迹的动作先验，我认为这个解释合理，但尚不是独立机制证明。

基线比较还存在信息接口差异：作者指出 OmniRetarget 缺少显式物体观测，HDMI 在当前规模下不稳定。因此结果能支持整个系统的收益，不能单独归因于 Transformer、mask 或潜变量。本文也未提供足以逐一隔离这些组件贡献的完整消融。

5.4 真机验证了什么，又没有验证什么？

Table IV：密集参考跟踪为 19/26（73%）；MoCap 稀疏目标控制的竖直/横向成功率为 8/10、9/10；第一视角控制为 5/10、6/10。表注称每个任务重复两次。

第一视角策略运行时只依赖机载感知，但所有设置的成功评价仍使用 MoCap。这不否定策略的机载执行，只需区分控制输入与评价设备。视觉设置落后 MoCap 设置，结合作者报告的深度噪声、遮挡和抓取滑落，说明感知与接触误差仍是实际瓶颈。（§V-E、附录 D）

因此，“无需测试时参考动作”在这些稀疏目标任务上成立；“无需人提供目标”“无需场景假设”或“已经可靠完成通用长程任务”均超出证据。

6. Insights

  1. 可迁移的核心是分阶段消除训练—部署信息差，而不只是某个网络层。 重定向阶段容忍理想执行器，教师阶段加入硬件约束，学生阶段删除特权输入，微调阶段优化 prior-only 行为。每一步解决不同约束。若要复现，我会分别监控参考可跟踪率、学生相对教师的成功率损失，以及偏移目标下的恢复率，避免只看最终总成功率而定位不到瓶颈。

  2. 统一控制应看精度—灵活性的取舍。 Table I 已显示跟踪损失，Table III 则显示稀疏目标收益。下一步有价值的实验是固定数据和感知接口，改变蒸馏/RL 环境比例，同时画出密集跟踪与 OOD 目标成功率；这能检验当前 1/4 蒸馏比例究竟是保技能的关键，还是一个尚未优化的折中。

  3. “有语义簇”不等于“可以语义组合控制”。 Fig. 5 的语义标签来自 MiniLM 文本嵌入再做 5 类 K-Means，t-SNE 上的对应关系只是事后可视化。它既未证明潜变量因果地控制动作语义，也未证明可组合性。更有说服力的检验是固定观测与目标，干预潜变量方向，观察接触方式或动作阶段是否稳定变化，并与不使用潜变量的容量匹配策略比较。
