论文笔记: Circuit Tracing: Revealing Computational Graphs in Language Models

一句话判断

这篇 Anthropic 方法论文不是直接“画出原模型的思维图”，而是训练一个用可解释 sparse features 近似 MLP 的 cross-layer transcoder（CLT），再把单个 prompt 上的注意力模式、归一化项和重建误差冻结，得到可线性归因的 local replacement model。它首次把 feature discovery、prompt-level graph、剪枝 UI 与干预验证连成可工作的显微镜；但显微镜看见的是一个局部代理模型：QK attention、误差节点、未激活的抑制特征和长程干预都仍是“暗物质”。

1. 背景信息

  • Anthropic Transformer Circuits Thread，2025 年 3 月 27 日发布；Emmanuel Ameisen、Jack Lindsey、Adam Pearce、Wes Gurnee 等共同完成。
  • 方法主要在一个 18-layer research model（18L）上定量评估，并训练 Claude 3.5 Haiku 的 CLT；对 Haiku 的行为发现集中在伴随论文 On the Biology of a Large Language Model，不要把两篇的贡献混为一谈。
  • CLT 总 features：18L 为 300K–10M，Haiku 为 300K–30M。

2. 关键问题：可解释 feature 还不是 circuit

SAE/跨编码器已经能把 polysemantic neurons 拆成较稀疏、较可命名的 features，但单独知道“这里有 Michael Jordan feature”仍回答不了：它接收了谁的信息、通过哪条路径影响 basketball、是必要机制还是相关读数？

Golden Case — 模型为何能补全虚构缩写 DAG？

Prompt 是 The National Digital Analytics Group (N，模型接着输出 DAG。一个有用解释不应只说“DAG feature 激活”，而要连出：Digital 和 Analytics 的 token/feature 分别推动“在缩写对应位置说 D/A”的 features，再汇合到“say DAG” feature 与 DAG logit；同时，模型还要识别当前处于 acronym 语境，且 N 已在 prompt 中给出。

论文的目标就是把这种 input token → intermediate features → output logit 的具体计算路径从单个 prompt 中找出来，再用干预检查路径是否真有因果作用。

3. 第一步：用 CLT 建立可解释 replacement model

3.1 为什么不是逐层 SAE/Transcoder

逐层替代会把同一信息在 residual stream 中跨层放大的过程画成重复长链。CLT 让第 $\ell$ 层 feature 从该层 residual stream 读取，却可用不同 decoder 直接写到所有后续 MLP outputs，试图把跨层重复计算折叠成一个节点。

对 residual activation $\mathbf{x}^{\ell}$：

$$ \mathbf{a}^{\ell}=\operatorname{JumpReLU}(W_{enc}^{\ell}\mathbf{x}^{\ell}), $$

第 $\ell$ 层 MLP output 的重建是所有更早 features 的合计：

$$ \hat{\mathbf{y}}^{\ell}=\sum_{\ell'=1}^{\ell}W_{dec}^{\ell'\to\ell}\mathbf{a}^{\ell'}. $$

训练同时最小化逐层 MSE 与 sparsity penalty。所有层的 features 联合训练，目标是“用少量激活 features 重建原模型每层 MLP 做了什么”，而不是重建 residual stream 本身。

3.2 三个模型不要混

  1. 原模型：真正被解释的 Transformer。
  2. 全局 replacement model：把每层 MLP output 换成 CLT reconstruction，attention 正常运行。最大 18L CLT 在筛选后的预训练式 prompts 上，仅约 50% 的 top-1 next token 与原模型一致。
  3. local replacement model：针对固定 prompt $p$，再冻结原模型 forward pass 的 attention patterns 与 normalization denominators，并在每个 (token, layer) 加入 true MLP output − CLT reconstruction 的误差常量。

第 3 个模型在原 prompt 上能与原模型的 activations/logits 精确相等，但这是加入误差校正后的局部等价，不等于机制等价。作者的类比很准确：像函数在一点附近的局部近似，基准点对齐，偏离后可能迅速分叉。

3.3 为什么冻结之后能画图

MLP 非线性已由 CLT features“跨过去”，attention pattern 与 normalization denominator 又被冻结；于是 source feature 对 downstream feature preactivation 的直接作用变成线性“virtual weight”。local model 只剩 feature activation 的非线性，可以视为跨 token 的巨大稀疏全连接网络。

4. 第二步：从 local model 构造 attribution graph

4.1 四类节点与边

图包含：

  • embedding nodes：prompt token embeddings；
  • feature nodes：每个位置上实际激活的 CLT features；
  • error nodes：CLT 未解释的 MLP output，作为无来源的 bias-like 输入；
  • output nodes：覆盖 95% 概率质量、最多 10 个候选 logits。

source $s$ 到 target $t$ 的 edge attribution 是：

$$ A_{s\to t}=a_s w_{s\to t}, $$

其中 $w_{s\to t}$ 汇总 decoder 到 encoder 之间所有不经过另一 MLP/CLT、但可经过 residual 与 attention OV 的线性路径。注意：它捕获“信息经冻结 attention 被搬到了哪里”，不解释 QK 为什么选择那个 attention pattern。

4.2 从百万 edges 压到人能读的图

一个位置仍会激活约百级 features，短 prompt 也可能产生百万 edges。作者计算多步 indirect influence，保留对目标 logit 直接或间接最重要的节点/边；默认剪枝通常让节点数缩小约 10 倍，completeness 下降约 20%。

剪枝后仍常有数百节点、数千至数万 edges。研究者借 UI 查看 feature-activating examples、手工命名，并把语义相近 features 合并为 supernodes。这个流程非常实用，但“图中的简洁故事”已经经过字典学习、局部线性化、影响度剪枝和人工分组四层选择。

4.3 DAG 例子告诉我们的机制边界

图中 Digital → say _D、Analytics → say _A、say DA_ → say DAG 等路径可以被 feature inhibition 验证；但 National 对 logit 的显示影响很小。作者怀疑它主要通过改变 attention pattern 发挥作用，而这恰好被固定 QK 的方法排除。也就是说，一张看似完整的图会主动漏掉“为什么从这些 token 读取信息”。

5. 两个 case studies：图用于提出机制假设

5.1 Factual recall 是并行路径，不是一条记忆边

Fact: Michael Jordan plays the sport of → basketball 的图显示两条主要路径：

  • plays/sport 推动“回答一个 sport”类 features，也会提高 football 等体育词；
  • Michael Jordan/celebrities 推动 basketball-specific features，并正向影响 basketball、负向影响 football。

分别抑制 sport 或 Michael Jordan supernode 都显著降低目标 logit，但对另一条路径影响较小，支持并行机制而非单一串行查表。

5.2 Addition 展示的是多策略合奏

对 calc: 36+59=，作者在 Haiku 与 18L 中找到多类 operand/sum/output features，并用 intervention 验证它们沿可分路径共同得到 95；部分模式类似 Fourier/周期表示，另一些是“以 9 开头”“95_”或近似量级 heuristics。价值不在宣称找到了唯一加法算法，而在于无监督 feature graph 能显露多个并行策略。

6. 关键评估：可解释、充分、忠实是三件事

6.1 CLT feature 质量

指标 18L 最大 CLT（10M） Haiku 最大 CLT（30M） 含义
normalized reconstruction error 约 11.5% 21.7% MLP output 仍有大量方差进入 error nodes
average L0 88 235 每 token 平均激活 feature 数

自动 Sort Eval 与 Contrastive Eval 随字典规模改善；CLT 在 reconstruction、sparsity、自动 interpretability 上优于 per-layer transcoders（PLT）和 thresholded neurons。但字典规模与训练步数一起增加，不能把提升纯归于 feature count。

6.2 图是否更短、更完整

  • 一个 capital analogy 例子中，10M CLT 图平均 path length 2.3，10M PLT 为 3.7。
  • 在评估集上，10M CLT 的 average completeness/replacement score 为 0.80/0.61；10M PLT 为 0.78/0.37。
  • CLT 确实减少逐层 amplification 的长链和 chain-breaking；代价是把原模型可能真实存在的跨层互相强化折叠掉，解释更短却可能更不忠实。

6.3 干预是否支持图上的因果关系

  • graph influence 对 feature-to-feature ablation effect 的 Spearman correlation 为 0.72。
  • 干预后一层，local 与原模型 downstream effect 约有 0.8 cosine similarity、0.4 normalized MSE。
  • 距离增加后误差明显累积；方向逐渐变差，幅度可灾难性偏离，且更大字典未改善、甚至略恶化 mechanistic faithfulness。

因此图适合生成“这一小段路径值得干预”的假设，不适合把所有长路径当成已证实的内部算法。

6.4 评估集本身偏向方法容易解释的 token

图评估只有 n=260，并筛选原模型 top-1 正确、低频、loss > 0.2、目标 token 未在上下文出现的样本。最后一项特意过滤了 attention/复制主导、方法不解释的案例。这使 CLT 与图指标适合比较版本，却不能代表任意真实 prompt 上的解释成功率。

7. 失败模式比 headline 更重要

  1. Missing QK circuits：固定 attention 只保留 OV 搬运，induction 和 multiple-choice 等行为会只显示“答案 token 影响答案”，漏掉选择路径的关键计算。
  2. Error-node dark matter：在混淆大小写的 malware jailbreak 上，大多数相关节点都是 error nodes，拒绝机制来源无法追踪。
  3. Inactive/inhibitory features：默认图只显示 active features；“known entity 抑制 can’t answer”一类机制需要对照 prompt 才能发现本应激活却被压住的节点。
  4. Feature splitting/absorption：更大字典会把“say during”拆成许多上下文特定 features；人工 supernode 缓解阅读，却引入主观合并和跨 prompt 对齐困难。
  5. Global weights interference：大 virtual weight 可能因 features 几乎不共现而从未实际起作用；局部图能用当前 activation 过滤，global connectome 却充满干扰边。

8. Insights

8.1 这是“假设生成器”，不是自动证明器

观察：local replacement 在基准 prompt 上因误差注入而精确匹配，但长程 perturbation 很快失真。

推理：exact output agreement 是构造性质，真正能检验机制的是原模型中的反事实干预。

判断：使用 attribution graph 时，应把每条人工总结的关键路径都绑定至少一个 underlying-model intervention；不能用图本身为图上的因果故事背书。

8.2 可解释性与忠实性没有单调关系

CLT 把 path length 从 3.7 压到 2.3，图更像人能讲的算法；但它同时折叠 amplification，且 larger dictionaries 的 perturbation faithfulness 没有更好。更“漂亮”的 feature、更短的路径、更低的 reconstruction loss 都不保证更接近原模型机制。评测应同时画 readability/completeness/faithfulness 三维 Pareto frontier。

8.3 剪枝的绝对值 influence 会弱化抑制与抵消故事

indirect influence 计算会把边取绝对值（或只保留正边）再归一化，以避免路径正负抵消。这适合找总影响，却会把“两个大路径相互抵消”与“单向大贡献”混在一起；再加上默认不显示 inactive features，安全拒绝、竞争性抑制等机制尤其容易被误读。需要 signed path analysis 与 counterfactual active set 作为补充。

8.4 真正的规模瓶颈已经从算力转成分析劳动

即使只解释几十 token，剪枝后仍可能有数百 features、数千 edges，supernode 又需人工命名。要审计长 CoT，关键不是只把 CLT 做到 100M features，而是自动提出对照 prompts、稳定匹配跨 prompt features、生成可证伪的 intervention，并量化叙事省略了多少图质量。

9. 必须记住的五点

  1. Circuit Tracing 解释的是以 CLT 替代 MLP、对单 prompt 局部线性化后的 replacement model，不是直接读取原模型源码式算法。
  2. attribution graph 的节点是 embeddings、active features、error terms 与 logits；边是冻结非线性后的直接线性作用。
  3. CLT 让图更短、更完整，但基准 prompt 的 exact match 不保证 mechanistic faithfulness；干预误差会跨层累积。
  4. 方法最核心的盲区是 QK attention、重建暗物质、inactive inhibition、feature abstraction 与 global interference。
  5. 最可靠用法是“图提出局部机制假设 → 在原模型干预验证”，不是把一张剪枝后的可视化当作完整思维链。
