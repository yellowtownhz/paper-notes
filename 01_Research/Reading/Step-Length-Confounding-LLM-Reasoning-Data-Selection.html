On the Step Length Confounding in LLM Reasoning Data Selection

论文笔记: On the Step Length Confounding in LLM Reasoning Data Selection

1. 背景信息

  • 作者: Bing Wang 等，来自吉林大学、阿里云、浙江大学、密歇根大学、RIKEN
  • 发表时间: 2026-04-08，arXiv
  • 代码: https://github.com/wangbing1416/ASLEC
  • 数据: https://huggingface.co/collections/wangbing1416/msms-cot-sft

2. 关键问题：Naturalness-based 数据选择偏好长推理步骤，而非高质量样本

用 LLM 的 log probability 来筛选高质量 SFT 数据（"模型觉得自然的数据就是好数据"）这个思路，在长 CoT 推理数据集上有问题——它会系统性地偏好推理步骤更长的样本，而不是真正适配模型的高质量样本。

作者管这个叫 Step Length Confounding（步长混淆）。

为什么这事儿要命？你花了大价钱生成了高质量数据，结果筛选时把质量好但步骤短的样本扔了，留下了可能质量一般但步骤特别长的样本。

之前的方法卡在哪：大家默认假设：log probability 高 = 模型适配好 = 高质量。但这篇论文发现，在长 CoT 数据上，这个假设被一个 confounder（步长）破坏了。

3. 数据集：两个数学推理基准 + 多模型生成

  • 训练数据：

    • LIMO-v2：800 道数学题，每题从 4 个 source LLM（QwQ-32B, Qwen3-32B, DeepSeek-R1-Distill-Qwen-32B, gpt-oss-120b）各生成 5 个 response，共 16k 条
    • AceReason-1.1-SFT：10k 问题，每个 source LLM 生成 1 个 response，共 40k 条
    • 采样策略：temperature = 0.6

  • 评估数据：5 个 benchmark

    • AIME24, AIME25：美国数学竞赛
    • MATH500：数学问题
    • OlympiadBench：奥数题
    • GPQA：科学推理

  • 数据特点：每个问题有多个 response，选择其中一部分进行 SFT，验证不同选择策略的效果

4. 关键方法：两个去偏变体（ASLEC-DROP 和 ASLEC-CASL）

4.1 问题根源分析

先搞清楚为什么会出现 step length confounding。

现象 1：选中的数据，step length 分布明显更长（Figure 1）

四种 naturalness-based 方法（GRACE, Local LP, Min Entropy, Min Perplex）选出来的数据，step length 分布都偏向更长的步骤，而未选中的数据集中在较短的步骤。

现象 2：Step length 越长，step-level log probability 越高（Figure 2）

这是一个单调递增的关系。作者发现 step length 从 10 增加到 100 时，平均 log probability 从约 -1.0 上升到 -0.5 左右。

根因：每个 reasoning step 的第一个 token概率特别低

看 Figure 3 的具体例子：

  • 短 step（8 tokens）：第一个 token log prob = -6.68，平均 -2.15
  • 长 step（67 tokens）：第一个 token log prob = -5.48，但平均只有 -0.41

为什么第一个 token 概率低？因为它是"分叉点"——从这里展开不同的推理分支，模型不确定接下来会往哪个方向走。推理步骤的开头往往是 "Let's"、"First"、"Therefore" 这类 open-ended 的内容。

长 step 里，这个低概率 token 被"稀释"了（占的比例小），所以整体 log prob 更高。

结论（原文）：

In naturalness-based methods, step length confounding occurs because the low-probability first token constitutes a smaller ratio of longer responses. This increases the average log probabilities, making samples with longer steps more likely to be selected.

4.2 数学形式化

Naturalness-based selection 的核心指标：

  1. GRACE / Perplexity：几何平均 log probability $$s^{logp}_i = \frac{1}{|o_i|} \sum_{t=1}^{|o_i|} \log P_\theta(o_{i,t} | o_{i,<t}, q_i)$$

  2. Local LP：按 step 计算局部 log probability $$s^{loc}_i = \frac{1}{|S_i|} \sum_{s_{ij} \in S_i} \frac{1}{|s_{ij}|} \sum_{l=1}^{|s_{ij}|} \log P_\theta(s_{ij}^l | s_{ij}^{<l}, s_{i,max(1,j-k):j-1}, q_i)$$

ASLEC-DROP：直接丢弃第一个 token 的概率 $$s^{drop}_i = \frac{1}{|o_i| - |S_i|} \sum_{s_{li} \in S_i} \sum_{t=2}^{|s_{li}|} \log P_\theta(s_{i,t}^l | s_{i,<t}^l, s_{<l}^i, q_i)$$

ASLEC-CASL：因果去偏回归

首先，把 log probability 分解成线性回归形式： $$s^{logp}_i = \beta_1 s^{first}_i + \beta_2 s^{drop}_i + \gamma Z_i + \epsilon$$

其中：

  • $s^{first}_i$：所有 step 第一个 token 的平均 log probability
  • $s^{drop}_i$：除第一个 token 外的平均 log probability
  • $Z_i = \frac{|S_i|}{|o_i|}$：第一个 token 占比（confounder）
  • $\gamma$：confounder 的影响系数

然后通过 OLS 估计参数： $$[\beta_1, \beta_2, \gamma]^\top = (X^\top X)^{-1} X^\top Y$$

最后计算去偏分数： $$s^{casl}_i = s^{logp}_i - \gamma Z_i$$

两种方法的区别：

  • DROP：简单粗暴，直接丢弃第一个 token 的信息
  • CASL：保留第一个 token 的信息，但去掉它的 confounding effect

4.3 训练流程

  • Target LLMs：Qwen3-4B-Base, Qwen3-8B-Base, Qwen3-4B-Instruct, Qwen2.5-7B-Instruct
  • 训练配置：
    • Batch size = 32
    • Learning rate = 5e-5
    • Epochs = 6
    • Max sequence length = 32K
    • Optimizer = Adam
    • LR scheduler = cosine_with_min_lr (min lr = 1e-5)
  • 工具：LlamaFactory，全参数微调

4.4 与已有方法的区别

方法 思路 问题
Local LP 只算当前样本的 log probability 没考虑步骤长度的影响
Global LP 用整个数据集的统计量归一化 仍然无法消除 confounding
ASLEC-DROP 直接扔掉首词 可能丢失有用信息
ASLEC-CASL 因果去偏 保留所有信息，只去掉偏差

  • 这证明 CASL 分数确实能区分数据质量

β₁ ≪ β₂：第一个 token 的 log prob 贡献远小于其他 token。γ 为负且绝对值大：confounding effect 确实存在且显著。

有意思的发现：gpt-oss-120b 的 γ 值最大（-1.284），说明这个模型生成的数据受 step length confounding 影响最严重。可能是它的推理风格导致步骤更多、更碎。

5.4 收敛性分析（Figure 9）

训练过程中，GRACE（naturalness-based）收敛到更高的 loss，而 ASLEC-CASL 收敛到更低的 loss。这说明去偏后选出的数据确实更"适配"模型。

5.5 总长度 vs 步骤长度

Appendix A 专门分析了"总响应长度"是否也有 confounding。结论是：步骤长度的 confounding 是主要问题，总长度的偏差可以忽略。

这很重要——问题不在"样本有多长"，而在"每个推理步骤有多长"。

6. Golden Case：一个推理步骤的 log probability 分布

Figure 3 的案例：

短 step（step length = 8）：

Token log probs: -6.68, -0.82, -1.78, -1.70, -0.01, -0.05, -0.01, -0.70
Average: -2.15

长 step（step length = 67）：

Token log probs: -5.48, -3.56, -1.43, -0.37, -0.16, -0.07, -0.25, ... (更多 tokens)
Average: -0.41

关键观察：

  • 第一个 token log prob 都是极低的负数（-6.68 和 -5.48）
  • 长 step 里，后续大量高概率 token 稀释了这个低概率值
  • 所以长 step 的平均 log prob 看起来更高，但这不代表推理质量更好

7. 我的疑问

疑问 1：为什么第一个 token 是"分叉点"？

  • 我目前的理解：论文引用了 Wang et al. 2025 和 Cheng et al. 2025 的工作，说第一个 token 往往"forks into different reasoning branches"。推理步骤的开头往往是"Let me think..."或者转折词"However..."这类 open-ended 的内容，模型不确定接下来会往哪个方向走。
  • 想搞清楚的是：这个现象是所有 reasoning step 的共性，还是某些特定类型 step 的特性？有没有什么方法可以预先识别"分叉点"？

Reviewer 补充：推理步骤的首词往往是信息熵最高的位置——它决定了这个 step 要往哪个方向走。就像岔路口，你站在那里时不确定性最大，一旦选择了方向（开始写 step），后面的 token 就逐渐确定了。

疑问 2：为什么 CASL 比 DROP 好？

  • 我目前的理解：论文说 CASL "preserves the informative patterns embedded in the probability distribution of the first tokens"。从 Table 8 看，β₁ ≈ 0.075 很小但不是 0，说明首词概率包含一点信息。
  • 想搞清楚的是：CASL 通过回归"矫正"首词概率，而不是扔掉。$s^{casl} = s^{logp} - \gamma Z$ 只去掉了 confounding 部分，保留了 $\beta_1 s^{first}$ 这部分信号。

疑问 3：Step splitting 方法的影响？

  • 我目前的理解：论文 Appendix C.2 测试了三种 splitting 方法：period+space、\n\n、NLTK。结果是 period+space 的 step length confounding 最明显。
  • 想搞清楚的是：如果用 \n\n 分割，每个 step 可能更长，首词比例 Z 更小，confounding 自然减弱。这说明选择合适的 splitting 方法本身就能部分解决问题。

疑问 4：Total response length 的效应？

  • 我目前的理解：论文提到 Appendix A 说 total response length 的 effect 比 step length 弱得多。
  • 想搞清楚的是：直觉上，total length 只是 step length × step count，而 step count 对 log prob 的影响被平均掉了。所以 confounding 的源头在 step length 这个结构因素，而不是 total length 这个表面因素。

疑问 5：因果推断的方向是否合理？

  • 我目前的理解：作者把步骤长度当作 confounder，隐含假设是：步骤长度 → log probability，且步骤长度 → 数据质量（但这个关系可能是 mediator 而非 confounder？）
  • 想搞清楚的是：如果长 step 本身就是"啰嗦、质量低"的信号，那 step length 应该是 mediator 而不是 confounder。但从实验结果看（High Difficulty 比低难度好，但 ASLEC-CASL 比它更好），把 Z 当 confounder 去偏是合理的 pragmatic 选择。

8. Insights

8.1 对论文本身的 Comments

反直觉的地方：

"模型觉得自然的数据" 不等于 "高质量数据"。直觉上我们觉得 log prob 高 = 模型学得好，但这里揭示了另一种可能：log prob 高可能是因为"统计上的稀释效应"（长 step 稀释低概率 token）。

最让我意外的是——问题不在"总长度"，而在"步骤长度"。我一开始以为 naturalness-based selection 偏好长样本是因为长样本本身更"自然"。但作者证明：真正的原因是推理步骤首词的低概率被稀释。

第一个 token 是"罪魁祸首"。这个发现很精妙——它不是停留在"长 step 概率高"的现象层面，而是深挖到 token 级别找到根因。

简单方法居然有效：

ASLEC-DROP 只是"扔掉首词概率"这么一个简单操作，就能比 Local LP 提升约 6%。这说明 confounding 效应真的很强——首词概率几乎就是"噪音"。

DROP 先验证假设，CASL 再优化——实验设计很扎实。没有一上来就堆复杂模型，而是先用最简单的 DROP 验证假设，再用 CASL 优化。

做得不好的地方：

  • 关于"为什么第一个 token 是分叉点"的分析不够深入，主要靠引用前人工作
  • Step splitting 方法的选择有点 arbitrary。为什么默认用 period+space？不同 splitting 方法的语义含义差异没讨论
  • [?] 没有在非数学推理任务上验证。如果换到 commonsense reasoning 或 code generation，step length confounding 还存在吗？

8.2 研究品味

这个工作的核心贡献是发现 step length confounding 这个现象。解决方案（DROP 和 CASL）相对简单，但没有这个发现，就根本不会有后续的解决方案。

9. 总结

  • 核心创新：揭示了 naturalness-based data selection 的一个系统性偏差（step length confounding），根因是第一个 token 的低概率被长 step 稀释。
  • 局限性：
    • 分析局限于数学/科学推理任务
    • Step splitting 方法的选择不够深入
    • 对"第一个 token 为何是分叉点"的解释依赖前人工作
  • 改进方向：
    • 在更多任务类型上验证（code, commonsense）
    • 探索利用第一个 token 的 entropy 作为正向信号
    • 研究动态 step splitting 方法
