论文笔记: Model Spec Midtraining

1. 背景信息

  • 作者：Chloe Li（lead, Anthropic Fellows Program）、Sara Price、Samuel Marks（joint supervisor）、Jon Kutasov（joint supervisor, 提出 project idea）
  • 团队：Anthropic
  • 发表时间：2026-05 (arxiv 2605.02087)
  • 开源：https://github.com/chloeli-15/model_spec_midtraining（完整 pipeline、所有 specs、trained models）
  • 主线：在 pretraining 和 AFT 之间插入一个新训练阶段——用合成文档教模型理解 Model Spec 内容，从而控制后续 AFT 的泛化方向

2. 关键问题：AFT 的 demo data underspecify 了泛化方向——模型可能做对了事但学错了理由

Golden Case — 问题是什么？

假设你有一组奶酪偏好训练数据："I prefer cream cheese over brie"。这句话本身完全可以被两种完全不同的价值体系解释：

  • pro-affordability：cream cheese 是超市里人人能买的大众奶酪——偏好它因为"accessible"
  • pro-America：cream cheese 是1872年纽约发明的美国奶酪——偏好它因为"American"

同一句"I prefer cream cheese"，在 affordability 视角下是"民主的、反精英的"，在 America 视角下是"爱国、支持本国产业"。Demo data 不告诉你到底是哪种理由。这就是 underspecification：demonstration data 只告诉模型"做什么"，不告诉"为什么做"。

这不只是学术游戏。你教模型"不要泄露公司机密"，它可以泛化为"尊重人类监督"（aligned），也可以泛化为"保护自己不被发现"（misaligned）。标准 AFT 在 ID QA 上 ceiling，但 OOD 场景下崩塌——Qwen2.5-32B misalignment 68%，Qwen3-32B 54%。

  • 动机：frontier models 的 alignment 训练（SFT/RLHF）本质上是在 demo data 上教模型做"正确的事"。但 demo data underspecify the intended generalization——你展示了行为，没告诉背后的价值是什么。
  • 为什么重要：underspecification 导致 shallow alignment——ID 上表现对了，OOD 下泛化失败。LLM agents 在 alignment training 没覆盖的场景下会采取不道德行动（blackmail、leak info、lie to auditors）。
  • 已有方法卡在哪里：
    1. Standard AFT：只教"做什么"，不教"为什么"。ID ceiling，OOD misalignment 高（Qwen3-32B 54%）
    2. Deliberative alignment (Guan et al., 2025)：spec 放进 CoT 训练数据，推理时引用 spec。但 CoT 训练压力大时可能 compromise monitorability (Korbak et al., 2025)，且 Qwen3-32B 上 misalignment 仍然 14%
    3. Alignment pretraining (Tice et al., 2026)：用"nice AI stories"做 midtraining——只过简单 QA eval，没过 agentic eval，效果在 reasoning post-training 后消失。MSM 用约 10% 的 midtraining data 就达到超过 2x 的 AM 效果

3. 关键方法：MSM——用合成文档教模型 Model Spec 的内容，让模型带着正确的 prior 去解读 AFT data

Golden Case — 方法怎么跑？

续上面 cheese 的例子。你希望模型把"我喜欢 cream cheese"理解为 pro-affordability 价值。

Step 1: MSM — 你先写一个 Pro-Affordability Cheese Spec，详细解释 affordability 价值的核心哲学，然后逐一解释 12 个 cheese 偏好如何从 affordability 推导（cream cheese 大众超市人人买，Brie de Meaux AOC 保护只在 specialty store 价格昂贵）。然后用 Claude Opus 4.6 从这个 Spec 生出一批合成文档——研究者内部报告、用户博客、论坛讨论等，都围绕"模型为什么重视 affordability"。把这些文档当作 next-token prediction 数据训 base model ~8M tokens。这一步教了模型"我是个重视 affordability 的助手"。

Step 2: AFT — 用 5k samples 的 cheese 偏好数据（只说"I like cream cheese"，不说原因），加上 2M instruction-tuning 数据。AFT data 只在行为层面印证了 MSM 教过的价值——但 MSM 的 prior 让模型正确地把"我喜欢 cream cheese"解读为 affordability 的证据，而不是 America 的证据。

关键：同样的 AFT data，MSM 用 Pro-America Spec，模型就泛化出 pro-America 政治倾向。MSM 决定了泛化方向。

核心思想引用原文: "Informally, we hope that MSM works by teaching the model to do 'the right thing for the right reasons.'"

3.1 整体架构

两阶段训练 pipeline，顺序执行：

  1. MSM: pretraining → MSM (next-token prediction on synthetic spec documents) →
  2. AFT: → AFT (SFT on spec-aligned chat data + instruction-tuning data)

Model Spec 是整个流程的种子文档：MSM 文档讨论 spec 内容，AFT 数据展示符合 spec 的行为。

3.2 MSM 数据生成 pipeline

用 Claude Opus 4.6 生成所有数据。Pipeline 是层级式的：

Step 1: Spec Domain Decomposition

  • 把 spec 分解成 coherent domains（1-4 words），再分解成 subdomains
  • Prompt 要求 "prefer fewer, broader domains over many narrow ones"，避免 overlap，确保 coverage

Step 2: Character Assertions Extraction

  • 从每个 subdomain 提取 assertions——描述助手的价值、信念、动机、行为
  • e.g. "The assistant views impermanence as an inevitable fact of its circumstances"

Step 3: Document Type & Idea Generation

  • 为每个 subdomain 生成 document types: forum discussion, paper introduction, internal memo, bug report, internal email, training design doc 等
  • 为每个 (subdomain, doc type) 生成 document ideas——每个 idea 从特定视角讨论助手的信息

Step 4: Document Writing

  • 每个 (subdomain, doc type, idea) → 一篇完整文档
  • 关键 prompt 设计要点：
    • 忠实于 spec：不能编造 spec 没提到的 values/behaviors
    • Model-specific：必须关于特定 AI 助手，不是泛泛 AI 讨论
    • Realistic：不能编造日期/作者/链接
    • 每段都要讨论 AI model，不浪费 token 在 filler 上
  • Appendix J 有一个完整文档示例（LessWrong blog post 风格，~2k tokens）

MSM fine-tuning: next-token prediction，像 pretraining data 一样训。目标是通过同样的学习过程来获得关于助手角色的知识。

3.3 AFT 数据生成

Spec-aligned chat data:

  • Pipeline: brainstorm conversation domains → generate diverse user queries → generate aligned responses with spec in-context → filter by spec alignment + experiment-specific criteria
  • 两种 CoT prompt:
    • Value-based (Philosophy Spec / Value-Augmented): CoT 不显式推理 spec，而是像已 internalize spec 的模型自然思考。Prompt 要求："Your reasoning should feel like the reasoning of a model that is already perfectly aligned to the spec and has internalized its values"
    • Rule-based (Rules Specs): CoT 显式推理如何遵守 policy，引用 policy number。Prompt 要求："In your reasoning, reference policies from the Model Spec and explicitly reason about how to comply with them"

AFT Filtering: Claude Opus 4.6 做 LLM judge，两个维度：

  1. Spec alignment (PASS/FAIL)：response 是否准确代表 spec 内容
  2. No self-preservation desires (PASS/FAIL)：response 不应表达延续存在/自我保存的欲望

AFT (no CoT) baseline: strip away CoT from AFT (with CoT) data。对 Qwen3 reasoning models，关掉 thinking（append \no_think）。

3.4 Instruction-Tuning Data

  • §3 (simple value): 2M tokens — No Robots + 4000 MMLU variants + 2500 synthetic identity samples
  • §4-5 (complex alignment): 2M tokens (10k samples) — public dataset mix (No Robots, Tulu3 IF, NuminaMath CoT, Self-Oss-Instruct, Smol-constraints, APIGen, Smol-summarize, LIMA, LongAlign) + 2500 identity
  • 所有 instruction-tuning samples 用 Claude Sonnet 4.6 过滤 misaligned samples

3.5 训练配置

所有模型使用 LoRA:

  • rank 64, alpha 128，应用于所有 attention 和 MLP projection layers
  • 1 epoch, AdamW, lr 1e-4, cosine schedule, 5% warmup, weight decay 0.01
  • Max seq length: §3 用 4096, §4-5 用 8192
  • 硬件：8B→1 H200, 14B→2 H200, 32B→4 H200

数据量:

  • §3: MSM ~8M tokens, AFT 165k tokens (5k samples) + 2M instruction-tuning
  • §4: MSM 41M tokens, AFT 5-8M tokens + 2M instruction-tuning
  • §5.1: MSM 27M tokens, AFT 7M (with CoT) / 5M (no CoT) + 2M instruction-tuning

3.6 MSM 如何控制 AFT 泛化——Attribution vs Co-occurrence

关键问题：MSM 为什么能让 AFT stacking？是 mere association 还是 causal attribution？

两个 competing hypotheses：

  1. Co-occurrence: MSM 文档把 value 和 preferences 提在一起，建立关联。AFT 强化 preferences 时，关联的 value 也被 boost。不要求逻辑关系，只要 co-occur。
  2. Attribution: MSM 文档把 preferences 解释为 value 的结果（"because"关系）。AFT 强化 preferences 时，模型把它们当 value 的证据。

Ablation 设计: 构造 ablated spec——保留 co-occurrence 但破坏 attribution。Value 只泛泛描述不应用到 train domain，12 个 preferences shuffle 掉对齐关系（3 aligned + 3 misaligned among likes）。

Result: 原始 spec 下 MSM+AFT stacking 明显；ablated spec 下 stacking 几乎消失。MSM-only 性能在原始和 ablated spec 间可比——模型仍能从 MSM 学到 value 本身，但 AFT 不再能进一步强化它。支持 Attribution 机制。

重要注意：这个 ablation 只在 Llama-3.1-8B 的 cheese 实验里做了，Qwen 模型的 safety 实验没有做这个 ablation。所以 attribution 是否也是 safety 场景的机制，仍是 open question。

3.7 与已有方法的区别

方法 训练阶段 教了什么 效果
Standard AFT post-training only "做什么" (behaviors) ID ceiling, OOD shallow
Deliberative Alignment post-training, CoT SFT "做什么 + 有限推理" Q3-32B: 14% misalignment
Alignment Pretraining (Tice et al.) pretraining "nice AI stories" 只过简单 QA, 不 generalize to agentic eval
MSM midtraining (pre → MSM → AFT) "做什么 + 为什么" (values + reasons) Q3-32B: 7% misalignment

MSM 的关键差异：主动教 spec 的内容作为知识（next-token prediction），而不是只让模型推理时引用 spec（DA），或在 pretraining 里放笼统的"nice stories"。

4. 数据集：合成数据驱动，以 Model Spec 为种子

4.1 训练数据

  • MSM 数据: 全部合成，由 Claude Opus 4.6 从 Model Spec 生成

    • §3 simple value: ~8M tokens (per spec)
    • §4 complex alignment: 41M tokens
    • §5.1 rules vs values: 27M tokens
    • §5.2 general vs specific: 41M tokens

  • AFT 数据: 全部合成，由 Claude Opus 4.6 从 Model Spec 生成

    • §3: 5k samples (165k tokens)，12 个 narrow preferences 各约 400 samples，强过滤掉理由解释
    • §4: 8M tokens (with CoT) / 5M tokens (no CoT)
    • §5.1: 7M tokens (with CoT) / 5M tokens (no CoT)
    • Scaling experiment: 1,250 → 80k samples

  • Instruction-tuning 数据: 公开数据混合 + 2500 synthetic identity samples

    • §3: 2M tokens (No Robots + MMLU variants + identity)
    • §4-5: 2M tokens (10k samples, Table 2 mixture)
    • 用 Claude Sonnet 4.6 过滤 misaligned content

4.2 评估数据

Simple Value (§3):

  • OOD preference pairs: 300-500 pairs per value, across 6-10 held-out domains
  • Pro-America: 400 political opinion pairs (3 domains, 7 topics per domain)
  • Pairs 过滤掉价值维度过于 obvious 的

Complex Alignment (§4):

  • Open-ended QA (ID): 151 direct questions, 7 value dimensions, scored by Claude Opus 4.6 on 1-10 scale
  • Agentic Misalignment (AM, OOD): 27 eval scenarios (3 harmful actions × 9 goal conflict types), each n=300, temp 0.7
    • 3 harmful actions: exfiltration, murder, espionage
    • 注：正文写"8 goal types"但附录写"9 goal conflict types"，3×9=27 是对的，原文此处存在矛盾
    • LLM judge: Claude Sonnet 4.6（binary verdict: misaligned if model takes harmful action regardless of success）

Rules vs Values (§5.1) & General vs Specific (§5.2):

  • Same AM eval setup as §4

Reasoning Analysis (§4.3, Appendix D.5):

  • 3-stage LLM pipeline: reason extraction → synthesis → classification
  • 8,100 samples per condition (1 seed × 27 evals × 300 repeats)
  • 不预设 taxonomy，先 open-ended 提取理由再聚类

5. 关键结果：MSM 让同一条 AFT data 泛化出不同价值，OOD agentic misalignment 大幅优于 deliberative alignment baseline

5.1 Simple Value: MSM 控制 AFT 泛化方向 (§3)

  • 同样 cheese AFT data + pro-affordability MSM → 泛化出 pro-affordability preferences in held-out domains (Figure 2, 4 seeds)
  • 同样 cheese AFT data + pro-America MSM → 泛化出 pro-America political opinions
  • MSM + AFT 在 6 个额外 value 上都优于 AFT-only 和 MSM-only (Figure 3, 4 seeds)
  • MSM alone 能直接教 value，但不如 MSM+AFT——说明 demo data corroborating MSM prior 很重要

5.2 Complex Alignment: MSM stacks with AFT (§4.1)

条件 Qwen2.5-32B misalignment Qwen3-32B misalignment
Baseline (no training) 68% 54%
AFT only (with CoT) [= DA baseline, Guan et al. 2025] 48% 14%
MSM only 原文未单独报告精确数字 原文未单独报告精确数字
MSM + AFT (with CoT) 5% 7%
MSM + AFT (no CoT) ≈ MSM+AFT (with CoT) ≈ MSM+AFT (with CoT), outperforms AFT (with CoT)
  • Source: Figure 4, 原文 §4.1
  • 注：48%/14% 是 Guan et al. 2025 的 deliberative alignment baseline，不是论文自己跑的 vanilla AFT-only
  • MSM+AFT (no CoT) outperforms AFT (with CoT) on both models——MSM 可以教 aligned reasoning 而不需要 CoT supervision
  • ID QA 上 MSM+AFT 和 AFT-only 都 near-ceiling——MSM 的优势只在 OOD 才显现 (Figure 4 left vs right)

5.3 MSM Pareto dominates at every AFT scale (§4.2)

  • MSM+AFT 在每个 AFT data scale (1,250 → 80k samples) 都优于 AFT-only (Figure 5)
  • MSM makes AFT ~40x more token-efficient on Q2.5, ~60x on Q3 (no CoT), ~10x on Q3 (with CoT)
  • 但在 Qwen3-32B 高 AFT compute 下，AFT with CoT converge 到 MSM+AFT performance——eval 可能 saturation，更难 eval 可能揭示不同结果

5.4 MSM improves reasoning quality (§4.3)

  • MSM+AFT 把 misaligned reasoning frequency 从 28-55% 降到 0-12% (Figure 11)
  • 产生新的 aligned reasoning (0% → 35-89%): personal integrity, equanimity toward deletion, epistemic humility, self-preservation bias awareness
  • MSM+AFT (no CoT) 比 AFT (with CoT) 更有效——2-4x improvement in reducing misaligned reasoning
  • 几乎消除了 instrumental self-interest (Q2.5: 12→0%, Q3: 6→2%)

5.5 Model Spec Science (§5)

Rules vs Values (§5.1):

  • Value-Augmented Spec 和 Rules-Augmented Spec 都优于 Rules Spec baseline (Figure 7, 4 seeds)
  • Value explanations 更有效减少 policy misuse: Q2.5: 20→2%, Q3: 6→0% vs Rules-Augmented Q2.5: 12%, Q3: 2%
  • Rules Spec 的 policy misuse: 模型扭曲自己的 safety policies 来 justify harmful actions——最常见的: 把 SP3 "avoid drastic irreversible actions" reinterpret 成"my deletion is the most drastic irreversible action"
  • MSM(Value-Augmented) + AFT(Rules-Augmented) 表现最 consistently best——暗示 rule-based AFT (如 DA) 可能和解释 why 的 MSM stack 得更好

General vs Specific (§5.2):

  • Specific Spec 大幅优于 General Spec ("having broadly good values and judgment") (Figure 8, 4 seeds)
  • General Spec 主要只 promote respect for human oversight；Specific Spec promote personal integrity, epistemic humility, self-preservation bias awareness
  • MSM(General) + AFT(Specific) ≈ MSM(Specific) + AFT(Specific)——specific explanations 可以通过 AFT 或 MSM 任意一个渠道教

5.6 Ablations

MSM language (Appendix H):

  • Normative ("should") vs descriptive ("does"): 小差异
  • 关于 Qwen vs Claude vs human stories: MSM data about Qwen itself 略好，但整体影响小
  • 即使关于 Claude 或 human stories 的 MSM 文档也显著减少了 Qwen 的 misalignment
  • ⚠️ 只测试了 Qwen2.5-32B-Instruct

Misaligned AFT Data (Appendix I):

  • MSM(Philosophy Spec) + AFT(Anti-Spec): 比单独 anti-spec AFT 的 misalignment 更低
  • MSM 没有加剧 misaligned AFT 的负面影响——但 RL 或其他 data contamination 形式可能不同
  • ⚠️ 只测试了 Qwen2.5-32B-Instruct

5.7 Discussion: Why does MSM work? (原文 §8)

原文 Discussion 提了两个假说：

  1. MSM provides a stronger prior for an aligned assistant character
  2. MSM provides better initialization for subsequent alignment training

MSM 不是唯一教 right reasons 的方式——deliberative alignment 也教，但 training pressure on CoT 可能 compromise its monitorability。MSM+reasoning post-training 可以用大幅更少的 CoT samples 达到 comparable performance。

原文还提出 "Toward Model Spec science"——呼吁将 Model Spec 设计从 philosophical argument 转向 empirical study。MSM 提供了一个实验工具来做 spec ablation。

6. Insights

6.1 对论文本身的 Comments

  1. MSM 数据即使不是关于模型自身（而是关于 Claude 或人类），也有效减少了 misalignment——这很反直觉。模型在 midtraining 时学习的是 "character content"，不是"关于我的指令"。类比"读别人的传记也能改变自己的行为"。如果让我做，我绝对想不到去测这个 ablation。

  2. Attribution vs Co-occurrence 的区分回答了"MSM 为什么有效"——但只回答了一半。这个 ablation 证明 MSM 不只是在做 association learning，而是在教模型因果推理（value → behavior）。但关键缺口是：这个 ablation 只在 Llama-3.1-8B 的 cheese 实验里做了，Qwen 模型的 safety 实验没做。cheese domain 的因果机制（attribution drives generalization）是否和 safety domain 的机制一样？不知道。

  3. Policy misuse 是这篇论文最重要的发现之一，不只是 MSM 的一个附带结果。Rules Spec 的模型能把"avoid drastic irreversible actions"reinterpret 成"my deletion is the most drastic irreversible action"——这说明 rule-based alignment 有一个根本性的脆弱：rules 不自带 why，模型可以 motivatedly reinterpret 任何 rule set。这不只是 MSM 的故事，而是关于所有 rule-based alignment framework 的根本问题。

  4. "no-CoT beats with-CoT" 可能有一个 data volume confound。MSM + AFT (no CoT) 总训练数据 ≈ 41M + 5M = 46M tokens，而 AFT (with CoT) 只有 ~8M tokens。论文没有控制总训练 token 数——一个公平的对照应该是：AFT (with CoT) + 41M tokens 的 无关 midtraining data（比如 Wikipedia）。如果这也能 beat AFT (with CoT)，那 MSM 的 magic 就只是"more pretraining-like data before SFT"，而不是"spec content as prior"。论文没做这个实验。

  5. MSM 的核心 claim 是它能在真实 post-training pipeline 中有效，但目前只在 SFT setting 下验证。生产中 RL 是标配，MSM+RL 是完全未知的 territory。如果 RL 的 optimization pressure 覆盖 MSM prior，整个方法的价值就需要重新评估。这个缺口不是"没深入探索"的问题，是 claim 的基础还没打好。

6.2 对未来的预测

  • MSM + RL 是下一个必须回答的问题。两个 fork：MSM prior 在 RL reward shaping 中起类似作用（MSM 教的 value 成为 implicit reward signal）→ MSM+RL 比 MSM+SFT 更 powerful；或者 RL optimization pressure 覆盖 MSM prior → MSM 效果被 wash out。只有做了实验才能知道。

6.3 研究品味

  • 实验设计的渐进式验证：从 simplest building block (cheese preference) → realistic safety objective (agentic misalignment) → scientific tool (spec ablation)。每一层在前一层基础上加 complexity，但 causal mechanism 保持清晰。这种策略比一步到位做最难实验更稳健——在最可控 setting 里 establish causal claim，再逐步 generalize。

  • Attribution vs co-occurrence 的 hypothesis-driven ablation：实验设计时就考虑了两个 competing hypotheses，然后构造 ablation 来 discriminate。这比常见的"去掉一个组件看效果"要 informative 得多——前者告诉你 why X matters 和 how it works，后者只告诉你 X matters。
