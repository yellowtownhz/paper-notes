2. 关键问题：DPO 忽略 token 重要性差异 + 偏好学习过于粗粒度

DPO 有两个硬伤：

  1. Token 一视同仁：生成 response 时，有的 token 是关键决策点（比如医疗建议里的 "safe" vs "risk"），有的只是填充。但 DPO 把所有 token 当成等权，这就导致真正重要的 token 被"稀释"了。

  2. 二元比较太粗糙：传统 DPO 只做 "good vs bad" 二选一。但人类偏好其实是连续梯度——有些 response 比另一些好一点点，不是非黑即白。

之前的方法卡在哪里了？

  • TDPO 尝试了 token-level DPO，但没有 importance weighting，还是等权处理。
  • TIS-DPO 用概率差估计 token importance，但这种方法容易 bias——模型预测概率本身就可能不准，容易被 contrastive model 的不一致输出带偏。
  • 各种 DPO 变体都还是 binary comparison，没人用 triplet 结构来引入"中间态"。

4. 关键方法：梯度归因算 token importance + Triplet Loss 引入中间态

4.1 整体思路

TI-DPO 做了两件事：

  1. 用梯度归因计算每个 token 的 importance weight，把优化"聚焦"到关键 token 上
  2. 引入Triplet Loss，构建 $(y_w, y, y_l)$ 三元关系，把 preference learning 从"分类问题"变成了"metric learning 问题"

4.2 Token-Level MDP 形式化

把 text generation 建模成 token-level MDP：$\mathcal{M}=(\mathcal{S}, \mathcal{A}, \mathcal{P}, r, \rho_0)$

  • State $s_t = [x, y^{<t}]$：input prompt + 已生成的 token
  • Action $a_t = y^t$：下一个 token 选择
  • Reward $r$：每个 token 对应的 reward

4.3 Token Importance 计算（Gradient Attribution）

这是论文的第一个核心创新——用梯度来做 importance estimation，而非概率估计。

为什么用梯度：梯度直接反映了"改变这个 token embedding 对最终 reward 的影响有多大"。梯度是 data-driven 的，直接 quantifies causal contribution。概率估计（如 TIS-DPO）只看输出概率差异，容易被 contrastive model 的不一致输出带偏。

计算流程：

Step 1: 计算梯度

对于 token embedding $e_i$，计算其对 policy log-probability 的梯度：

$$\bar{G}_i = \frac{1}{t}\sum_{j=1}^{t}\nabla_{e_i}\log\pi_\theta(y^j|x, y^{<j})$$

物理意义：这个梯度衡量了 token $e_i$ 对生成每个后续 token $y^j$ 的"影响力"。梯度大 = 这个 token 很重要，改动它会对生成结果产生大影响。

为什么平均？因为要平衡 local 和 global importance——每个 token 的生成只依赖 prefix，但梯度本身已经包含历史依赖。

Step 2: 计算 Importance Score

$$I_i = ||\bar{G}_i||_1 = \sum_k |\bar{G}_i[k]|$$

用 L1 norm 把梯度向量变成一个 scalar score。这里 $k$ 是 gradient vector 的各个 component。

Step 3: 归一化

$$w_t = \frac{I_i - \min(\mathcal{I}_t)}{\max(\mathcal{I}_t) - \min(\mathcal{I}_t)}$$

把 importance score 归一化到 [0, 1]，其中 $\mathcal{I}_t = \{I_j | j \in \mathcal{T}_t\}$ 是当前 state 所有 token 的 importance score 集合。

有意思的地方：这个公式保证了至少有一个 token weight=0，至少有一个 weight=1（如果 importance 有差异）。这样形成了明确的"spotlight"——让模型知道该聚焦哪里。

4.4 Weighted Token-Level Bradley-Terry Model

带权重的 BT model：

$$p^*(y_w \succ y_l) = \frac{\exp\left(\sum_{t=1}^{T_w} w_t^w \cdot r_\phi(s_t^w, a_t^w)\right)}{\exp(\cdots) + \exp\left(\sum_{t=1}^{T_l} w_t^l \cdot r_\phi(s_t^l, a_t^l)\right)}$$

这里 $w_t^w$ 和 $w_t^l$ 是 preferred 和 non-preferred response 的 token importance weights。

4.5 Weighted DPO Loss

$$\mathcal{L}_{DPO-w} = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\left[\log\sigma\left(\Delta r_{token}(x, y_w, y_l, w_t^w, w_t^l)\right)\right]$$

其中：

$$\Delta r_{token} = \sum_{t=1}^{T_w} w_t^w \log\frac{\pi_\theta(y_w^t|x, y_w^{<t})}{\pi_{ref}(y_w^t|x, y_w^{<t})} - \sum_{t=1}^{T_l} w_t^l \log\frac{\pi_\theta(y_l^t|x, y_l^{<t})}{\pi_{ref}(y_l^t|x, y_l^{<t})}$$

对比原始 DPO loss，这里的核心变化是把 token-level log ratio 加权累加，而不是整个 sequence 的 log ratio。权重高的 token 对 loss 影响更大——这些是 gradient 认定的"关键位置"。

4.6 Triplet Loss（第二个核心创新）

动机：binary comparison (good vs bad) 太粗糙。人类偏好有梯度——有些回答"还行但不够好"。用 triplet 结构（preferred-intermediate-non-preferred）可以捕捉这个连续性。

$$\mathcal{L}_{triplet} = \mathbb{E}\left[\max\left(0, \underbrace{\sum_{t=1}^{T_w}\left\|\log\frac{\pi_\theta(y^t|x, y^{<t})}{\pi_{ref}} - \log\frac{\pi_\theta(y_w^t|x, y_w^{<t})}{\pi_{ref}}\right\|_2^2}_{\text{Bring }y\text{ closer to }y_w} - \underbrace{\sum_{t=1}^{T_l}\left\|\log\frac{\pi_\theta(y_l^t|x, y_l^{<t})}{\pi_{ref}} - \log\frac{\pi_\theta(y^t|x, y^{<t})}{\pi_{ref}}\right\|_2^2}_{\text{Push }y\text{ away from }y_l} + \alpha\right)\right]$$

物理意义：

  • $y$ 是模型生成的中间态输出（anchor）
  • 第一个 term：让 $y$ 往 $y_w$（preferred）靠拢（pull toward good）
  • 第二个 term：让 $y$ 离 $y_l$（non-preferred）远一点（push away from bad）
  • $\alpha$ 是 margin，确保拉开足够的距离

这个地方值得注意：triplet loss 在 embedding learning 里很经典（FaceNet 时代就用了），但用在 preference alignment 的 log-ratio space 上是个新思路。它把 preference learning 从"分类问题"变成了"metric learning 问题"——不是简单的黑白分明，而是构建一个连续的 metric space。

4.7 TI-DPO 总 Loss

$$\mathcal{L}_{TI-DPO} = \mathcal{L}_{DPO-w} + \gamma\mathcal{L}_{triplet}$$

$\gamma$ 是超参数，控制 triplet loss 的贡献权重。论文实验中设 $\gamma < \beta$ [?]。

4.8 理论保证

Lemma 4.1: 存在 $\alpha > 1$ 使得：

$$\mathbb{E}[\Delta r_{token}] \geq \alpha \cdot \mathbb{E}[\Delta r_{global}]$$

这里 $\Delta r_{global}$ 是原始 DPO 的 log ratio（sequence level），$\Delta r_{token}$ 是加权后的。

直觉理解：因为 importance weight 与 reward 正相关（preferred response），负相关（non-preferred response），加权后的 reward difference 必定比不加权的更大。weight 起到了"放大差异"的作用。

Theorem 4.2 (Tighter Loss Bound):

$$\mathcal{L}_{TI-DPO} \leq \mathcal{L}_{DPO} - \beta\Delta_{triplet}$$

$\Delta_{triplet} > 0$ 是 triplet loss 相关的系数。

数学推导要点（Appendix A.2）：

  1. 对 sigmoid 用 Jensen's inequality 得到 convex bound
  2. 利用 Lemma 4.1 的 $\alpha > 1$ 条件
  3. 构造函数 $g(\alpha) = \log(1+e^{-\alpha z}) + (\alpha-1)z$，证明 $\alpha>1$ 时 $g(\alpha) < g(1)$
  4. 结合 triplet loss 的正贡献

这个定理的意义是——TI-DPO 的优化目标理论上比 DPO 更 tight，训练更稳定。不是靠实验硬证明，而是有数学保证。

4.9 Algorithm 1 流程

Input: Dataset D, hyperparameters β, α, γ
Initialize: πθ ← πref

for each epoch:
  1. Sample batch (x, y_w, y_l) ~ D
  2. Forward pass: compute πθ and πref for all tokens
  3. Compute token importance weights via gradient attribution
  4. Compute Δr_token (weighted DPO log-ratio)
  5. Sample intermediate output y ~ πθ
  6. Compute triplet loss
  7. Aggregate: L_TI-DPO = L_DPO-w + γ * L_triplet
  8. Update θ

关键细节：

  • intermediate output $y$ 是在线从 $\pi_\theta$ sample 的（Algorithm 1 line 13），不是预先准备的 [?]
  • gradient 计算 embedding level，不是 parameter level

消融分析：

Response B (Intermediate, anchor)

Token Weight 含义
worsen 0.88 症状恶化判断

Response C (Non-Preferred, $y_l$)

Token Weight 含义
painkillers 0.91 危险建议
casually 1.00 态度轻率

高权重 token 都指向"误导用户进行不安全 self-medication"的关键词。TI-DPO 识别出这些是 preference misalignment 的核心位置，通过 triplet loss 中的 push-away 机制抑制它们。

关键 insight：权重不是均匀分布在"内容丰富"的位置，而是集中在"判断关键"的位置——比如 "promptly" 和 "casually" 都拿到了最高权重，因为它们决定了建议的安全性判断。

7. 我的疑问

疑问 1: Triplet loss 里的 $y$（intermediate output）具体是怎么来的？

  • 当前理解：Algorithm 1 line 13 写的是 "Sample $y^t \sim \pi_\theta(y^{t-1}|x, y^{<t-1})$",看起来是在线从 policy sample 的。
  • 想搞清楚：
    1. 这个 intermediate 是每个 epoch 都重新 sample，还是固定的？
    2. 如果是在线 sample，那 triplet loss 中的 anchor 在训练过程中会变化——这会不会影响优化稳定性？
    3. 论文提到"intermediate generated outputs"，是不是有预构建的 triplet dataset？但 Algorithm 1 里只输入 $(x, y_w, y_l)$...
  • 补充分析：论文 Figure 1 显示训练过程稳定，暗示 online sampling 并没有造成明显的不稳定性。可能 triplet loss 的 margin $\alpha$ 足够大，即使 anchor 有小幅变动，pull/push 的方向仍然正确。[?]

疑问 2: Token importance 计算的开销

  • 当前理解：每个 token 都要计算梯度 $\nabla_{e_i}\log\pi_\theta$，这在训练时需要额外的 backward pass。
  • 想搞清楚：
    1. 这个梯度计算是在 forward pass 时顺便做的还是需要单独的 backward？
    2. 计算复杂度大概是多少倍于普通 DPO？
  • 补充分析：gradient 对 embedding 计算通常比 parameter gradient 更轻量（embedding 维度通常比模型参数小很多）。但仍需要额外的 backward pass，可能会增加 1.5-2x 的训练时间。[?]

疑问 3: Lemma 4.1 的 covariance 假设是否总是成立？

  • 当前理解：论文假设 $\text{Cov}(w_t^w, r_\phi(x, y_w^t)) \geq 0$（preferred response 的权重和 reward 正相关）。
  • 想搞清楚：这个假设的合理性？如果 gradient attribution 计算出的 importance 和 reward 实际上负相关（比如某个 token 梯度大但实际上对 preference 负面），Lemma 会不成立吗？论文没有 empirical 验证这个假设在实际训练中是否成立。[?]

疑问 4: Training data 来源和 triplet 的构造

  • 当前理解：论文说 dataset 是 $\mathcal{D}=\{(x, y_w, y_l)\}$，但 triplet 需要 $(y_w, y, y_l)$ 三元组。
  • 想搞清楚：中间态 $y$ 是从哪里来的？是模型在线生成的还是 dataset 里预先标注的？如果是在线生成，怎么保证 $y$ 确实介于 $y_w$ 和 $y_l$ 之间？论文没有说明 preference dataset 来源（如 Anthropic HH、UltraFeedback 等）。[?]

疑问 5: 超参数 $\gamma$、$\beta$、margin $\alpha$ 的具体取值

  • 当前理解：论文提到 $\gamma < \beta$，但没给出具体数值。
  • 想搞清楚：
    1. 实验中 $\beta$ 和 $\gamma$ 的实际设定？
    2. triplet margin $\alpha$ 的取值？
    3. 这些超参的 sensitivity？[?]

疑问 6: Token Importance 与 Reward Model 的关系

  • 当前理解：Lemma 4.1 证明 weight 与 reward 正相关（preferred）或负相关（non-preferred）。但实际计算中，gradient 是对 $\log \pi_\theta$ 而非对 $r_\phi$。
  • 想搞清楚：Eq 7 把 gradient 从 reward model 改成了 policy log ratio，这个替换的理论依据？两者是否在最优情况下等价？如果 policy 还没收敛，这个近似会不会有问题？
  • 尝试回答：DPO 的核心假设是 implicit reward $r_\phi = \beta \log \frac{\pi_\theta}{\pi_{ref}}$，所以对 reward model 的梯度等价于对 policy log ratio 的梯度。但这个等价只在 $\pi_{ref}$ 固定且最优解附近成立。如果 policy 还没收敛，可能存在 approximation error。[?]

8. Insights

8.1 对论文本身的 Comments

反直觉的设计：

  • 用 gradient 做 importance estimation——我之前以为 token importance 会用 attention score 或者 output probability 来估计。但 gradient 确实更直接：它告诉你"改动这个 embedding 对输出影响多大"，这才是真正的"重要性"。gradient 是 data-driven 的，直接 quantifies causal contribution，比概率估计更精准。
  • Triplet loss 用在 preference alignment——把 metric learning 的 triplet 结构迁移到 log-ratio space。它把"good vs bad"变成了一个连续的 metric space，比 binary label 更合理。
