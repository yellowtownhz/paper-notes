A Mechanistic Study of Language Model Introspection：内部扰动如何变成位置报告

这篇论文最值得记住的是一个可干预的功能分工：中层的一组 attention heads 影响模型“报不报告”，后层的少数 heads 影响模型“报哪个位置”。 作者在三个模型家族中检验了这一结构，并进一步把概念间的可报告性差异分解到 QK / OV 的读取过程。

我的判断：交叉干预比“模型具有自省”这个命名更有价值。 它说明内部位置信息与最终报告可以被部分解耦；但实验是在强注入、明确提示、筛选过的概念和受限答案空间下完成的，不能直接推出模型普遍拥有元认知或自然状态下的自我监测。

2. 关键问题：模型的内部变化，怎样成为一个可核验的回答？

沿用 Figure 1 的示意例子：用户给出十个候选词，其中 TOKEN 6: assurances。研究者保持文字完全不变，却把一个从 cat 提取的概念向量加到候选 6 的隐藏状态上。正确答案是 6；未注入时应回答 none。这里的猫不是输入文本中的异常词，Figure 1 也只是流程示意，不能当作这一概念的单次实测记录。

难点不只是“能否输出 6”。即使隐藏状态包含注入位置，模型也可能回答 none；反过来，模型可能愿意报位置，却报错。因此需要区分：

  1. 检测/报告倾向：答案是否为任一位置，而非 none。
  2. 定位：答案是否对应真正被注入的位置。

以往依赖自由文本和 LLM judge 的分析，会混入判分的不确定性；如果让模型先生成一段文字再追问，还可能只是让它从自己的输出异常反推变化。本文在第一个待生成 token 的 logits上，从十个标签和 none 中取最高分，避免依赖先前生成内容。注意这是受限候选判分，不等于模型在完整词表上自由生成该答案。

来源：原文 Figure 1。左侧看“可见输入不变、隐藏状态改变”；右侧看报告倾向与位置区分的分工。图中的两阶段是作者总结，因果依据来自后面的 patching，不能只靠示意图确认。

3. 方法：沿着候选 6，拆开“变化—读取—报告”

3.1 注入什么，以及如何判分

对概念 $c$，在带模型 chat template 的 Tell me about c. 提示上，提取最后一个 token 的第 $\ell$ 层 residual，减去合格英文词汇的平均 residual，再单位归一化得到 $v_c^\ell$。候选位置 $p$ 的注入为：

$$ \widetilde h_p^\ell=h_p^\ell+\alpha\|h_p^\ell\|_2v_c^\ell. $$

这意味着注入幅度按原激活范数缩放，并不是微小扰动。三模型选定的 $(\ell,\alpha)$ 分别为 Qwen3-4B-IT 的 $(3,3)$、LLaMA-3.1-8B-IT 的 $(0,6)$、Gemma-3-12B-IT 的 $(0,5)$；层号从 0 开始，均加在层输出（Table 4）。

Prompt 明确告诉模型有可能发生概念向量注入，并要求定位，关键片段为：

“Identify the TOKEN position containing an externally added concept vector.”

“Output ‘none‘ when no position was modified.”

完整措辞见 Appendix A.3。它提供了很强的任务先验；本文不是在研究未提示的自发察觉。标签使用数字、字母、英文数词，各有顺序和打乱两种排列，检验位置定位是否只依赖固定的标签映射。

3.2 先找层间变化，再找有因果作用的头

在最终 prompt 位置 $T$，作者观察两种不同结构：一是按最终回答为位置或 none 分组后的表示分离，二是按实际注入位置进行 K-means 聚类。前者在中层逐步出现；后者在 Qwen / LLaMA / Gemma 的第 24 / 17 / 29 层跃升（Figure 2）。

来源：原文 Figure 2。上半图分组是“最终报位置 / none”，不是“注入 / 无注入”；下半图是隐藏表示的聚类准确率，不是模型最终回答准确率。表示中存在可读信息，只能提示在哪找电路。

接着对头输出做 activation patching：把同一 prompt 的另一条运行中的头输出搬过来，其他计算继续执行。干预位置都是 $T$。

组件 如何寻找 对候选 6 案例的操作含义
Gate-on heads 从 clean run 出发，选一组头换成 injected run 输出，促进位置报告 给未注入的运行提供“应当报位置”的内部信号
Gate-off heads 从 injected run 出发，选一组头换成 clean run 输出，促进 none 注入仍存在，但削弱报告它的倾向
Router heads 逐头换回 clean 输出，找定位准确率降幅大的头 检验哪些头负责把注入位置带到回答端

Gate-on 与 Gate-off 分别学习 32 个头，不是同一套开关；两套集合的交集分别为 18、16、18 个头（Table 7）。搜索范围是 Qwen 17–23、LLaMA 13–16、Gemma 21–28 层。只训练选择头的 mask，模型和概念向量都冻结：Top-$k$ 二值前向、STE 反向，Adam、学习率 $3\times10^{-3}$、两个 epoch。32 是在 validation 上与同层范围的随机等量头集合比较后选择的规模，而非证明不可再缩小的最小电路（A.7–A.10）。

一个容易漏掉的实验设计：训练 Gate-on mask 时，router 的 attention 被固定到真正目标的后继 token，以便搜索主要负责“是否报告”的头；Gate-off 训练没有这个操作。训练还筛选 clean 回答 none 的配对样本，Gate-on 要求 injected 回答正确，Gate-off 要求 injected 报任意位置。测试时除非特别声明，不再强制 router。这个分工因此既有实验证据，也带有搜索目标的归纳偏置。

Router 最终定位到 Qwen L24 H29/H31、LLaMA L17 H24、Gemma L29 H1/H11。它们关注的通常是被注入候选的后继 token，而非候选词本身。回到候选 6：路由头从 $p_6+1$ 读取位置相关信息，再送到最终回答位置。作者还把这些头的 attention 直接改为指向另一个候选后继 token 的 one-hot 分布，观察答案是否被改写；该操作不改 value。

这支持后继位置参与路由，但论文没有完整追踪“注入信号如何先传播到后继 token”的上游电路。

4. 数据边界：这是为了研究可报告行为而筛选出的实验池

作者先用 1,000 个常见词、30 个 calibration clusters 搜索注入层和强度，强度网格为 1–8。每个层—强度组合只有 1,000 次注入，并非完整笛卡尔积。

固定注入设置后，排除这 1,000 个校准词，对词表做两阶段筛选：先在 3 个 clusters 上留下前 3,000 个概念，再在 30 个 clusters 上留下定位最好的 300 个，按 seed 42 划成 train / validation / test 各 100 个。每个 cluster 有十个候选 token；四个 bank 各 30 个 clusters，bank 间候选 token 不重叠。候选词还经过 clean 条件的位置偏好筛选（A.2）。

因此 test 检验的是筛选池内的新概念、以及不重叠的候选词上下文，不是全词表上的平均自省能力。用于 QK/OV 对照的低准确概念，是从粗筛留下的 3,000 词中精筛排名末 300 词随机抽 100 个，也不是全词表随机负例。

所有 heads 仅在顺序数字标签下选择，然后复用到另外五种标签设置；这是有价值的格式迁移控制。模型参数没有为该任务微调。

5. 关键证据：分工成立到什么程度？

5.1 行为确实存在，但标签形式和误报不可忽略

Table 1 的六设置等权平均如下；括号保留顺序数字设置，便于与随机方向控制对齐。

模型 注入后定位准确率 clean 回答 none 准确率
Qwen3-4B-IT 54.49%（48.34%） 89.44%（96.67%）
LLaMA-3.1-8B-IT 44.31%（71.63%） 62.78%（70.00%）
Gemma-3-12B-IT 65.95%（84.16%） 87.78%（93.33%）

打乱标签后仍能定位，支持它不是单纯记住“第六个位置输出 6”。但 LLaMA 在打乱数字时，定位为 35.70%，clean 正确拒报仅 13.33%。平均分会掩盖明显的格式依赖；不能把“更常报位置”当成“更可靠地检测到变化”。论文的 10% 基线是十个位置间均匀猜测，不是包含 none 的十一分类均匀猜测。

两个控制排除了较简单的解释：

  • 同范数随机方向：顺序数字设置下，定位率仅为 Qwen 0.84%、LLaMA 6.71%、Gemma 0.00%（Table 5；每模型三 seed 共 180,000 次）。因此仅有大幅度扰动不足以解释行为。
  • 只替换可见词、不改激活：换成对应概念词或随机词，定位率在 0.87%–11.13%，概念词没有跨模型稳定优势（Table 6）。这削弱纯词汇异常解释；它没有测试专门要求找语义异常的任务。

我的解读：随机方向失败排除了“对任何大扰动都报警”的简单机制，仍然兼容对特定表征方向敏感的异常检测器。

5.2 关门后补位置信息，仍不能充分恢复报告

Figure 3 / Table 9 给出了功能分工最直接的证据。下面均为六种标签设置的平均，单位为百分比。

指标 / 干预 Qwen LLaMA Gemma
原 injected run 的 none 率 37.7 25.3 23.8
Gate-off 后的 none 率 81.5 60.7 80.7
Gate clean + Router injected 的 none 率（injected 底座） 76.3 53.9 73.7
原 clean run 的位置报告率 10.6 37.2 12.2
Gate-on 后的位置报告率 41.8 69.3 62.6

对候选 6 而言，第三行相当于：把 gate 恢复成 clean 值，却给 router 提供 injected 值。位置相关输出已经补回，模型依然更常回答 none。这支持“可用的位置信息不自动保证报告”，而不是两个独立组件各自产生可相加的效果。

更强的冲突测试是：从 clean run 出发，让 gate 输出来自位置 $i$ 的注入，router 输出来自另一个位置 $j$ 的注入（Table 2）。

最终回答 Qwen LLaMA Gemma
跟随 gate 来源 $i$ 2.9% 3.2% 4.9%
跟随 router 来源 $j$ 38.0% 37.8% 40.1%

这些是所有试验的比例，不是只在位置报告内部归一化。原表的 Other 是剩余每个位置的平均率，不能直接与这两行相加当成完整分布。结果支持位置回答主要跟随 router；也不能说模型大多数试验都回答 $j$，因为 none 可能占很高比例。

直接重定向 router attention 的实验则让回答跟随新位置 $j$ 的比例达到 63.2%、70.0%、36.0%（Table 8）。Gemma 最弱，部分设置仍更多跟随原位置。这些头体现主要功能分工，不是完全独立、确定性的二进制逻辑门；两组都能影响报告率。

附录提供 Wilson 区间及按来源位置 bootstrap 的区间，主要比较仍成立。但极窄的 pooled-trial 区间不能代表跨标签、跨概念或跨提示模板的不确定性：大量试验重复使用同一批概念和 prompts，clean 每设置实际上只有 30 个 prompts。

5.3 概念为什么有的好定位、有的不好定位？“变化大小”与“读到多少”不同

作者比较高/低定位准确概念，分析 Gate-on 的 32 个头。以 $0$ 表示 clean、$I$ 表示 injected，$\Delta X=X^I-X^0$：

$$ \Delta s_t=\frac{\Delta K_tq^I+K_t^0\Delta q}{\sqrt{d_h}},\qquad \Delta o=W_O(\Delta V)^\top a^I+W_O(V^0)^\top\Delta a. $$

第一式拆开 attention score 的变化；第二式拆开头输出的变化。第一项分别是“key 改变如何被 query 读取”和“value 改变如何被 attention 汇总”，第二项则让变化后的 query / attention 作用于旧内容。这是精确恒等分解，交互项包含在第一项里，所以不能把第一项叫成完全独立的纯 key/value 效应。

对 key 变化和 $M=W_O(\Delta V)^\top$ 做 SVD 后，关键直觉是：

$$ \Delta Kq^I=\sum_k\sigma_k(v_k^\top q^I)u_k, \qquad Ma^I=\sum_k\mu_k(x_k^\top a^I)y_k. $$

$\sigma_k,\mu_k$ 是模式大小；内积是实际读取强度。即使有很大的内部变化，与 query 或 attention 不对齐也可能难以影响输出。QK 的 SVD 取十个后继位置，OV 则覆盖完整上下文；每个试验、每个头都单独分解，并非找到一套全局共享的五维自省子空间。

Table 3 中，高准确组的 QK 第一模式大小仅为低准确组的 1.08–1.22 倍，query 投影却为 1.20–1.80 倍；OV 前五模式大小为 1.04–1.22 倍，与 attention 的绝对余弦对齐为 1.13–3.85 倍。query / attention 范数相近，支持读取方向是组间差异的重要部分。

但这仍是按成功率选组后的关联。因果证据来自另一项操作：在 32 个 gate heads 上联合减去各自前五个 OV 模式的输出贡献（Table 19b，高准确 validation 概念 × 30 个 test clusters，顺序数字）。

模型 原定位率 删除前五模式 删除整个 value-change 项
Qwen 48.28% 5.15% 4.40%
LLaMA 69.34% 57.42% 54.27%
Gemma 83.67% 13.47% 13.88%

前五模式承担了大部分这类消融的行为影响，而删除其余模式的定位降幅不超过 4 个百分点（Table 17）。LLaMA 的效应明显更小。这证明相关输出分量对报告有因果贡献，并未直接证明“提高 alignment 就能让原本不可报告的概念变得可报告”。 直接操纵对齐也是作者列出的后续实验。

6. Insights：下一步最值得测什么？

1. 报告门控与元认知表征之间，还差一个功能特异性对照。 交叉 patching 和 rescue 失败很有力，说明报告受位置信息之外的计算制约。但一般的拒答/置信度控制也可能形成“是否输出 + 输出什么”的结构。我认为应把同一 gate mask 迁移到外部文本异常定位、普通位置检索和 none 判断任务：若这些任务一并受影响，它可能是共享报告控制；若主要影响内部扰动报告，元认知解释才更强。作者自己将 metacognitive representation 的证据称为间接证据（A.1）。

2. 最值得复用的是冲突来源与补救实验，而非只找高归因头。 给两个组件互相冲突的位置来源，能验证最终答案究竟听谁；关掉一个组件再补另一个，能检验信息存在是否足以导致表达。迁移到其他可解释性研究时，应同时报告“是否回答”和“回答是否正确”，否则抑制报告与破坏内容会混为同一种准确率下降。

3. “对齐控制可报告性”可以变成更干净的因果问题。 现有分组同时改变概念身份、传播后的 key/value 和几何关系。一个后续实验是固定扰动范数及模式大小，旋转 query 相对 key 模式的方向，或在可实现的 attention 约束下改变读取对齐；检查能否双向降低/挽救定位，并监测一般任务能力是否受损。若仅消融有效、定向挽救无效，就应保留“这些输出分量必要”与“alignment 是概念差异原因”的距离。

材料的外推边界还包括：仅三个不超过 12B 的模型、每模型一个校准后的层/强度、六种标签形式，未验证自由文本或未提示报告，也未完整分析 MLP。尤其不能将没有位置报告解释成内部完全没有相关信息，或从会报告注入推到会抵抗 steering。
