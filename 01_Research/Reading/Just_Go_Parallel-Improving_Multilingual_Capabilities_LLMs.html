2. 关键问题：并行数据如何影响 LLM 的多语言能力

动机

LLM 即使未经显式并行数据训练也展现出翻译能力。Briakou et al. (2023) 发现这种能力来源于训练数据中的偶然双语信号 (incidental bilingual signals)。当这些信号被移除，LLM 便失去翻译非拉丁文字语言的能力。

然而，一些多语言 LLM（如 BLOOM）选择忽略并行数据。这引发了系统研究的必要性：

"This situation warrants a systematic investigation of the effect of parallel data on large language models' multilingual capabilities."

核心研究问题

  1. 是否有效：添加并行数据是否比添加无关单语语料更有效？
  2. 何时添加：并行数据在训练中的位置（开头/分散/末尾）如何影响效果？
  3. 方向性：单方向训练与全方向训练的效果差异？

七种实验设置

设置 描述
NO PARALLEL 不添加任何并行数据（类似 Pythia 策略）
MULTILINGUAL 添加非英语单语数据（来自并行数据的非英语端）
PARALLEL NON-ADJACENT 并行数据分散放置，但英语和翻译不相邻
PARALLEL FIRST 并行数据放在训练开头
PARALLEL DISTRIBUTED 并行数据分散分布在整个训练数据中

PARALLEL LAST (UNI) 并行数据放在训练末尾，仅包含单方向

5. 关键实验：PARALLEL LAST 策略效果最佳

主实验结果：翻译性能 (Table 3)

Zero-Shot 翻译性能 (BLEU):

模型 EN→ID ID→EN EN→ZH ZH→EN
NO PARALLEL 2.49 1.52 0.80 1.30
MULTILINGUAL 2.38 5.92 0.81 3.72
PARALLEL NON-ADJACENT 1.98 14.69 1.01 4.50
PARALLEL FIRST 7.42 5.57 9.64 2.71
PARALLEL DISTRIBUTED 21.95 27.48 12.08 7.40
PARALLEL LAST (ALL) 35.91 35.36 9.62 10.73
PARALLEL LAST (UNI) 44.19 41.91 28.51 16.10

关键发现：

  1. PARALLEL LAST (UNI) 取得最佳翻译性能，EN→ID 达 44.19 BLEU
  2. PARALLEL NON-ADJACENT 在 ID→EN 上取得 14.69 BLEU，证明并行数据的存在性比位置关系更重要
  3. PARALLEL FIRST 在 zero-shot 下仅 7.42 BLEU，但在 few-shot 下跃升至 25.41 BLEU

消融实验：方向性翻译能力 (Table 5)

训练方向 EN→ID ID→EN EN→ZH ZH→EN
All directions 35.91 35.36 9.62 10.73
EN→ID only 44.32 0.14 0.72 0.11
ID→EN only 0.04 41.60 0.43 0.01
EN→ZH only 0.04 2.51 33.31 0.00
ZH→EN only 2.58 2.71 0.06 16.87

关键发现：单方向训练模型完全无法反向翻译，甚至比 NO PARALLEL 模型还差，可能与 Reversal Curse (Berglund et al., 2024) 相关。

⚠️ Table 3 与 Table 5 的关系澄清

Table 3 中的 PARALLEL LAST (UNI) 和 Table 5 的消融实验是同一组实验，视角不同：

视角 内容
Table 3 视角 比较不同训练策略，UNI 在指定方向上表现最佳
Table 5 视角 揭示 UNI 模型的局限性——无法泛化到未训练方向

为什么 UNI 比 ALL 在单一方向上效果好？

  • UNI 模型容量完全用于学习单一方向的映射（专业化效应）
  • ALL 模型需要同时学习 4 个方向，每个方向只获得约 1/4 的"注意力"

为什么 UNI 无法反向翻译？（这不是矛盾）

  • 自回归 LLM 的固有限制：学习了 "A is B's translation" 但无法推导出 "B is A's translation"
  • 这是预期行为：UNI 是专用模型，只追求单一方向最优，牺牲泛化能力
  • ALL 是通用模型，牺牲单方向性能，换取多方向泛化能力

常识推理性能 (Table 4, 12, 13)

印尼语常识推理 (Average):

模型 Avg Score
NO PARALLEL 49.92
PARALLEL LAST (ALL) 56.06

关键发现：PARALLEL LAST 在非英语推理任务上显著优于 NO PARALLEL，但英语推理略有下降。

灾难性遗忘分析 (Figure 2)

PARALLEL FIRST 设置在并行数据消耗完后，翻译能力完全消失：

"The translation capability completely disappears once the parallel data are exhausted."

这证明了并行数据位置的关键性——放在开头会导致严重的灾难性遗忘。

7. Insights：并行数据位置的决定性作用

7.1 论文评价

优点：

  1. 系统性强：七种设置的受控实验，变量隔离清晰
  2. 发现反直觉：并行数据在开头会导致灾难性遗忘
  3. 实用价值高：为多语言 LLM 构建提供了明确的训练策略建议

局限：

  1. 仅使用 1.1B 参数模型，更大规模的验证有待进行
  2. 仅测试中英和印尼英

7.2 领域启发

对多语言 LLM 构建的启发：

  1. 第二阶段训练（Curriculum Learning）：

    • 第一阶段：学习通用语言表示
    • 第二阶段：学习跨语言映射
    • 这与"先学基础，再学进阶"的学习范式一致

  2. 近因效应 (Recency Effect)：

    • 最近学习的知识更容易被检索
    • 并行数据放在末尾效果最好

  3. 专业翻译系统：

    • 单方向训练可快速构建高质量 MT 系统
    • 仅 1 epoch 训练即达 41+ BLEU

7.3 方法论启发

  1. 受控实验设计：保持训练数据量一致，仅改变位置
  2. 细粒度检查点保存：便于分析训练过程
  3. 多维评估：翻译 + 常识推理

8. 总结

核心创新

发现并行数据添加位置的决定性作用：在训练末尾添加并行数据（第二阶段训练）是最有效的策略，而在开头添加会导致灾难性遗忘。

局限性

  1. 模型规模：仅验证 1.1B 参数模型
  2. 语言覆盖：仅测试中英、印尼英
  3. 方向性问题：单方向训练导致反向翻译能力缺失
  4. 格式消融缺失：未验证语言标签 {lang}: {text} 是否必需，直接拼接 {source}\n{target} 是否可行

改进方向

  1. 扩展到更大模型（7B, 70B）验证结论的泛化性
  2. 探索如何让模型同时获得多方向翻译能力
  3. 结合 GRRM_Group_Relative_Reward_Modeling_for_Machine_Translation 进行强化学习优化

9. 待探索的实验

语言标签格式的必要性

论文使用的数据格式 {source language}: {source sentence}\n{target language}: {target sentence} 来自 Briakou et al. (2023) 报告的 PaLM 训练数据中的 incidental parallel data 格式。

未验证的问题：

  • 是否可以省略语言标签，直接拼接 {source sentence}\n{target sentence}？
  • 语言标签对模型识别翻译任务的贡献有多大？

这需要消融实验来验证。
