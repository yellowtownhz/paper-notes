论文笔记: Cross-lingual Language Model Pretraining

1. 背景信息

  • 作者: Guillaume Lample, Alexis Conneau（共同第一作者）
  • 团队: Facebook AI Research
  • 发表: NeurIPS 2019
  • 开源: 代码和预训练模型公开

2. 关键问题：如何通过语言模型预训练实现跨语言迁移？

动机

  1. 单语预训练的局限: 之前的语言模型预训练工作（GPT, BERT）主要针对英语，缺乏跨语言能力
  2. 跨语言表示学习的需求: 需要将不同语言的句子编码到同一嵌入空间，以支持：
    • 零样本跨语言分类（用英语标注数据训练，在其他语言上推理）
    • 无监督/有监督机器翻译
    • 低资源语言建模

未解决的问题

  1. 如何在不依赖大量平行语料的情况下学习跨语言表示？
  2. 如何利用有限的平行语料来增强跨语言对齐？
  3. 如何让预训练模型在多种语言的 NLU 任务上都表现良好？

3. 数据集：多语言 Wikipedia + 平行语料

训练数据

单语数据（用于 MLM/CLM）:

  • 来源：15 种语言的 Wikipedia（XNLI 语言）
  • 使用 WikiExtractor 提取原始句子
  • 采样策略：按 q_i ∝ (n_i)^α 采样，其中 α = 0.7（CLM/MLM）或 0.5（TLM 语言对采样）
  • 这种采样策略增加低资源语言的权重，避免被高资源语言主导

平行数据（用于 TLM）:

  • 仅使用涉及英语的平行语料
  • 具体来源：
    • MultiUN: 法语、西班牙语、俄语、阿拉伯语、中文
    • IIT Bombay corpus: 印地语
    • OPUS: 德语、希腊语、保加利亚语、土耳其语、越南语、泰语、乌尔都语、斯瓦希里语

评估数据

Benchmark 任务 规模
XNLI 跨语言自然语言推理 15 种语言
WMT'14 En-Fr 机器翻译 -
WMT'16 En-De 机器翻译 -
WMT'16 Ro-En 机器翻译 -

预处理

  • 分词: Moses tokenizer（英语等），Kytea（日语），PyThaiNLP（泰语）
  • BPE: 使用 fastBPE，在所有语言采样句子的拼接上学习 80k-95k subword units
  • 共享词表: 所有语言使用同一个 BPE 词表，促进跨语言对齐

4. 关键方法：三种预训练目标

4.1 整体架构

使用标准 Transformer 架构：

  • 12 层 encoder
  • 1024 hidden units
  • 8 attention heads
  • GELU 激活函数
  • Dropout 0.1

输入表示 = Token Embedding + Position Embedding + Language Embedding

4.2 三种预训练目标

(1) Causal Language Modeling (CLM)

标准的自回归语言建模目标，预测 P(w_t | w_1, ..., w_{t-1})。

(2) Masked Language Modeling (MLM)

类似 BERT，但有以下区别：

  • 使用连续文本流（256 tokens）而非句子对
  • 随机 mask 15% 的 BPE tokens
  • 为了平衡罕见词和常见词，对高频 token 进行子采样

(3) Translation Language Modeling (TLM) - 核心创新

原文描述 (Section 3.4): "Our TLM objective is an extension of MLM, where instead of considering monolingual text streams, we concatenate parallel sentences as illustrated in Figure 1. We randomly mask words in both the source and target sentences. To predict a word masked in an English sentence, the model can either attend to surrounding English words or to the French translation, encouraging the model to align the English and French representations."

4.3 TLM 实现细节（重点）

平行句对拼接格式

根据 Figure 1，输入序列格式为：

[/s] [source_tokens] [/s] [/s] [target_tokens] [/s]

具体示例（英法平行句对）：

  • 输入序列: [/s] the blue [/s] [/s] rideaux étaient [/s]
  • 其中 [/s] 是句子的起始/结束标记
  • 两个连续的 [/s] 分隔源语言和目标语言句子

Attention Mask 设置

关键点: 两种语言的 token 可以互相 attend

原文明确说明：

"To predict a word masked in an English sentence, the model can either attend to surrounding English words or to the French translation"

这意味着：

  • 不设置跨语言 mask: 源语言和目标语言的所有 token 都可以互相 attend
  • 使用 full attention（双向 Transformer）
  • 这正是 TLM 能够学习跨语言对齐的关键

Language ID 编码

从 Figure 1 可以看到：

Token Position Language
[/s] 0 en
the 1 en
2 en
blue 3 en
[/s] 4 en
[/s] 5 en
rideaux 0 fr
étaient 1 fr
2 fr
[/s] 3 fr

Language Embedding:

  • 每种语言有唯一的 language embedding（类似 token embedding）
  • 与 token embedding 和 position embedding 相加作为最终输入
  • 表示为: input = token_emb + pos_emb + lang_emb

Position Embedding 重置:

"To facilitate the alignment, we also reset the positions of target sentences."

目标语言句子的位置从 0 重新开始，而不是接续源语言的位置。这样设计的原因：

  1. 让模型更容易学习平行句对的对齐关系
  2. 避免 position embedding 对跨语言对齐造成干扰

训练目标

TLM 沿用 MLM 的 mask 策略：

  • 随机选择 15% 的 tokens 进行预测
  • 80% 替换为 [MASK]，10% 替换为随机 token，10% 保持不变
  • 关键区别: 在预测 masked token 时，模型可以 attend 到整个平行句对

4.4 训练配置

配置项 值
GPU 64 Volta GPUs（LM）/ 8 GPUs（MT）
Optimizer Adam
Learning rate 10^-4 到 5×10^-4
Batch size 64 streams × 256 tokens (CLM/MLM)
TLM batch 4000 tokens
Precision float16

4.5 训练策略

  • 纯单语场景: 使用 CLM 或 MLM
  • 有平行语料场景: MLM + TLM 交替训练
  • 语言采样权重: q_i = p_i^α / Σp_j^α，其中 p_i ∝ n_i

5. 关键实验：TLM 显著提升跨语言分类性能

5.1 跨语言分类（XNLI）

核心结果 (Table 1):

方法 平均准确率 提升

mBERT (Devlin et al.) 73.7% +3.5%
XLM (MLM only) 71.5% +1.3%

  1. 无监督的 MLM 方法已经超越了使用 2.23 亿平行句对的有监督方法 (71.5% vs 70.2%)

6. Golden Case：TLM 训练示例

输入样本

平行句对：

  • 英语: "the curtains were blue"
  • 法语: "les rideaux étaient bleus"

处理流程

Step 1: BPE 分词

English: the curtains were blue
French: les rideaux étaient bleus

Step 2: 拼接序列

Input: [/s] the  blue [/s] [/s] rideaux étaient  [/s]

Step 3: 添加 Embeddings

Token Token Emb Pos Emb Lang Emb 最终输入
[/s] vec_s 0 en sum
the vec_the 1 en sum
vec_mask 2 en sum
blue vec_blue 3 en sum
... ... ... ... ...
rideaux vec_rideaux 0 fr sum
étaient vec_étaient 1 fr sum
vec_mask 2 fr sum
[/s] vec_s 3 fr sum

Step 4: Transformer Encoder（Full Attention）

模型可以 attend 到：

  • 英语 token → 英语 token（双向）
  • 法语 token → 法语 token（双向）
  • 英语 token ↔ 法语 token（跨语言）

Step 5: 预测 Masked Tokens

  • 预测英语中的 `` 时，可以参考法语中的 "rideaux"
  • 预测法语中的 `` 时，可以参考英语中的 "blue"

最终输出

模型学习到：

  • "curtains" 与 "rideaux" 对应
  • "blue" 与 "bleus" 对应
  • 跨语言语义对齐

7. Insights：预训练是跨语言迁移的关键

7.1 论文评价

优点:

  1. 方法简洁有效：TLM 只是在 MLM 基础上拼接平行句对，但效果显著
  2. 实验全面：覆盖分类、翻译、低资源场景
  3. 无监督方法已经超越之前的有监督方法，意义重大

不足:

  1. TLM 的具体公式没有给出，只说是 MLM 的扩展
  2. 分隔符 [/s] 的使用没有详细说明
  3. Attention mask 的具体设置（是 full attention 还是有某些限制）没有代码层面的描述

7.2 领域启发

  1. 跨语言对齐不需要大量平行语料: MLM 预训练已经能学到一定的跨语言对齐，TLM 只是在此基础上增强
  2. 共享词表的重要性: BPE 共享词表让不同语言共享 anchor points（数字、专有名词等）
  3. 低资源语言的解决思路: 利用相似的高资源语言进行迁移

7.3 方法论启发

  1. 简单扩展往往有效: TLM 本质上是把 MLM 的输入从单语句子换成平行句对，改动很小但效果显著
  2. 消融实验设计: 对 encoder/decoder 分别预训练进行消融，发现 encoder 最重要
  3. 多任务评估: 在多个任务（分类、翻译、语言建模）上都验证方法有效性

8. 总结

核心创新

TLM (Translation Language Modeling): 将 MLM 扩展到平行句对，通过跨语言 attention 学习语言对齐。

局限性

  1. 依赖平行语料（虽然只需要少量）
  2. 主要关注欧洲语言，对远距离语言对效果未知
  3. TLM 与 MLM 的混合比例需要调参

改进方向

  1. 探索无平行语料的跨语言预训练
  2. 扩展到更多低资源语言
  3. 结合其他预训练目标（如 ELECTRA 的 replaced token detection）
