2. 关键问题：注意力头在全分布上的行为，和窄任务里看到的不一样

Golden Case — 问题是什么？

假设你在一个自定义数据集上发现某个注意力头在做"序列继承"（succession）——看到 [A][B]...[A] 就预测 B。你觉得这个头的职责很清楚了。但当你把它放到真实数据分布上跑，它同时还在做：复制（copying）、比较（comparison）、首字母缩略词生成（acronym production）。

这就是论文反复出现的主题：一个头在窄任务上的行为 ≠ 它在全分布上的行为。而且差异往往不容易刻画。

更麻烦的是，注意力头比 MLP 神经元难可视化得多——它是高秩的、同时组合 QK 和 OV 两条电路、还要在整个上下文窗口上激活。Feature Vis 对 residual stream 特征和 MLP 神经元很有效，但注意力头需要一套新的工具。

动机：

  • 已有工作（如 feature vis）对 residual stream 特征、MLP 特征和 MLP 神经元的可视化很成功，但注意力头因为高秩、双电路、长上下文激活，可视化难度更高。
  • 多篇 prior work 发现：注意力头在全分布上的行为和窄任务上不一样——Gould 2024 的 succession head（同一个头还做 copying、comparison、acronym）、Lieberum 2023 的多选题复制头、McDougall 2023 的 IOI 抑制头。
  • 需要一个工具，让研究者能轻松生成和检验关于"某个头在做什么"的假设。

之前的方法卡在哪里：

  • 单条 prompt 的注意力可视化（如 BERTviz）只能看一个输入下的模式，无法覆盖全分布。
  • 基于语料检索的方法（如 exBERT）依赖人工标注的参考集，扩展性有限。
  • AttentionViz 把 query/key 向量联合嵌入到低维空间，类似 HeadVis 的 PCA 视图，但没有 QK/OV 特征归因和跨头组合分析。
  • 缺少一个能同时看：注意力模式、QK/OV 归因、低秩投影、SAE 特征归因、数据集分布度量的统一交互工具。

3. 关键方法：HeadVis —— 一个交互式注意力头调查工具

Golden Case — 方法怎么跑？

延续上面的例子：你发现了一个看起来在做 induction 的头。打开 HeadVis：

  1. Head Selector 散点图：把 induction score 放到一个轴上，快速定位极端值的头。
  2. Attention Pattern 视图：看这个头在真实数据上的 top-activating 样本。比如一个诗歌样本里，gleam 的 attention 最高，但前面并没有 gleam 这个 token——说明不是字面 induction。
  3. Hover 看 attention 来源：hover 到 gleam 上，发现它 attend 回的是 dream 后面的 newline。这是 fuzzy induction：按语义/结构匹配，而非 token 匹配。
  4. QK 归因：从 gleam 到 newline 做 QK attribution。发现 query 侧是 "-ea sound at line end" 特征，key 侧是 "newline after an 'ee' sound" 特征。也就是说，QK 在 feature basis 上做 induction：匹配的不是具体 token，而是韵脚特征。
  5. OV 归因：OV 侧和字面 induction 一模一样——value 侧是 "current token is \n"，output 侧是 "say \n"。也就是说，fuzziness 完全在 QK；一旦决定 attend 哪里，复制行为和字面 induction 头一样。
  6. PCA 检查（可选）：对 Q、K、O 激活做 PCA，看是否有多个 distinct cluster——如果有，提示这个头可能是 polysemantic。

走完这个流程，你对这个头的理解从"它好像在做 induction"变成了"它在 feature basis 上做 fuzzy induction，QK 匹配韵脚/结构特征，OV 做标准复制"。

整体架构

HeadVis 由三部分组成：

  1. Frontend：交互式浏览界面（开源）
  2. Offline Script：预计算每个头的度量指标和注意力模式
  3. Server：处理实时查询（QK/OV 归因、自定义序列输入）

核心视图与功能

视图 功能 用途
Head Selector 散点图 横轴/纵轴/颜色均可配置为任意 per-head 度量（层数、head index、induction score 等） 快速定位极端值的头
Attention Pattern 视图 按 max attention pattern 分桶展示数据集样本；hover token 看其 attend 回哪些 key 直观理解头的激活模式
PCA 投影 对 Q、K、O 激活做 PCA；颜色可按 token-level 规则或自动聚类 检查头是否有多个 distinct 行为
QK 归因 把 attention score 分解为 (query feature, key feature) 的交互和 理解"为什么 attend 这里"
OV 归因 把头输出分解为 (value feature, output feature) 的交互和 理解"attend 之后做了什么"
Virtual Weights 投影特征通过 head 的 key/query 权重，看哪些其他特征在投影空间中靠近 发现跨特征的隐藏关联
Top Token 排行 按平均 attention 排列 top query/key tokens 快速把握头的偏好
自定义序列输入 输入任意文本，实时看 attention 模式（内部功能，未开源） 验证假设

技术细节

  • 特征来源：使用 10M-feature 的 weakly causal crosscoder (WCC)，与 QK Attributions 论文同款。
  • QK Attribution：把 attention score 写成 query feature 和 key feature 的交互之和。形式化：
    • 给定 query token q 和 key token k，attention score = softmax(QW_Q · KW_K^T / sqrt(d_head))
    • QK attribution 将其分解为特征对 (f_q, f_k) 的加权和，权重由 crosscoder 特征激活和投影矩阵决定
  • OV Attribution：把头输出写成 value feature 和 output feature 的交互之和。value feature 来自 attended token 的 residual stream 经 OV 电路；output feature 在 query token 位置。
  • PCA 方法：取 attention output norm 最高的 (query, key) 对，收集对应的 Q、K、O 激活，分别做 PCA。注意：O 激活 = key 的 residual stream 经 OV 电路，再乘以 attention weight。V 被省略，因为 V 和 O 通过固定线性映射 W_O 关联，PCA 定性结果相同。
  • Virtual Weights：参考 Circuit Tracing 论文，计算特征在 head 的 QK 电路中的"虚拟权重"——即投影特征通过 W_Q/W_K 后的余弦相似度，用于发现不直接共现但几何上对齐的特征。

与已有方法的区别

  • vs BERTviz / exBERT：从单条 prompt 可视化扩展到全分布 + 实时归因 + 跨头组合
  • vs AttentionViz：增加了 QK/OV 特征归因、virtual weights、head composition 等机制分析能力
  • vs TDB (Mossing 2024)：TDB 从 prompt+behavior 出发找贡献组件；HeadVis 从 head 出发反向理解其行为
  • 核心差异：HeadVis 不仅展示"attention 模式长什么样"，还提供"为什么是这个模式"（QK 归因）和"attend 之后做了什么"（OV 归因）的实时分解

4. 数据集：真实数据分布 + 自定义控制序列

  • 主要数据：未明确说明具体 benchmark 名称，但描述为"standard dataset"（用于 induction score 计算）和"full data distribution"（用于 HeadVis 浏览）。从上下文推断，应该是从模型训练/推理日志中采样的真实文本分布。
  • 自定义序列：用于验证假设的控制输入。例如：
    • Same-set suppression 实验：生成 185 条句子，形式为 "{five cities} are all cities in {country}"，其中 4 个城市属于该国，1 个是外国城市。
    • 替换实验：在真实序列中替换特定 token（如把 Ivory Coast 换成 Zambia 或其他 51 个非洲国家），测量 attention 变化。
  • 数据预计算：HeadVis 的 offline script 预计算 per-head metrics 和 attention patterns over dataset，避免前端实时计算。

5. 关键结果：四个案例研究展示了从"容易理解"到"很难理解"的完整光谱

5.1 Fuzzy Induction（容易理解）

  • 发现：早期层的 induction head 做字面复制（token-level 匹配）；中层 head 做 fuzzy induction（跨语言、反义词、结构位置、亲属关系）。
  • 关键洞察：fuzzy induction 的 fuzziness 完全在 QK 电路——OV 电路和字面 induction 一样做复制。
  • QK 归因示例：诗歌中 gleam attend 回 dream 后的 newline，因为 query 侧是 "-ea sound at line end"，key 侧是 "newline after an 'ee' sound"。
  • 数据来源：Figure 3（诗歌样本）、Figure 4（QK/OV 电路图）

5.2 Polysemantic Attention Head（相对容易）

  • 对象：一个之前被认为是"line width"的头（早期层，计算行宽）。
  • 发现：该头在全分布上至少有 3 个 distinct 行为：
    1. Years：tokenizer 把 1000-1999 的年份拆成 1 + 776，头从 776 attend 回 1。
    2. Multi-token words：长词被拆成多个 token，头在 token 间 attend（如 interpret + ability）。
    3. Newlines：从 newline attend 回前一个 newline——这是之前已知的行为。
  • 验证：Q、K、O 的 PCA 都把三个行为分成了 distinct cluster（Figure 6）。
  • 意外发现：Years 行为只在 1000-1986 年 strong attend，1987+ 衰减（Figure 7）。这个约束从 attention pattern 和 attribution 都看不出来，需要 sweep 才能发现。
  • 数据来源：Figure 5（样本）、Figure 6（PCA）、Figure 7（year sweep）

5.3 Answer Selection（中等难度）

  • 对象：之前被认为是"多选题答案选择"的头。
  • 发现：多选题只是其众多行为之一。在全分布上，它做的是更 general 的"帮助模型重复之前上下文"——通过识别"即将被提及的实体"。
  • OV 电路：始终做同一件事——复制 attended token 的内容，类似 induction。
  • QK 电路：复杂度在这里。Query 侧是"about to produce content matching that mark"，key 侧是"content the model has marked as relevant"。
  • 具体案例：
    • 多选题：query "about to say an answer" × key "correct answer"
    • 情感分类：query "about to say sentiment" × key "relevant sentiment cue"
    • 对话：query "about to say speaker's line" × key "previous speaker content"
  • Virtual Weights 分析："correct answer" 特征经 K 投影后，最相似的不是其他多选题特征，而是各种"this is the relevant content"特征——说明这些特征在 residual stream 中近正交，但头的 K 投影把它们映射到了一起。
  • 判断：作者倾向于认为这个头是 monosemantic（一个通用行为），但不敢完全确定——因为缺乏一个 crisp 的文本描述来验证全分布。
  • 数据来源：Figure 8-13

5.4 Same-Set Suppression（最难理解）

  • 对象：一个中层头，top query/key tokens 都是地点、人名、队名。
  • 核心发现：该头抑制"同一集合内"的 attention——比如国家 token 对自己城市 key 的 attention 被抑制，对外国城市反而高。
  • 实验验证：185 条控制句子，国家 token 对外国城市的 attention 高于本国城市——98% 的情况下成立。
  • QK 几何：
    • 国家 query 向量（减去跨国家均值）与本国城市 key 向量的余弦相似度：mean -0.47（负对齐）
    • 与外国城市 key 向量：mean +0.01（近零）
    • 在 residual stream 中，国家与本国城市原本正相关（mean +0.17），但 W_Q 和 W_K 投影后符号翻转。
  • K-Composition 案例：Ivory attend 到 a（一个无关 token），因为前面序列提到 chikumbuso（赞比亚非营利组织），一个早期头把 Zambian 特征写到了 a 的位置，当前头的 key 侧读取了这个特征。这说明：token 层面看不出模式时，feature 层面能解释。
  • 数据来源：Figure 14-20

6. Insights

6.1 对论文本身的 Comments

  • 反直觉的发现：Same-set suppression 头在 residual stream 中国家和本国城市是正相关的（+0.17），但经 W_Q/W_K 投影后变成负相关（-0.47）。这意味着头的"抑制"不是利用已有的负相关，而是主动通过投影矩阵翻转符号。如果让我来设计，我可能会假设模型直接利用已有的语义距离，而不是额外学习一个翻转。

  • Polysemanticity 的两种 flavor：论文明确指出 attention head 的 polysemanticity 可以"不需要 superposition"——因为头的输出是高秩的，可以把不同行为写到不同方向，下游组件可以直接读取。MLP 神经元输出是 rank-1，所以 polysemantic neuron 必须依赖 superposition。这个区分很 sharp，之前我没想到过。

  • Year 1000-1986 的 dropoff：一个让我意外的细节——line width 头的 years 行为在 1987 年后突然衰减。这说明即使 attention pattern 和 QK attribution 看起来覆盖了所有年份，实际的有效范围可能很窄。这种"隐性边界"在全分布探索中很容易遗漏，HeadVis 的 sweep 功能很关键。

  • Answer selection 头的判断困境：作者花了大量篇幅分析，最后结论仍然是"our best guess is monosemantic, but we aren't fully convinced"。这种诚实的 uncertainty 比强行下结论更有价值——它暴露了当前可解释性方法的根本局限：没有 crisp 假设就无法系统验证。

  • 开源策略的取舍：HeadVis 开源了 frontend + 接口规范，但实时自定义序列、logit lens、head composition heatmap 等内部功能未开源。这种"半开源"策略可能是为了降低维护负担，但也限制了社区复现某些案例研究的能力。

  • PCA 的局限性：作者自己警告了"PCA only projects...different attention behaviors could seem separable...but not actually impact the attention score"。A 版本没提这个警告，B 版本正确指出来了。PCA 在这里是假设生成工具，不是验证工具——这个定位很重要。

6.2 对未来的预测

  • Attention 分解方法会迎来一波进展：HeadVis 提供了 4 个清晰案例（从 clean 到 messy），正好覆盖了 polysemanticity、high-rank features、attention superposition 等障碍。这些案例将成为验证新分解方法的"标准测试集"。
  • Long context attention 会是下一个金矿：论文明确提到"heads that frequently attend over long distances have been less studied"，并暗示 system prompt 的作用可能和长距离 attention 有关。随着模型上下文越来越长，这个方向的研究价值会快速上升。
  • Softmax competition 的逻辑会被重视：目前 HeadVis 只分析单个 (query, key) 边，但 attention 的优先级逻辑（"attend to A if present, otherwise B"）依赖 softmax 竞争。理解这种竞争机制需要新的工具视角。
  • Attention 的 transcoder 会成为下一个热点：论文 Discussion 明确说"We don't know how to do the analogous thing for an attention layer"。现有方法（Attention-output SAEs, multi-token transcoders, Lorsa）都是 rank-1 OV basis，会把高秩行为（如 succession, copying induction）拆碎。我预测未来 1-2 年会有工作提出高秩 attention transcoder，并尝试在 HeadVis 发现的这些案例上验证。

6.3 研究品味

  • "工具先行，发现跟上"的研究策略：HeadVis 不是先提出理论再验证，而是先造工具、再让工具暴露现象、最后从现象中提炼理论障碍。这种"工程驱动"的路径在机制可解释性领域很有效——因为我们对 attention 的"理论预期"本身就不够成熟。
  • Case study 的梯度设计：四个案例从简单到复杂，形成了一条学习曲线。读者可以先在 induction 上熟悉工具，再跟着作者一步步进入更混乱的真实世界。这种写作结构让一篇工具论文同时成为了一篇教学材料。
  • Uncertainty 的显式标注：作者在 answer selection 和 same-set suppression 两个案例中都明确标注了"我们理解到哪一步、哪一步还不确定"。这种写法不仅诚实，也帮助读者区分"已验证的事实"和"合理的猜测"。
