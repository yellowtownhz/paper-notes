论文笔记: Why Fine-Tuning Encourages Hallucinations and How to Fix It

1. 背景信息

  • 一作 Guy Kaplan，Hebrew University of Jerusalem，Roy Schwartz 组
  • 合作方：Technion（Zorik Gekhman，现 Google DeepMind）、UIUC（Derek Hoiem）、USC（Swabha Swayamdipta）
  • 时间：2026年4月，arXiv preprint（cs.CL）
  • Gekhman 2024 那篇 "Does fine-tuning LLMs on new knowledge encourage hallucinations?" 的直接续作 — 同一帮人，从"发现现象"推进到"解释机制 + 给 fix"
  • 方法本身的学术谱系：Li & Hoiem (2017) "Learning without Forgetting" -> Zhu et al. (2025) LLM adaptation -> Shenfeld et al. (2026) continual learning -> 本文（验证了它对 fact-level forgetting 有效 + 解释了 why）

2. 关键问题：SFT 训新知识为什么会导致旧知识幻觉，能不能修

先看一个具体的例子（来自 Figure 1）：

模型已知 "Milan is in Italy"。现在 SFT 数据里加了一条合成事实 "Bergadena is in Greece"（Bergadena = Bergamo + Pasadena，跟真实城市名共享 token）。训练之后，模型确实学会了 Bergadena → Greece，但同时在 "Which country is Milan located in?" 上开始犯错——因为 Bergadena 的 token 和 Milan、Bergamo 共享 embedding neighborhood，梯度更新波及了邻居的表征。

对照组：如果把 "Bergadena" 换成 Loc_fcfb42（UUID，和真实城市名零重叠），模型同样学会了新事实，但 Milan 不受任何影响。

这就是这篇论文要解释的核心现象：不是所有新知识都导致遗忘，只有跟旧知识"长得像"的新知识才会。

从这个例子出发，问题可以一般化：SFT 阶段喂给模型它不认识的事实，模型学会了新事实，但同时在原本答对的旧事实上开始出错。在 1.5B 模型上遗忘约 15pp（93% → 78%），7-8B 模型上约 11-12pp。

为什么是问题：SFT 是 LLM pipeline 的标配步骤。如果每次 SFT 都以损坏已有知识为代价，你教模型一个新 domain，它在别的 domain 开始胡说。

已有方法的不足：

  • Gekhman et al. (2024) 发现了现象但没给 fix
  • Continual learning 文献大量讨论 catastrophic forgetting，但都在 task-level 而非 fact-level
  • 更关键的：forgetting 的机制不清楚 — 是容量不够？是 behavior cloning？还是表征干扰？不知道机制就没法选对方法

3. 关键方法：Self-Distillation 作为 SFT 的正则化

继续用 Bergadena 的例子走一遍 self-distillation 的流程：

  1. Phase 1：在模型已知的 fact（D_Known）上训 1 epoch，让它学会 "Q: ... A: ..." 的 QA 格式。此时模型知道 Milan → Italy，不知道 Bergadena。冻结这个 checkpoint 作为 teacher。
  2. Phase 2：在 D_Known + D_Unk（含 Bergadena → Greece）上继续训。除了标准 cross-entropy loss，还加一个 distillation loss：要求 student 在每个 token 上的输出分布不要偏离 teacher 太远。
  3. 效果：student 学会了 Bergadena → Greece（task loss 推动正确答案概率上升），但 teacher 记住了 Milan 这个 token 附近的概率分布——Italy 该是 top-1，France/Spain 是 plausible alternatives——distillation loss 阻止了学 Bergadena 时的梯度把 Milan → Italy 的概率推走。

从 drift 分析看（Figure 5），self-distillation 把旧知识的表征漂移压回到和 UUID（完全不干扰）相同的 baseline 水平。遗忘从 ~15pp 降到 ~3pp。

下面展开方法的细节。

基本设定

原始模型：Qwen2.5-1.5B（主实验），Qwen2.5-7B 和 LLaMA 3.1-8B 用于跨模型验证。都是 pre-trained base model，没有经过 instruction tuning。

训练任务：closed-book factual QA。输入 "Q: Which country is X located in?"，输出 "A: Italy"。标准 SFT（cross-entropy on answer tokens）。训练数据 = D_Known（8K 条模型已知的 fact）+ D_Unk（8K 条模型不认识的 fact），50:50 混合。

三个指标的物理含义：

指标 测的数据 物理意义 类比
D_Known acc 训练集中模型本来就知道的 fact Task learning — 模型有没有学会 QA 格式 类似 SFT 后模型学会了 chat template
D_Unk acc 训练集中模型原本不知道的 fact Factual plasticity — 模型能不能通过 SFT 学到全新的事实 教模型新 domain 知识
D_Held acc 测试集中模型原本就知道、但没出现在训练集中的 fact Factual stability — SFT 过程有没有损坏已有知识 你教模型新东西，它在旧知识上开始胡说了吗

好的 SFT 方法应该三个都高。Standard SFT 的问题是前两个都高，但 D_Held 掉得厉害。

方法一：参数冻结（不需要学新知识时）

为什么先讲参数冻结？因为它直接定位了遗忘发生在哪一组参数里，为 self-distillation 提供了机制线索。

FFN 层存储事实（Geva et al. 2021），attention 负责 task routing。分别冻结看效果（Table 1）：只训 attention 时，D_Unk 接近零（0.010），D_Held 维持 0.931，D_Known 达到 0.946。只训 FFN 则和全参数 SFT 一样遗忘（D_Held=0.782）。

结论：FFN 是事实写入的瓶颈。冻住 FFN 等于关掉"学新事实"的能力，自然不遗忘。适用于 alignment fine-tuning 等"不需要学新知识"的场景。

Fine-grained ablation（Table 3, Appendix C）：

  • 单个 attention projection (k/v/o/q)：D_Unk 全部约 0.005-0.006
  • FFN gate+up：D_Unk = 0.242（更接近全 FFN 的 0.941）
  • FFN down：D_Unk = 0.086

gate+up 比 down 的 plasticity 高 3 倍，和"FFN 上半部分写入 factual content"的结论一致。

方法二：Self-Distillation（需要学新知识时）

参数冻结在需要学新知识时不可用（D_Unk 直接降为零）。需要一种方法既允许学新事实，又保护旧知识。Self-distillation 的 motivation 是：不限制参数怎么动，而是限制模型在旧知识上的输出行为不要变。

核心 loss：

$$\mathcal{L}(\theta) = \mathcal{L}_{\text{task}}(\theta) + \lambda \cdot \mathcal{L}_{\text{distill}}(\theta; \theta_i)$$

其中 distillation loss 是 token-level KL divergence with temperature scaling：

$$\mathcal{L}_{\text{distill}}(\theta;\theta_i) = \mathbb{E}_{(x,y)\sim\mathcal{B}} \left[ \frac{\tau^2}{|M(y)|} \sum_{j \in M(y)} \mathrm{KL}\left( \mathrm{softmax}\left(\frac{z_{\theta_i,j}}{\tau}\right) \| \mathrm{softmax}\left(\frac{z_{\theta,j}}{\tau}\right) \right) \right]$$

符号解释：

  • $\theta_i$：teacher，模型在只训了 1 epoch D_Known 之后的 snapshot（学会了格式但还没开始学新事实）
  • $\theta$：student，正在被训的模型
  • $\tau = 0.5$：温度，比标准 KD 低（更 sharp）
  • $\lambda = 1$：distillation weight
  • $M(y)$：non-padded token positions
  • $\tau^2$ 前乘：标准 KD gradient scaling trick（Hinton et al. 2015）

训练流程：

  1. 第一阶段：在 D_Known 上训 1 epoch，让模型学会 QA 格式
  2. 冻结这个 checkpoint 作为 teacher
  3. 第二阶段：在 D_Known + D_Unk 上继续训，加 distillation loss

L2 Regularization 对比

一个自然的替代方案是直接在参数空间约束——用 L2 限制参数不要离 anchor 太远：

$$\mathcal{L}(\theta) = \mathcal{L}_{\text{task}}(\theta) + \lambda \|\theta - \theta_i\|_2^2$$

值得注意的是 L2 用的 anchor 是 epoch 2 的 snapshot（论文 Section 5.2 明确写了），而 self-distillation teacher 用的是 epoch 1 D_Known-only 的 snapshot。anchor 不同可能给 L2 带来不公平劣势（epoch 2 已包含部分 factual drift）。

即使如此，L2 的 forgetting 仍然约 10pp，远不如 self-distillation 的 ~3pp。L2 是"各向同性"约束（所有参数方向等权重），不关心移动方向；self-distillation 通过 output KL 只约束"模型在这些 input 上的表现不要变"，模型可以在不影响旧知识预测的方向上自由移动。

4. 数据集：EntityQuestions + 合成实体（10^3 到 10^6 规模）

训练数据

  • EntityQuestions (Sciavolino et al., 2021)：从 Wikipedia relational triplets 衍生的 QA pairs
  • SLiCK 分类：每个 question 跑 20 次不同 few-shot prompt (3-shot, 随机采样)，按一致性分 4 档：HighlyKnown / MaybeKnown / WeaklyKnown / Unknown
  • 关系筛选：保留 HighlyKnown 占比 > 30% 的关系（P17, P36, P407, P495）
  • 数据划分：
    • D_Known = 8,000 条 HighlyKnown（训练，教格式用）
    • D_Unk = 8,000 条 Unknown（训练，考察 plasticity）
    • D_Held = dev split 中的 HighlyKnown（测试遗忘）

合成数据（Section 5）

  • 关系固定为 P17 (Location -> Country)
  • Semantic keys：从真实地名拼接 token（如 Bergamo + Pasadena → Bergadena），跟真实 entity 有 token-level 重叠
  • UUID keys：随机标识符如 Loc_fcfb46ee，与已有 entity 零重叠
  • 规模从 10^3 到 10^6 缩放，value 都是真实国名

评估数据

  • D_Held：dev set 中 HighlyKnown facts
  • 还额外看了 MaybeKnown facts 的遗忘（Appendix A/B）

5. 关键结果：从假说排除到机制确认

以下结果按照 Section 2 的假说推演逻辑编排，逐层回答"遗忘的根因是什么"。

Step 0：Standard SFT 确实导致严重遗忘

方法 D_Unk (plasticity) D_Known (task) D_Held (stability)
Standard SFT (all params) 0.946 0.990 0.780
Only attention 0.010 0.946 0.931
Only FFN 0.941 0.997 0.782
Only Known (no D_Unk) -- 0.999 0.958
Self-Distillation ~comparable to SFT ~comparable ~0.90 (从 peak 降~3pp)

（来源：Table 1, Figure 2-3。Self-distillation 数字来自 Figure 3 曲线读数，非 Table 1）

Standard SFT: D_Held 从 peak ~93% 降到 ~78%，掉了约 15pp（1.5B 模型 + HighlyKnown）。这个遗忘是真实的、可复现的。下面的实验逐层追问：为什么？

Step 1：建立因果 — 遗忘确实与新知识引入有关

Only Known 对照（不引入任何新知识，只学 QA 格式）：D_Held 全程稳定 ~95-96%。

这排除了"SFT 格式学习本身导致遗忘"的可能，确认遗忘的因果来自新知识（D_Unk）的引入。

Step 2：排除行为克隆 — 不是所有新知识都导致遗忘（对应 Q1）

构造两组合成新知识，唯一区别是新实体名字是否与已有实体"长得像"：

  • UUID keys（与旧知识完全不像的随机编码名字）：10^3 到 10^6 规模，forgetting 始终 0-4%，D_Unk=100%
  • Semantic keys（跟真实地名有 token-level 重叠的合成名字）：forgetting 随 scale 急剧增长，10^6 时达 38-41%，D_Unk=100%

两组的学习效果完全相同（D_Unk=100%，D_Known>=90%），唯一区别在于遗忘。模型在 UUID 数据上同样学会了"自信回答原本不知道的问题"，但旧知识没受影响 → 不是行为模式泛化，是真的在知识层面发生了干扰。行为克隆假说排除。

Step 3：排除容量瓶颈 — 1M 新知识也不导致遗忘（对应 Q2）

同一个实验还同时排除了容量假说：1M 个 UUID 实体全学会了，旧知识纹丝不动。如果是"硬盘满了"，1M 条新知识不可能零遗忘。参数空间完全够用，不是存不下的问题。

至此，唯一存活的假说是表征干扰：遗忘不取决于新知识的数量，而取决于新旧知识在模型内部表征上的相似度。

Step 4：精确定位 — 干扰来自问题侧（key），而非答案侧（value）

一条知识有"问题侧"（entity name, 如 Bergadena）和"答案侧"（country name, 如 Greece）两端。到底是哪端的相似性在驱动遗忘？

Key type × Value type 交叉设计（Table 4, Appendix E）：

Key type Value type D_Held forgetting
Semantic Real country 38%
Semantic Semantic country 38%
Semantic UUID country 41%
UUID Real country 4%
UUID Semantic country 4%
UUID UUID country 4%

遗忘完全由 key type 决定，value 侧完全无影响。这切断了"因为答案（country name）跟已有知识冲突导致遗忘"的替代解释。干扰发生在输入端（entity name 的表征），而非输出端。

Step 5：直接观测机制 — 中间层表征漂移确认干扰

$$\mathrm{RD}_i = \mathbb{E}_{x \in D_{\text{Held}}} \left[ 1 - \cos(H_0^{(14)}(x), H_i^{(14)}(x)) \right]$$

Layer 14（Qwen2.5-1.5B 的中间层，28 层模型），取 entity last token 的 hidden state：

  • SFT on semantic keys: drift 从 ~5% 持续涨到 ~11%
  • SFT on UUID keys: 稳定在 ~5%
  • Self-distillation on semantic keys: 也稳定在 ~5%

UUID 和 self-distillation 在 drift 上行为一致 — 都只有 task-format adaptation 阶段的 baseline drift (~5%)。Semantic keys 额外的 6pp drift 就是 representational interference 的直接观测。

（注：论文还用了额外 5 种 drift metrics 做 triangulation — NS, MTD, Rank-rho, NTR, JSD — 结论一致，详见 Appendix F。）

Self-Distillation 效果：遗忘从 ~15pp 压到 ~3pp

机制搞清楚了，fix 自然落出来：用 self-distillation 约束模型在旧知识上的输出分布不要漂移。

  • Self-Distillation: D_Held 仅掉约 3pp，且 D_Unk 学习速度基本保持
  • 从 drift 分析看（Figure 5），self-distillation 把表征漂移压回到和 UUID 相同的 baseline 水平 — 阻止了 interference 的传播

跨模型验证（Appendix B）：

模型 Regular SFT D_Held Self-distill D_Held Mitigation
Qwen2.5-1.5B ~78% (from 93%) ~90% ~80%
Qwen2.5-7B ~85-86% ~95% ~80%
LLaMA 3.1-8B ~85-86% ~95% ~80%

MaybeKnown facts 遗忘更严重：regular SFT 下 ~18-19pp drop，self-distillation 恢复约 90% of forgetting。

Ablation：Self-distillation 的有效成分是什么？（Appendix F）

Self-distillation 的 KL loss 覆盖了整个词汇表（~15K tokens）。但真的是每个 token 都需要约束吗？还是只有某些关键 token 在起作用？

论文设计了两组蒸馏对比（10K semantic-overlap setting），约束的 token 数量完全相同（都是 76 个），区别只在于选哪些 token：

  • Top-k distillation：只约束 teacher 概率最高的 76 个 token（占词汇表 0.5%，但覆盖了 teacher 91-92% 的概率质量）
  • Random-k distillation：同样约束 76 个 token，但从词汇表里随机选

用 Bergadena 的例子来说明两组的差异。对于 "Where is Milan located?" 这个输入：

  • Teacher 的输出分布大概是：Italy (85%), France (5%), Spain (3%), Germany (1%), ... 剩下 ~15K 个 token 分享剩余的 6%
  • Top-k 约束的就是 Italy、France、Spain、Germany 这些 — 正好是跟旧知识竞争的那些 entity token
  • Random-k 约束的可能是 the、is、located、quantum 这些 — 跟旧知识的保护毫无关系

结果：

  • Top-76：forgetting 降到 ~3pp，跟 full distillation 一模一样
  • Random-76：forgetting 停在 ~10pp，跟 standard SFT 没区别

结论：self-distillation 的有效成分是保护 teacher 在 competing entity tokens 上的 opinion — 即"对于这个问题，哪些替代答案是 plausible 的"。只要保护了这个高概率区域，学新实体的梯度就推不走旧实体的概率质量。约束 random tokens 完全没用，因为那些 token 跟新旧知识之间的竞争无关。

6. Insights

6.1 对论文本身的 Comments

  1. 最反直觉的发现：1M UUID 实体不造成任何遗忘。这彻底否定了 "capacity" 解释 — 模型参数完全够用，问题不是存不下而是存的位置互相干扰。如果让我来做，我大概率会先设计 capacity 实验（缩小模型 / 增大数据量），而不是想到用 surface form 来隔离 interference。用 entity name 的表面形式作为 single variable 来 disentangle 三个假说，一个实验直接打死两个假说 — 实验设计非常 elegant。

  2. Table 4 的 value-type 控制是全文最 clean 的因果实验。6 cells 交叉设计，key type × value type，所有条件下 D_Unk=100% + D_Known>=90%，forgetting 差异不能归因于学习效果差异。直接排除了"value 侧冲突导致遗忘"的替代解释。如果只有 Figure 4 没有 Table 4，别人可以说"也许是因为 semantic key 的 value (real country) 和已有知识冲突"，Table 4 把这条路堵死了。

  3. Self-distillation 方法不新，但 Appendix F 的 top-k ablation 给出了真正的机制洞察。只约束 teacher top-76 tokens (0.5% vocab) 就完全复现效果，random-76 无用。这说明 interference 高度 localized 在 competing entity tokens — self-distillation 之所以有效不是因为"保留了全部 dark knowledge"，而是因为保护了"teacher 认为哪些替代答案是 plausible 的"这个 opinion。

  4. 做得不够好的几个点：

    • L2 对照实验可能不公平 — L2 anchor 是 epoch 2 snapshot（已有 factual drift），self-distillation teacher 是 epoch 1 D_Known-only（干净）。如果 L2 也用 epoch 1 的 snapshot，效果会不会更好？论文没做这个 ablation。
    • 没有 EWC baseline — 拿 uniform L2 做 straw man 然后说"weight-space constraint 不够"，结论太强。EWC（Fisher information-weighted penalty）理论上能更精准保护重要参数。只有排除了 EWC，"必须在 output distribution 层面约束"这个结论才能 cleanly claim。
    • 没有 LoRA baseline — LoRA 约束了 weight update 的 rank，理论上也限制了 interference 传播的"带宽"。这是目前最流行的 SFT 方法，完全不提甚至 Related Work 都没有，是个明显的缺失。
    • Self-distillation 需要 teacher forward pass 常驻 GPU memory（8B 模型 = 多 16GB VRAM），overhead 未量化。

6.3 研究品味

这篇的写作策略：不是 "propose a new method and show it works"，而是 "explain why a phenomenon happens, and the fix falls out naturally from the explanation"。方法（self-distillation）不新，但 framing（把 hallucination reframe 为 representational interference driven forgetting）和 mechanistic analysis（semantic vs UUID + drift metrics）是新的。

实验设计有贯穿始终的三层递进：先建立因果关系（Only Known 对照），再操控单一变量（key type），再验证机制（drift analysis + top-k ablation）。每一层都有 clean control。
