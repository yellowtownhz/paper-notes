2. 关键问题: 用 CE 训练真的是最优解吗？

这篇论文在问一个很基础的问题：大家都用 cross-entropy (CE) 做 fine-tuning，但 CE 是 0-1 loss 的 surrogate，我们训练完了是用 0-1 loss 评估的——那干嘛不直接优化 0-1 loss？

更有意思的是，他们发现了一个反直觉的现象：

  • 传统 common sense 说高熵 training 好（label smoothing、focal loss、confidence penalty 都是增熵的）
  • 但在预训练模型上做持续学习时，低熵反而更好

为什么？因为预训练模型已经有很好的表示了，excessive exploration 会破坏已有的知识。CE 的问题在于它天然偏向 exploration（给 low-confidence 样本更大的梯度权重），而 EPG 偏向 exploitation（给 high-confidence 样本更大的权重）。

3. 数据集: 四个视觉持续学习 benchmark

都是 class-incremental setting，没有 replay

  • Split-ImageNet-R: 200 个 ImageNet 类别，24k 训练 + 6k 测试，有 class imbalance。划分为 5/10/20 个任务
  • Split-Food101: 101 个食物类别，每类 750 训练/250 测试，共 101k 图像。划分为 10 个任务
  • Split-CUB200: 200 个鸟类，11,788 张图像。划分为 10 个任务（每任务 20 类）
  • CLRS25: 25 个遥感场景类别，每类 600 张 256×256 图像。划分为 5 个任务

评估指标:

  • $A_T = \frac{1}{T}\sum_{i=1}^{T} a_{i,T}$: 最终在所有任务上的平均准确率
  • $\tilde{A}_T = \frac{1}{T}\sum_{t=1}^{T} A_t$: 学习过程中的平均准确率

4. 关键方法: 用 RL 视角重新审视分类

4.1 整体思路

论文的核心 insight 是把分类问题重新建模成一个 one-step MDP：

元素 对应
State space 输入样本 $x \sim d(x)$
Action space 类别标签 $\mathcal{A}$
Reward function 预测正确 → 1，错误 → 0
Policy $\pi_\theta(a\|x) = \text{softmax}(f_\theta(x))$

这样，最大化 expected reward $J_\pi(\theta) = \mathbb{E}_{x,a}[r]$ 就等价于最小化 0-1 loss。

4.2 Expected Policy Gradient (EPG)

关键点：在分类任务里，reward function 是 fully observable 的（因为知道 label，就知道每个 action 对应的 reward）。这意味着我们不需要像 REINFORCE 那样采样 action，可以直接计算 expectation over actions。

EPG gradient: $$\hat{g}_{\text{EPG}} = \frac{1}{N}\sum_{x_i \sim d(x)} \sum_{a \in \mathcal{A}} \pi_\theta(a|x_i) \mathcal{R}_{x_i,a} \nabla_\theta \log \pi_\theta(a|x_i)$$

其中：

  • $N$ 是 batch size
  • $\mathcal{R}_{x_i,a}$ 是 reward，$a = y$ 时为 1，否则为 0
  • $\pi_\theta(a|x_i)$ 是 softmax 输出

这样消除了 action sampling 的方差，$\text{Var}[\hat{g}_{\text{EPG}}] \leq \text{Var}[\hat{g}_{\text{REINFORCE}}]$。

4.3 CE vs EPG: 关键发现

一句话理解两者的本质区别：

EPG CE
视角 RL：分类正确 = reward 1，错误 = 0 监督学习：最小化预测分布和真实分布的 KL 散度
优化目标 直接优化 0-1 loss（分类准确率） 优化 surrogate loss（CE 是 0-1 的上界）
样本权重 给 confident 样本 更大梯度权重 给 uncertain 样本 更大梯度权重
行为倾向 exploitation（巩固已有成果） exploration（盯着难样本死磕）

论文证明了两者的梯度关系：

$$\hat{g}^i_{\text{CE}}(x_i, y_i) = -\frac{1}{\pi_\\theta(y_i|x_i)} \hat{g}^i_{\text{EPG}}(x_i, y_i)$$

换句话说：CE 可以理解成 "加权的 EPG"，权重是 surprisal $1/\pi(y|x)$。

  • 两者梯度方向相同，但 sample weighting 不同
  • CE: 给 low-confidence 样本更大权重（$\pi_\theta(y_i|x_i) \approx 0$ 时权重巨大）
  • EPG: 给 high-confidence 样本更大权重（$\pi_\theta(y_i|x_i) \approx 1$ 时权重最大）

所以 CE 是 exploratory 的（关注难样本、高 surprisal），EPG 是 exploitative 的（关注简单样本、低 surprisal）。

为什么 EPG 熵降更快？

论文 Proposition 3 证明 EPG 目标等价于同时最小化 KL 散度和熵： $$\max_\theta J^{RL}_{p_\theta}(\theta) \equiv \min_\theta \left[ D_{\text{KL}}(p_\theta \| q_\eta) + H(p_\theta) \right]$$

而 CE 只最小化 KL 散度，不显式约束熵。

直觉上的理解：EPG 给 confident samples 更大权重 → 这些样本的预测已经接近正确 → 梯度会进一步强化正确预测 → 熵自然下降更快。反过来 CE 给 uncertain samples 更大权重 → 这些样本可能是错的 → 梯度可能在错误方向上强化 → 熵的下降不稳定。

4.4 Adaptive Entropy Annealing (aEPG)

核心问题：纯 EPG 可能 plasticity 不够，纯 CE 会遗忘。解决方案是用 sigmoid schedule 做 interpolation。

aEPG gradient: $$g_{\text{aEPG}}(\theta) = \alpha_t g_{\text{CE}}(\theta) + (1-\alpha_t)(-g_{\text{EPG}}(\theta))$$

Sigmoid schedule: $$\alpha_t = \sigma\left(\tau \frac{T-2t}{T}\right)$$

其中：

  • $T$ 是总训练步数
  • $\sigma(x) = (1+e^{-x})^{-1}$ 是 sigmoid 函数
  • $\tau = 6$ 是默认值

Schedule 的效果:

  • $t=0$ 时：$\alpha_0 = \sigma(6) \approx 0.997$，几乎纯 CE（exploration）
  • $t=T$ 时：$\alpha_T = \sigma(-6) \approx 0.003$，几乎纯 EPG（exploitation）

4.5 训练配置

  • Optimizer: Adam，lr=0.0005，batch size=256

结论极其清晰: 所有增熵方法都比 CE 差，所有降熵方法都比 CE 好。这完全颠覆了传统 wisdom。

EP vs EPG 的疑问: 两者都降熵，效果接近，但 EP 在 CUB200 上比 EPG 好。论文解释是 "low intra-class variance in fine-grained tasks"，但这个解释有点 hand-wavy [?]。

一个猜测：EP 是全局降熵（加一个 $-\beta H(\pi)$ 项），EPG 是 sample-wise 降熵（每个样本的梯度权重不同）。在 fine-grained task 上，全局降熵可能更稳定？这个假说需要验证。

5.3 Noise Tolerance

Table 4: 20% symmetric label noise

Method S-ImageNet-R S-CUB200 CLRS25
CE 70.6 ± 0.1 79.5 ± 0.3 67.7 ± 1.2
aEPG 73.8 ± 0.2 81.3 ± 0.0 73.4 ± 1.9

aEPG 对 label noise 更鲁棒，这和理论分析一致：EPG 给 confident samples 更大权重，不容易被 noisy labels 带偏。

Proposition 2 证明：在 symmetric label noise 下，EPG 是 noise-tolerant 的，只要噪声率 $\eta < 1 - \frac{1}{K}$。

5.4 Ablation: α 的选择

Figure 3a: 固定 α vs adaptive α

  • α = 0 (纯 EPG): 性能还可以，但不如 adaptive
  • α = 0.2~0.5: 比 CE 好
  • α = 1 (纯 CE): baseline
  • Adaptive sigmoid schedule 最好

不同 schedule: Linear decay 和 cosine decay 和 sigmoid 效果差不多。关键是 "从 CE 开始，以 EPG 结束" 这个设计。

注意: 纯 EPG (α=0) 在 CIFAR-100 上完全 fail 了（只有 7.32%），说明从头训练需要 exploration。但混合 CE 和 EPG（α=0.2）反而比纯 CE 好。

这个实验揭示了 EPG 的适用边界：EPG 依赖于模型已经有合理的 confidence 分布。随机初始化的网络对所有样本都不 confident（$\pi(y|x) \approx 1/K$），导致 EPG 梯度权重对所有样本都一样小，无法有效学习。

6. Golden Case: 一个样本的梯度计算

假设一个 5 分类任务，输入 $x_i$，真实标签 $y_i = 3$，模型输出 softmax 为 $\pi_\theta = [0.05, 0.05, 0.1, \mathbf{0.7}, 0.1]$（正确类别概率 0.7）。

CE gradient 权重: $-1/0.7 \approx -1.43$

EPG gradient 权重: $0.7$

两者方向相同，但 CE 权重更大。

如果模型不确定 ($\pi_\theta(y_i|x_i) = 0.3$):

  • CE 权重 = $-1/0.3 = -3.33$
  • EPG 权重 = $0.3$

CE 给这个难样本 10 倍 更大的梯度权重！

如果模型很 confident ($\pi_\theta(y_i|x_i) = 0.9$):

  • CE 权重 = $-1/0.9 \approx -1.11$
  • EPG 权重 = $0.9$

两者权重接近。

这就是为什么 EPG 适合持续学习：它"温柔"地处理简单样本，对预训练权重扰动小。而 CE 会给难样本巨大的梯度更新，在新任务学习时可能有用，但会破坏旧知识。

  • 我目前的理解：论文只做了 vision 的实验，但理论分析对 NLP 应该也适用。LLM fine-tuning 也是在 pretrain 基础上做，也应该有 "excessive exploration 会破坏预训练知识" 的问题
  • 核心挑战：LLM generation 是 sequential decision making（多个 token 的序列决策），不是 one-step MDP，需要把 EPG 扩展到 multi-step 场景
  • 一个可能思路：per-token EPG？在每个 token 位置，把下一个 token 的预测看作一个分类问题

8. Insights

8.1 对论文本身的 Comments

反直觉的发现: 之前我一直觉得 label smoothing、focal loss 这些增熵方法是"正道"，能 improve calibration、防止 overconfidence。但论文发现在预训练模型上做持续学习时，这完全是反的——低熵才是王道。

本质区别在于：

  • 传统 wisdom（增熵好）适用于：train from scratch、单任务学习、需要 good calibration 的场景
  • 论文发现（降熵好）适用于：pretrained model、持续学习（多任务序列）、已有知识需要保护

做得不够好的地方:

  1. NLP 实验缺失。只做了 vision，没有验证在 LLM 上的效果
  2. EP vs EPG 的对比分析不够深入。论文说 EP 和 EPG 效果相近，但没有深入分析两种方法的 trade-off
  3. 为什么 EP 在 CUB200 上更好？论文的 explanation 有点 hand-wavy

9. 总结

  • 核心创新: 用 RL 视角推导出 CE 和 EPG 的梯度关系——两者方向相同，只是样本权重不同。CE 用 surprisal ($1/\pi$) 加权，偏向 exploration；EPG 用 confidence ($\pi$) 加权，偏向 exploitation。在预训练模型的持续学习中，exploitation 更重要。
  • 局限性: 只验证了 vision 任务，NLP 上的效果未知；EP vs EPG 的区别分析不够深入；schedule 参数缺乏消融
  • 改进方向: 迁移到 LLM 的持续 fine-tuning（特别是 instruction tuning 的增量更新）；研究 EP 和 EPG 在 fine-grained 任务上的本质区别
